# Phase 43.4 Plan 01: Service Layer Optimizations & Bar Layout Cleanup Summary

**Eliminated idle procfs/sysfs syscall churn in background telemetry singletons and retired legacy status bar Resources pill.**

## Performance & Execution Metrics

- **Duration:** 12 min
- **Completed:** 2026-09-27
- **Tasks:** 3
- **Files modified:** 4
- **Production Commit:** `79d38a0`

## Accomplishments

1. **Eliminated `ResourceUsage.qml` 1ms Polling Anomaly:**
   - Declared `property bool isInspectorActive: false`.
   - Replaced `interval: 1` anomaly with declarative binding: `interval: root.isInspectorActive ? 1000 : (Config?.options?.resources?.updateInterval ?? 3000)`.
   - Eliminated imperative `interval = ...` reassignment inside `onTriggered`.
   - Extracted `function pollMetrics()` and added `Component.onCompleted: root.pollMetrics()` for synchronous startup initialization.
   - Gated `root.updateHistories()` behind `if (root.isInspectorActive)` to stop V8 heap churn and GC passes during idle.

2. **Implemented Two-Tier Demand-Gated Sweeping in `HardwareTelemetry.qml`:**
   - Separated polling into `pollTier1()` (3 pill files: `/proc/stat` CPU aggregate line, package temp, and iGPU RC6 residency) and `pollTier2()` (remaining 28 sensors: per-thread loads, frequencies, governors, NVMe, motherboard, GPU clock/throttle).
   - `pollAll()` invokes `pollTier1()` unconditionally and `pollTier2()` only when `root.fastPollingRequests > 0`.
   - Bound `onFastPollingRequestsChanged` to trigger `root.pollTier2()` immediately when `fastPollingRequests === 1` for zero-latency frame 0 rendering.

3. **Retired Legacy `Resources` Status Bar Pill:**
   - Removed `BarGroup { id: resourcesGroup; Resources { ... } }` from `BarContent.qml`.
   - Removed `Resources { ... }` and `HorizontalBarSeparator` from `VerticalBarContent.qml`.
   - Left Zone is uncluttered and primed for Phase 44 `MemoryStoragePill.qml`.

# Phase 54.3: Interactive Multi-Metric Hourly Graph Component - Research

**Researched:** 2026-10-13  
**Domain:** Meteorological Canvas 2D Data Visualization, Reactive QML Shell Components, Zero-Repaint Hover Scrubbing  
**Confidence:** HIGH  

## Summary

Phase 54.3 transforms the baseline 24-hour temperature/rain graph into a fully featured, interactive multi-metric hourly graph component (`WeatherGraph.qml`) deployed in `restow/quickshell/.config/quickshell/ii/modules/ii/bar/weather/WeatherGraph.qml` shadowing upstream via GNU Stow leaf symlinks. The component visualizes the 25-point rolling timeline (`[-12h .. NOW .. +12h]`) delivered in Phase 54.2 (`Weather.timeline`) across six meteorological parameter groups: **Thermal (Temp)**, **Precipitation (Rain)**, **Wind**, **Air Quality (AQI)**, **Atmosphere (Baro)**, and **Solar (UV)** [VERIFIED: `Weather.qml` schema].

A single-row horizontal metric selector tab bar positioned directly beneath the card header allows instant 1-tap switching between all six parameter groups without horizontal scrolling or wrapping (~416px usable width). Tab transitions employ a smooth sliding highlight animation (~200ms `Appearance.animationCurves.expressiveEffects`) while triggering an instant single-shot Canvas 2D repaint (`requestPaint()`), strictly avoiding multi-frame canvas transitions to preserve the system's quiescent zero-repaint performance policy ($\le 1.68\%$ idle CPU) [VERIFIED: `Appearance.qml`, Phase 50 benchmark baseline].

The visualization standardizes on a dual-tier canvas layout across all six tabs: the upper ~70% renders continuous Fritsch-Carlson Monotone Cubic Splines, and the lower ~30% renders domain-specific context bars (e.g. rain volume, cardinal wind coloring, particulate PM2.5/PM10, visibility, and solar radiation). A unified Y-coordinate helper `getMetricY()` is shared symmetrically between `Canvas.onPaint` and `MouseArea.onPositionChanged`, guaranteeing 0px divergence between rendered curves and the interactive snap dot. Interactive scrubbing employs zero Canvas repaints, tracking cursor coordinates through lightweight QML overlay items with a context-adaptive floating tooltip pill that intelligently flips above or below the cursor based on vertical clearance [VERIFIED: `WeatherGraph.qml` prototype].

**Primary recommendation:** Centralize all curve scaling and coordinate mapping into a single helper `getMetricY(metricKey, slotIndex, plotTop, plotBottom)` consumed identically by `Canvas.onPaint` and `MouseArea.onPositionChanged`, gate all canvas paints strictly behind `root.popupActive`, and render all scrub overlays exclusively via lightweight QML Items with zero `requestPaint()` invocation.

### Pattern 1: Symmetric Single-Source-of-Truth Y-Coordinate Helper (`getMetricY`)
Both `Canvas.onPaint` and `MouseArea.onPositionChanged` must evaluate identical coordinate mappings to avoid 1–4px divergence between the rendered curve and the interactive snap dot.
```javascript
function getMetricY(metricKey, slotIndex, plotTop, plotBottom) {
    const hours = root.validHours;
    if (!hours || slotIndex < 0 || slotIndex >= hours.length) return plotBottom;
    const h = hours[slotIndex];
    if (root.isTimeline25 && h.isHistoricalUnavailable) return plotBottom;

    const plotHeight = plotBottom - plotTop;

    switch (metricKey) {
        case "temp": {
            const bounds = root.calcTempBounds();
            const range = Math.max(1, bounds.max - bounds.min);
            const val = (h.thermal && h.thermal.tempC !== null) ? h.thermal.tempC : (Number(h.tempC || 20));
            return plotBottom - ((val - bounds.min) / range) * plotHeight;
        }
        case "rain": {
            // Fixed 0-100% scale
            const prob = (h.moisture ? h.moisture.rainProb : (parseInt(h.chanceofrain || 0, 10))) || 0;
            return plotBottom - (Math.max(0, Math.min(100, prob)) / 100.0) * plotHeight;
        }
        case "wind": {
            const maxSpeed = root.calcWindMax();
            const val = (h.wind ? h.wind.speedKmph : (parseInt(h.windspeedKmph || 0, 10))) || 0;
            return plotBottom - (val / maxSpeed) * plotHeight;
        }
        case "aqi": {
            // Fixed discrete EPA scale 1-6
            const epa = (h.aqi ? h.aqi.epaIndex : (parseInt(h.air_quality ? h.air_quality["us-epa-index"] : 1, 10))) || 1;
            const clamped = Math.max(1, Math.min(6, epa));
            return plotBottom - ((clamped - 1) / 5.0) * plotHeight;
        }
        case "baro": {
            const bounds = root.calcBaroBounds();
            const range = Math.max(4, bounds.max - bounds.min);
            const val = (h.atmosphere ? h.atmosphere.pressureHpa : (parseInt(h.pressure || 1013, 10))) || 1013;
            return plotBottom - ((val - bounds.min) / range) * plotHeight;
        }
        case "uv": {
            const maxUV = root.calcUvMax();
            const val = (h.solar ? h.solar.uvIndex : (parseInt(h.uvIndex || 0, 10))) || 0;
            return plotBottom - (val / maxUV) * plotHeight;
        }
        default:
            return plotBottom;
    }
}
```

### Pattern 2: Single-Shot State-Driven Canvas Multiplexing
Avoid multi-canvas stacks or frame-by-frame crossfades. A single Canvas item switches active datasets and calls `requestPaint()` exactly once per tab tap [VERIFIED: D-54.3-06, D-54.3-07]:
```qml
MouseArea {
    anchors.fill: parent
    cursorShape: Qt.PointingHandCursor
    onClicked: {
        if (root.activeMetric !== modelData.id) {
            root.activeMetric = modelData.id;
            graphCanvas.requestPaint();
        }
    }
}
```

### Pattern 3: Standardized Dual-Tier Geometry
Dedicate upper ~70% to continuous curves and lower ~30% to domain context bars, with an 8px vertical buffer and a dedicated bottom axis band for glyphs and timestamps [VERIFIED: D-54.3-08]:
```javascript
const plotLeft = 14;

```

### Pattern 4: Smart Tooltip Vertical Flip with Edge Clamping
To prevent the tooltip from colliding with the top tab bar when hovering near the top of the canvas, flip the pill downward when $Y < 60\text{px}$, and clamp horizontally 6px inside card borders [VERIFIED: D-54.3-22]:
```qml
x: Math.max(6, Math.min(parent.width - implicitWidth - 6, root.activeScrubX - implicitWidth / 2))
y: (root.activeScrubY < 60) ? (root.activeScrubY + 14) : (root.activeScrubY - implicitHeight - 8)
```

### Anti-Patterns to Avoid

- **Anti-Pattern 1: Calling `requestPaint()` inside `MouseArea.onPositionChanged`:** Triggers full canvas rasterization at 60–120Hz while the user drags across the graph, causing massive GPU/CPU spikes and violating the quiescent system policy. Overlay items must be updated declaratively without painting.
- **Anti-Pattern 2: Multi-Canvas Buffering for Animated Crossfades:** Allocating 6 separate Canvas items with crossfade opacities creates 6 OpenGL/Vulkan Framebuffer Objects (FBOs), causing heavy VRAM thrashing and idle composite load.
- **Anti-Pattern 3: Duplicating Y-Scaling Formulas:** Calculating Y coordinates in `onPaint` with local variables and writing separate formulas in `onPositionChanged` results in rounding divergence and visual drift of the snap dot.
- **Anti-Pattern 4: Hardcoding Static Hex Colors:** Using `#4fc3f7` or `#81c784` directly rather than `Appearance.colors.colPrimary` or `WeatherGlyphs.getAqiColor()` breaks dark/light theme switching and Matugen wallpaper adaptation.
- **Anti-Pattern 5: Using Optional Chaining (`?.`) in QML JS Blocks:** Older Qt Declarative versions or `qmllint` syntax checkers may throw syntax errors on `obj?.prop`. Use safe guarded expressions `(obj && obj.prop ? obj.prop : fallback)` [VERIFIED: `qmllint` output].

## Common Pitfalls

### Pitfall 1: Zero/Flat Scaling Division by Zero
**Problem:** In dry climates (0 mm rain) or calm days (0 km/h wind), `max - min` equals 0. Naively calculating `val / max` yields `NaN` or `Infinity`, causing Canvas drawing paths to fail silently or corrupt the display.  
**Mitigation:** Enforce safe positive denominators across all metrics:
- Temp: `Math.max(1, padMax - padMin)`
- Rain: Lower bound 0, upper bound 100% (denominator 100); volume denominator `Math.max(5.0, maxMM)`
- Wind: Denominator `Math.max(20, Math.ceil((maxSpeed + 5) / 5) * 5)`
- AQI: Denominator 5 (`(epaIndex - 1) / 5.0`)
- Baro: Denominator `Math.max(4, padMax - padMin)`
- UV: Denominator `Math.max(11, maxUV + 1)`

### Pitfall 2: Historical Unavailable Past Slots Corrupting Splines
**Problem:** On initial cold boot, yesterday's hourly history is not yet populated (`isHistoricalUnavailable === true`), leaving `thermal.tempC === null` for slots 0..11. Passing `null` to `getY()` produces `NaN` coordinates, breaking `ctx.bezierCurveTo()`.  
**Mitigation:** Spline point arrays must only be populated with valid non-null coordinates. The unavailable range (e.g. index 0 to `firstValid - 1`) renders a subtle hatched rectangle with the text `"Past data unavailable"`, and splines begin cleanly from the first populated slot [VERIFIED: D-54.3-18].

### Pitfall 3: Tab Highlight Slider Layout Desync
**Problem:** If the animated highlight rectangle attempts to bind to `activeTabPill.x` before the `Repeater` has finished instantiating child items, `activeTabPill` is `null`, causing QML runtime warnings or an invisible highlight.  
**Mitigation:** Guard the highlight rectangle with `visible: activeTabPill !== null` and retrieve the target pill safely via `tabsRepeater.itemAt(activeMetricIndex)`.

### Pitfall 4: Tooltip Clipping at Canvas Edges
**Problem:** When hovering over slot 0 (-12h) or slot 24 (+12h), an unconstrained tooltip pill will overflow past the card borders and get clipped by parent containers. When hovering near the top of the curve, it collides with the tab pills.  
**Mitigation:** Implement dual-axis clamping:
- Horizontal: `Math.max(6, Math.min(parent.width - implicitWidth - 6, root.activeScrubX - implicitWidth / 2))`
- Vertical: `(root.activeScrubY < 60) ? (root.activeScrubY + 14) : (root.activeScrubY - implicitHeight - 8)` [VERIFIED: D-54.3-22].

### Pitfall 5: Unwanted Canvas Repaints During Scrubbing
**Problem:** If property bindings or signal handlers inadvertently trigger `requestPaint()` when `activeSlotIndex` changes, the zero-repaint policy is broken.  
**Mitigation:** Ensure `onPositionChanged` only updates coordinate properties (`activeScrubX`, `activeScrubY`, `activeSlotIndex`). The test harness must grep `onPositionChanged` and assert that `requestPaint` is completely absent from its implementation.

### Context-Adaptive Scrub Readout Formatter
```javascript
function formatTooltipMetric(metricKey, slot) {
    if (!slot) return "--";
    if (root.isTimeline25 && slot.isHistoricalUnavailable) return "Past data unavailable";

    switch (metricKey) {
        case "temp": {
            const t = (slot.thermal && slot.thermal.tempC !== null) ? slot.thermal.tempC : (slot.tempC || "--");
            const f = (slot.thermal && slot.thermal.feelsLikeC !== null) ? slot.thermal.feelsLikeC : (slot.FeelsLikeC || t);
            const prob = slot.moisture ? slot.moisture.rainProb : (slot.chanceofrain || 0);
            const mm = slot.moisture ? slot.moisture.precipMM : (slot.precipMM || 0.0);
            return `${t}°C (Feels ${f}°C) • Rain ${prob}% (${mm}mm)`;
        }
        case "rain": {
            const prob = slot.moisture ? slot.moisture.rainProb : (slot.chanceofrain || 0);
            const mm = slot.moisture ? slot.moisture.precipMM : (slot.precipMM || 0.0);
            const cloud = slot.moisture ? slot.moisture.cloudCover : (slot.cloudcover || 0);
            return `Rain ${prob}% • Precip ${mm}mm • Cloud ${cloud}%`;
        }
        case "wind": {
            const spd = slot.wind ? slot.wind.speedKmph : (slot.windspeedKmph || 0);
            const gst = slot.wind ? slot.wind.gustKmph : (slot.WindGustKmph || "--");
            const dir = slot.wind ? slot.wind.dir16 : (slot.winddir16Point || "N");
            const deg = slot.wind ? slot.wind.degree : (slot.winddirDegree || 0);
            return `${spd} km/h • Gust ${gst} km/h • ${dir} (${deg}°)`;
        }
        case "aqi": {
            const epa = slot.aqi ? slot.aqi.epaIndex : 0;
            const cat = WeatherGlyphs.getAqiCategory(epa);
            const p25 = slot.aqi ? slot.aqi.pm2_5 : 0.0;
            const p10 = slot.aqi ? slot.aqi.pm10 : 0.0;
            return `EPA ${epa} (${cat}) • PM2.5: ${p25} µg/m³ • PM10: ${p10} µg/m³`;
        }
        case "baro": {
            const press = slot.atmosphere ? slot.atmosphere.pressureHpa : (slot.pressure || 1013);
            const vis = slot.atmosphere ? slot.atmosphere.visibilityKm : (slot.visibility || 10);
            return `${press} hPa • Vis ${vis} km`;
        }
        case "uv": {
            const uv = slot.solar ? slot.solar.uvIndex : (slot.uvIndex || 0);
            const tier = (uv <= 2) ? "Low" : (uv <= 5 ? "Moderate" : (uv <= 7 ? "High" : (uv <= 10 ? "Very High" : "Extreme")));
            const rad = slot.solar ? slot.solar.shortRad : 0.0;
            return `UV ${uv} (${tier}) • Solar ${rad} W/m²`;
        }
        default:
            return "--";
    }
}
```

# Phase 54.3: Interactive Multi-Metric Hourly Graph Component - Context

**Gathered:** 2026-10-12T12:06:00+06:00  
**Status:** Ready for planning  

<domain>
## Phase Boundary

Build and deliver the production interactive multi-metric hourly graph component (`WeatherGraph.qml`) deployed in `restow/quickshell/.config/quickshell/ii/modules/ii/bar/weather/WeatherGraph.qml` shadowing upstream via GNU Stow leaf symlinks. The component renders a continuous 25-point rolling timeline (`[-12h .. NOW .. +12h]`) with instant 1-tap switching across all 6 meteorological parameter groups (Thermal, Precipitation, Wind, Air Quality, Atmosphere, Solar/UV) powered by the `Weather.timeline` and `Weather.getSeries()` services delivered in Phase 54.2.

**In scope:**
- Single personal overlay `WeatherGraph.qml` in `restow/quickshell/` inheriting `WeatherBaseCard.qml`.
- Single-row horizontal metric selector tab bar positioned directly beneath the card header with 6 compact icon+label pills (`Temp`, `Rain`, `Wind`, `AQI`, `Baro`, `UV`), fitted evenly across ~416px width with zero horizontal scrolling.
- Accent-filled active pill styling (`colPrimary` background fill + `colOnPrimary` text) with smooth sliding highlight animation (~200ms `expressiveEffects`).
- Instant single Canvas repaint (`requestPaint()`) on tab switch — zero multi-frame animation or transition canvas overhead, preserving the zero-repaint quiescent policy.
- Default to `Temp` (Thermal) tab on popup open.
- Multi-metric Canvas 2D visualizations:
  1. **Thermal:** Dual Monotone Cubic Splines (solid actual temp with vertical gradient fill + dashed feels-like temp); lower bars = rain probability (height) + volume saturation (color deepening > 2.5mm).
  2. **Rain:** Primary spline = rain probability (0–100%); lower bars = precipitation volume columns (mm).
  3. **Wind:** Primary spline = wind speed (km/h); secondary dashed spline = peak gusts (km/h); lower bars = cardinal direction color indicators (N=blue, S=warm, E/W=neutral).
  4. **Air Quality (AQI):** Upper EPA index spline (1–6) color-coded by EPA health tier; lower bars = PM2.5 and PM10 particulate matter concentrations.
  5. **Barometer (Baro):** Upper barometric pressure spline (hPa) with auto-zoomed scaling and 1013.25 hPa reference line; lower bars = horizontal visibility (km).
  6. **Solar (UV):** Upper UV index curve (0–11+) with risk tier color bands; lower bars = daylight intensity/radiation.
- Standardized dual-tier layout across all 6 tabs: Upper ~70% dedicated to continuous spline curves, lower ~30% dedicated to domain-specific context bars.
- Metric-appropriate Y-axis scaling: Dynamic auto-zoom (`[min - 1, max + 1]`) with high/low dotted guidelines for Thermal and Barometer; zero-anchored lower bound (0 km/h, 0%, 0 UV) for Wind, Rain, and UV; fixed 1–6 scale for AQI.
- Semantic Material 3 palette tokens mapped dynamically to Matugen system colors, eliminating conflicting static hex values.
- Unified Y-coordinate calculation helper `getMetricY()` shared symmetrically between `Canvas.onPaint` and `MouseArea.onPositionChanged`, ensuring 0px snap dot divergence.
- Day/Night & Date Boundaries:
  - Translucent nocturnal background bands (10–15% opacity `colLayer1`) behind night slots (`!isDaytime`).
  - Vertical dotted boundary divider (`colOutlineVariant`) at the 00:00 midnight slot with a compact date label (e.g. `"Oct 13"`).
  - Clock timestamps every 3–4 hours (`02:00`, `06:00`, `10:00`, `NOW`, `18:00`, `22:00`), with center index 12 ("NOW") highlighted in `colPrimary`.
  - Mini outline condition glyphs (12px, `fill: 0`, `colOnSurfaceVariant`) above timestamp labels.
- Zero-repaint hover scrub overlay:
  - Context-adaptive floating tooltip pill displaying: `[Time (Relative + Clock + Date)] • [Condition icon] • [Active metric details]`.
  - Dynamic curve tracking snap dot following the active tab's primary curve.
  - Smart vertical flip: Floats above snap dot by default; flips below when $Y < 60\text{px}$ to prevent colliding with the tab pills; horizontally clamped 6px from card edges.
  - Smooth fade-out on cursor exit; static dashed `"NOW"` hairline at index 12 remains visible on Canvas.
- Event-driven repaint gating strictly behind `root.popupActive` and data revisions, guaranteeing idle CPU $\le 1.68\%$.
- Cold-boot past data fallback: Clean curve truncation with subtle muted hatch indicating `"Past data unavailable"` when yesterday's cache is not yet populated.
- Automated assertion test harness `scripts/phase54.3-weather-assert.sh` and zero vendor git churn gate (`arch/dots-hyprland.sh verify --strict`).

**Out of scope:**
- Modifying backend fetcher or `Weather.timeline` schema (completed in Phase 54.2).
- Status bar pill modifications (completed in Phase 54.1).
- Outer popup card assembly, hero header card, atmospheric card, wind compass card, AQI card, astronomy card, and multi-day forecast strip (allocated to Phase 54.4).
- Retiring prototype test files and final GNU Stow integration (allocated to Phase 55).
- Upstream vendor file modifications in `vendor/dots-hyprland` (strictly prohibited).

## Implementation Decisions

### 1. Metric Selector Controls & Layout
- **D-54.3-01:** Single-row horizontal tab bar. Position a dedicated row of 6 compact pills directly beneath the `WeatherBaseCard` header and above the graph canvas. — **Reversibility:** reversible
- **D-54.3-02:** Fitted single-row layout without scrolling. Fit all 6 pills evenly across ~416px usable inner width using 3–4 letter labels (`Temp`, `Rain`, `Wind`, `AQI`, `Baro`, `UV`), 4px spacing, 14px outline icons, and `pixelSize.smallest` bold text, guaranteeing all options are visible at a glance without horizontal scrolling or wrapping. — **Reversibility:** reversible
- **D-54.3-03:** Accent-filled active pill with slide animation. Active pill receives `colPrimary` background fill and `colOnPrimary` text/icon; inactive pills are transparent with `colOnSurfaceVariant`. A sliding highlight rectangle animates between pills on tab change (~200ms `Appearance.animationCurves.expressiveEffects`). — **Reversibility:** reversible
- **D-54.3-04:** Material Symbols outline icons (`fill: 0`). Map pills to standard icons: `thermostat` (Temp), `water_drop` (Rain), `air` (Wind), `eco` (AQI), `speed` (Baro), `wb_sunny` (UV), strictly adhering to dots-hyprland outline aesthetic. — **Reversibility:** reversible
- **D-54.3-05:** Default to Temp (Thermal) on popup open. The graph always defaults to the `Temp` tab on opening, maintaining visual harmony with the top status bar pill and hero card temperature. — **Reversibility:** reversible
- **D-54.3-06:** Instant single-shot Canvas repaint. Tapping a tab pill invokes `requestPaint()` once to redraw the canvas with the new dataset. Zero frame-by-frame animation between datasets to preserve the zero-repaint quiescent policy. — **Reversibility:** costly — animated crossfade requires multi-canvas buffering and continuous redraw churn

### 2. Multi-Metric Visualizations & Chart Types
- **D-54.3-07:** Unified component architecture. Implement all 6 metric visualizations inside a single `WeatherGraph.qml` component driven by internal `activeMetric` state property, preserving a single integration point in `WeatherPopup.qml`. — **Reversibility:** reversible
- **D-54.3-08:** Standardized dual-tier layout across all 6 tabs. Upper ~70% of canvas is reserved for continuous Monotone Cubic Spline (Fritsch-Carlson) curves; lower ~30% is reserved for domain-specific context bars. — **Reversibility:** reversible
- **D-54.3-09:** Thermal tab visualization. Retain established dual-spline design (Phase 54 D-54-14..D-54-19): solid `colPrimary` spline for actual temperature with vertical gradient fill + dashed `colSecondary` spline for feels-like temperature; lower bars = rain probability % with color saturation deepening when volume > 2.5mm. — **Reversibility:** reversible
- **D-54.3-10:** Rain tab visualization. Primary spline = rain probability (0–100%, `colPrimary`); lower bars = precipitation volume in mm (`colSecondary` deepening past 2.5mm). — **Reversibility:** reversible
- **D-54.3-11:** Wind tab visualization. Primary spline = wind speed in km/h (`colPrimary`); secondary dashed spline = peak gusts in km/h (`colSecondary`); lower bars = cardinal direction color indicators (N=blue, S=warm, E/W=neutral). — **Reversibility:** reversible
- **D-54.3-12:** AQI tab visualization. Upper spline = US-EPA index (1–6) color-coded along the curve via `WeatherGlyphs.getAqiColor()`; lower bars = PM2.5 and PM10 particulate matter concentrations. — **Reversibility:** reversible
- **D-54.3-13:** Barometer tab visualization. Upper spline = barometric pressure in hPa with auto-zoomed scaling and a subtle dashed horizontal baseline at 1013.25 hPa; lower bars = visibility in km (0–20km). — **Reversibility:** reversible
- **D-54.3-14:** Solar/UV tab visualization. Upper curve = UV index (0–11+) with risk tier color bands; lower bars = daylight intensity/radiation. — **Reversibility:** reversible
- **D-54.3-15:** Metric-appropriate Y-axis baselines:
  - Thermal & Barometer: dynamic auto-zoom (`[min - 1, max + 1]`) with high/low dotted guidelines.
  - Wind, Rain & UV: lower bound strictly anchored at zero (0 km/h, 0%, 0 UV).
  - AQI: fixed 1–6 discrete scale. — **Reversibility:** reversible

### 3. Palette Tokens & Unified Scaling Architecture
- **D-54.3-16:** Semantic Material 3 palette tokens. Bind curves and bars to M3 theme tokens rather than static hardcoded hex colors, ensuring 100% harmonization with Matugen dynamic wallpaper themes:
  - Temp: `Appearance.colors.colPrimary`
  - Rain: `Appearance.m3colors.m3primary` / `colSecondary`
  - Wind: `Appearance.colors.colTertiary`
  - AQI: Dynamic `WeatherGlyphs.getAqiColor(epaIndex)`
  - Baro: `Appearance.colors.colOutlineVariant` / muted accent
  - UV: Dynamic `colWarning` / `colError` for high tiers, `colPrimary` for low tiers. — **Reversibility:** reversible
- **D-54.3-17:** Unified Y-coordinate scaling helper `getMetricY()`. Centralize all metric curve math into a single helper function in `WeatherGraph.qml`:
  `function getMetricY(metricKey, slotIndex, plotTop, plotBottom)`
  Both `Canvas.onPaint` and `MouseArea.onPositionChanged` call this exact helper, guaranteeing 0px divergence between the rendered spline and the interactive snap dot. — **Reversibility:** reversible
- **D-54.3-18:** Cold-boot past data fallback. Splines draw only through valid non-null points; unpopulated past slots (`isHistoricalUnavailable === true`) show a subtle muted hatch with `"Past data unavailable"` label until the first midnight rollover. — **Reversibility:** reversible

### 4. Interactive Scrub Tooltip & Readout Hierarchy
- **D-54.3-19:** Context-adaptive floating tooltip pill. Floating pill dynamically tailors its readout to the active tab:
  - Common prefix: `[Time]` • `[Condition icon]`
  - Temp tab: `Temp°C (Feels XX°C) • Rain % (XXmm)`
  - Rain tab: `Rain Prob % • Precip Vol mm • Cloud Cover %`
  - Wind tab: `Speed km/h • Gust km/h • Dir 16-point (e.g. NNW 340°)`
  - AQI tab: `EPA Tier Badge • PM2.5: XX µg/m³ • PM10: XX µg/m³`
  - Baro tab: `Pressure hPa • Visibility km`
  - UV tab: `UV Index (Tier) • Solar Rad W/m²` — **Reversibility:** reversible
- **D-54.3-20:** Full temporal context in time tag. Format time clearly as `"NOW (14:00)"` at center, `"-3h (11:00)"` for today, `"Yesterday 22:00 (-16h)"` across midnight, and `"Tomorrow 02:00 (+12h)"`. — **Reversibility:** reversible
- **D-54.3-21:** Dynamic curve tracking snap dot. The snap dot dynamically tracks the active tab's primary curve (Temp, Rain prob, Wind speed, EPA index, Pressure, UV index), colored to match the tab's primary accent stroke, with vertical scrub hairline spanning the full canvas height. — **Reversibility:** reversible
- **D-54.3-22:** Smart vertical flip with horizontal clamping. Tooltip floats above the snap dot by default; flips below when $Y < 60\text{px}$ to prevent clipping against the tab pills; horizontally clamped 6px from card edges. — **Reversibility:** reversible
- **D-54.3-23:** Smooth fade-out on cursor exit. Floating pill, scrub hairline, and snap dot smoothly fade out (~150ms) when mouse leaves bounds; the static dashed `"NOW"` hairline at index 12 remains visible on Canvas for orientation. — **Reversibility:** reversible

### 5. Day/Night Shading & Midnight Date Boundaries
- **D-54.3-24:** Subtle nocturnal background bands. Nighttime slots (`!isDaytime`) receive faint translucent dark background bands (10–15% opacity `colLayer1`) across the full canvas height, giving instant day/night visual intuition. — **Reversibility:** reversible
- **D-54.3-25:** Midnight transition divider with compact date chip. The 00:00 midnight transition is marked with a subtle vertical dotted divider (`colOutlineVariant`) and a compact date label (e.g. `"Oct 13"`). — **Reversibility:** reversible
- **D-54.3-26:** X-axis timestamps every 3–4 hours. Render clock hours (`02:00`, `06:00`, `10:00`, `NOW`, `18:00`, `22:00`), with center index 12 highlighted in `colPrimary` and midnight 00:00 highlighted. — **Reversibility:** reversible
- **D-54.3-27:** Mini outline condition glyphs. Render small outline condition glyphs (12px, `fill: 0`, `colOnSurfaceVariant`) above timestamp labels in a dedicated 16px bottom axis band with clearance below lower bars. — **Reversibility:** reversible

### Reusable Assets
- `Appearance.animationCurves.expressiveEffects`: Standard Bezier easing curve for smooth pill highlight transitions and tooltip fades.
- `Appearance.colors.colLayer2`: Card background surface color.
- `Appearance.colors.colOutlineVariant`: Subtle border and dotted divider stroke.
- `Weather.timeline`: 25-point continuous rolling array with pre-computed `normalizedX`, `isPast`, `isNow`, `isFuture`, `isDaytime`, `isDayBoundary`.
- `Weather.getSeries(metricPath)`: Cached accessor returning `number[25]` for any modeled parameter path (e.g. `"wind.speedKmph"`, `"aqi.epaIndex"`).
- `computeMonotoneSplineControlPoints(points)`: Existing Fritsch-Carlson cubic spline tangent calculation inside `WeatherGraph.qml`.

### Established Patterns
- **Zero-Repaint Scrub Policy:** Canvas 2D renders splines/bars strictly once per data update; scrub hairline, snap dot, and floating tooltip are lightweight QML Items tracking mouse position with 0.0% idle CPU overhead.
- **Event-Driven Gating:** All `Canvas.requestPaint()` calls are gated behind `root.popupActive` to guarantee quiescent CPU $\le 1.68\%$.
- **Material 3 Outline Aesthetic:** All icons strictly use outline styling (`fill: 0`).
- **GNU Stow Leaf Symlinks:** Personal customizations live in `restow/quickshell/` and shadow upstream files without touching `vendor/dots-hyprland`.

### Integration Points
- `restow/quickshell/.config/quickshell/ii/modules/ii/bar/weather/WeatherGraph.qml`: Destination component.

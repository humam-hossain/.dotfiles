### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Mouse interaction events, QML scenegraph rendering pipeline, filesystem symlink boundaries.
- **T-54.3-01: Performance Degradation & Battery Drain via Repaint Storms (ASVS V11 - Availability)**:
  - *Threat*: Mouse hover scrub triggering 60–120Hz Canvas rasterization passes, overwhelming the GPU compositing pipeline and blowing past the idle CPU limit ($\le 1.68\%$).
  - *Mitigation*: Strictly zero Canvas `requestPaint()` calls during pointer tracking; `scrubMouseArea.onPositionChanged` updates only declarative X/Y properties on lightweight QML overlay items (`scrubHairline`, `snapDot`, `tooltipPill`).
- **T-54.3-02: Visual Inconsistency / Snap Dot Divergence (ASVS V11 - Data Integrity)**:
  - *Threat*: Tooltip snap dot deviating from the Canvas spline curve due to disparate scaling formulas or unshared rounding offsets.
  - *Mitigation*: Single source of truth: snap dot `y` is calculated directly by calling `getMetricY(root.activeMetric, idx, plotTop, plotUpperBottom)`, the exact same function that renders the spline path.
- **T-54.3-03: Submodule Churn & Upstream Corruption (ASVS V14 - Integrity)**:
  - *Threat*: Editing upstream files in `vendor/dots-hyprland/` breaking submodule tracking.
  - *Mitigation*: Strictly verify with `arch/dots-hyprland.sh verify --strict` in Section 5.
</threat_model>

### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Execution privileges (`EUID`), repository file boundaries, GNU Stow leaf symlinks, vendor submodule isolation.
- **T-54.3-01: Root Privilege Escalation (ASVS V1 - Principle of Least Privilege)**:
  - *Threat*: Test harness executed as root, causing root-owned temporary files, corrupted permissions in user home, or unauthorized modifications.
  - *Mitigation*: Fail-closed root check at the head of `scripts/phase54.3-weather-assert.sh`: `if [[ "${EUID:-$(id -u)}" -eq 0 ]]; then exit 1; fi`.
- **T-54.3-02: Confidential Secrets Exposure (ASVS V2/V3 - Sensitive Data Protection)**:
  - *Threat*: Test script accidentally grepping, scanning, or dumping credentials from `*rclone.conf*` or environment variables into test output logs.
  - *Mitigation*: Strict project boundary: never reference, glob, or read `*rclone.conf*`. Test script targets only `restow/quickshell/` and public test fixtures.
- **T-54.3-03: Upstream Git Dirty State & Accidental Vendor Churn (ASVS V14 - Integrity)**:
  - *Threat*: Test runs or build tools leaving transient files or staging changes in `vendor/dots-hyprland`.
  - *Mitigation*: Section 5 integrates `arch/dots-hyprland.sh verify --strict` and verifies `git status --porcelain` to reject any upstream submodule drift.
- **T-54.3-04: Denial of Service via Uncontrolled Loop / Headless Runaway (ASVS V11 - Availability)**:
  - *Threat*: Node.js test script hanging indefinitely on malformed input or infinite loop in spline math.
  - *Mitigation*: Node scripts use deterministic bounded iteration over 25 timeline slots and standard assert statements with immediate exit.
</threat_model>

<threat_model>
### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: QML overlay tree inside the weather card, quickshell process lifecycle versus restow file state, assert harness shell execution.
- **T-54.3-05: UAT False-Pass From Stale Quickshell Session (Tampering, medium / ASVS V14 - Integrity)**:
  - *Threat*: Operator visually validates a quickshell process hosting pre-fix QML while believing it current, closing gaps that are still live on screen.
  - *Mitigation*: Harness emits a fail-soft FINDING (never FAIL) whenever the running quickshell start epoch predates the restow graph file mtime, naming the exact restart command; INFO skip when no quickshell process exists (headless CI).
- **T-54.3-06: QML ReferenceError From Partial Chrome Removal (Denial of Service, medium / ASVS V11 - Availability)**:
  - *Threat*: Deleted tab chrome leaves dangling references in highlight bindings, repeater delegates, or reset handlers, throwing at popup open.
  - *Mitigation*: Harness Section 2 asserts absence of every removed chrome identifier and qmlformat parses the file; executor re-greps for remaining references before finishing.
- **T-54.3-SC: Supply-Chain Installs (Tampering, low)**:
  - *Disposition*: accept. This plan installs no npm, pip, or cargo packages; only preinstalled system tools (qmlformat, node, pgrep, stat) are invoked.
</threat_model>

### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: QML Scenegraph FBO rendering, client property binding engine, user interaction surface.
- **T-54.3-01: Resource Exhaustion via Continuous Repaint Churn (ASVS V11 - Availability)**:
  - *Threat*: Inadvertently animating Canvas frames or triggering `requestPaint()` in response to property changes or hover scrubbing, causing high CPU/GPU utilization and battery drain.
  - *Mitigation*: Single-shot `requestPaint()` on tab click (D-54.3-06); all repaints gated behind `root.popupActive` (GRAPH-04); tab highlight animation operates purely on QML Rectangle item geometry with zero canvas paints.
- **T-54.3-02: Scenegraph Crash / Canvas Path Corruption via NaN / Infinity (ASVS V11 - Data Integrity)**:
  - *Threat*: Zero wind speed, zero rainfall, or unpopulated historical data causing division by zero (`range === 0`), yielding `NaN` or `Infinity` in Bezier curve control points, crashing Qt Quick or rendering corrupt visual artifacts.
  - *Mitigation*: Enforce strict positive minimum denominators in `getMetricY()` and bounds helpers: `Math.max(1, rangeT)` for temp, `Math.max(4, rangeP)` for pressure, `Math.max(20, maxSpeed)` for wind, fixed 100 for rain prob, and fixed 5.0 for EPA index per D-54.3-15.
- **T-54.3-03: Upstream Git Dirty State (ASVS V14 - Integrity)**:
  - *Threat*: Altering files directly inside `vendor/dots-hyprland`.
  - *Mitigation*: Changes made strictly to personal overlay `restow/quickshell/.../WeatherGraph.qml`.
</threat_model>

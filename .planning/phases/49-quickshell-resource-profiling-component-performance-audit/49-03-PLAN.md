<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| QML Render Thread → Compositor & Intel GPU | Frame dirtying and shader execution triggered by property animations and canvas points updates |
| Process Stdout Stream (`cava`) → QML Main Thread | ASCII frequency values streamed over standard output parsed on Qt Quick GUI thread |
| Linux procfs / sysfs Polling → Quickshell Background Services | Periodic file read triggers waking Qt Quick event loop and generating syscalls |
| GNU Stow Filesystem Hierarchy (`~/.config/quickshell/ii`) → Repository | Symlinks resolving to `restow/quickshell` leaf files |

## Threat Assessment

| Threat ID | Threat Type | Target | Severity | Mitigation Strategy |
|-----------|-------------|--------|----------|---------------------|
| T-49-09 | Denial of Service / Resource Starvation | GPU render queue & clock frequency | high | De-escalate infinite opacity animation in `NetworkPingPopup.qml` to bounded 3-cycle pulse, allowing compositor surface caching and preventing locked 1550 MHz boost clock. |
| T-49-10 | Denial of Service / UI Freezing | Qt Quick GUI main thread | high | Gate `cava` child process behind active player playback state and throttle SplitParser rate by 3x (frame skipping to 20 FPS), cutting CPU overhead by over 50%. |
| T-49-11 | Performance Degradation | System idle wakeups & syscalls | medium | Relax idle polling intervals in `Voice.qml` (500ms -> 2500ms) and `StorageUsage.qml` (1000ms -> 3000ms) when inactive. |
| T-49-12 | Integrity Violation / Drift | GNU Stow leaf symlinks | high | Confine all modifications strictly to `restow/quickshell/` leaf paths; verify zero drift and pristine vendor submodule via `./arch/dots-hyprland.sh verify --strict`. |
| T-49-13 | Information Disclosure | Confidential credentials | high | Strictly prohibit viewing, parsing, or matching any `rclone.conf` or OAuth token storage files. |
</threat_model>

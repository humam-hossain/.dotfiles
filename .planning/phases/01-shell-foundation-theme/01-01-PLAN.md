<objective>
Bootstrap the Quickshell directory structure by performing a wholesale copy of the dots-hyprland `ii` implementation, establishing the PanelLoader architecture and panel families.
</objective>

## Tasks

<task id="01-01-01">
<title>Wholesale Directory Copy</title>
<read_first>
- .config/quickshell/ (Target directory)
- ../dots-hyprland/dots/.config/quickshell/ii/ (Source of truth)
</read_first>
<action>
1. Remove all existing contents inside `.config/quickshell/` in the dotfiles repo to ensure a clean slate.
2. Recursively copy all files and folders (including hidden files like `.qmlformat.ini`) from `../dots-hyprland/dots/.config/quickshell/ii/` into `.config/quickshell/`.
</action>
<acceptance_criteria>
- `.config/quickshell/shell.qml` exists and contains `import "modules/common"`.
- `.config/quickshell/panelFamilies/IllogicalImpulseFamily.qml` exists.
- The `ls -A .config/quickshell/` output shows `modules`, `services`, `scripts`, `defaults`, `assets`, `panelFamilies`, and `qmldir` files.
</acceptance_criteria>
<verify>
test -f .config/quickshell/shell.qml && test -f .config/quickshell/panelFamilies/IllogicalImpulseFamily.qml && echo "Copy successful"
</verify>
</task>

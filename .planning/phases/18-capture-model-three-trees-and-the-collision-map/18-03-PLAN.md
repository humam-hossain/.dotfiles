<objective>
Make the wrapper refuse the one upstream flag that would void every row of the collision map, and
record in the research document why the refusal exists.

`--exp-files` routes installation through `3.files-exp.sh`, which reads its destinations from a YAML
file rather than from `3.files-legacy.sh` and uses an entirely disjoint set of write primitives — all
of which either destroy a symlink or write through it. Q15 is answered in D-30: the experimental path
is complete and functional, not a stub, and it runs an interactive preference wizard. Refusal is the
correct response, and the refusal has to fire rather than merely be written down.

Purpose: close the one route by which an operator can reach a code path the map does not model.
Output: the gate in `main()`, an end-to-end assert section that proves it fires, and the research
record.
</objective>

    Pass the dry-run meta flag alongside the refused flag in every invocation this section makes. The
    gate sits in `main()`'s prologue and fires before the install family's argument scan ever sees the
    dry-run flag, so a working gate still exits 2 and the check is unchanged. What the flag buys is the
    failure case: if the gate is ever absent or broken, the run falls through to `run_install_family`,
    which would otherwise reach `preflight` and exec upstream's installer against the operator's live
    desktop. With the dry-run flag the fall-through prints its would-exec line and exits 0, which the
    assert reads as a failure on both the exit code and the upstream-invocation checks. An assert whose
    failure mode is a full unattended install of the vendored stack is not an acceptable regression test.

    Under `set -euo pipefail` a bare command substitution of a failing command aborts the assert, so
    write the capture as an assignment with an `|| RC=$?` tail and read the code from that, exactly as
    RESEARCH's example spells it. Initialise the exit-code variable before the call so an unset
    variable cannot satisfy the comparison.

    wrapper's existing failure code; collapsing them would let a `preflight` failure pass as a refusal.

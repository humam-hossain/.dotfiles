<objective>
Prove `capture`'s behaviour end to end against a fixture the assert builds and tears down.

ROADMAP criterion 7 asks for three things from `capture`: it copies live to repo for a `capture/`
fixture, it leaves the staged diff empty, and it refuses any path whose repo mirror is already dirty
against HEAD. The mechanism shipped in plan 18-05; this plan makes it falsifiable.

Two of the refusals would otherwise ship unexercised. The untracked-mirror case is the one the
CONTEXT's original dirty-check command could not detect at all, and the happy-path fixture commits
its own files, so without a deliberate untracked case the defect would ship green. The
live-symlink-into-the-repo refusal has no inhabitant to exercise it until Phase 21 — but the fixture
already controls both sides, so building it is one link.

`capture/` stays legitimately empty when this plan ends. Nothing fixture-shaped is committed.

Purpose: make every `capture` refusal demonstrated rather than asserted.
Output: assert sections 7b and 7c.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fixture `$HOME` → the real `$HOME` | the assert repoints `$HOME` at a temporary directory; a leak of the real one would run `capture` against live config |
| fixture git repository → this repository | the fixture runs real git commands; acting on the wrong repository would stage or modify tracked work |
| fixture temporary tree → tracked tree | a fixture surviving a failing check gets committed by the next `git add -A` |

<objective>
Split the hypr configuration across the two trees exactly where the collision map splits it, link
both halves live, and remove repo-root `.config/` as a second authoring tree.

`hypr` becomes two packages with the same name. The custom overlay directory is reached by a
primitive that short-circuits on the whole destination and leaves the link alone; the hyprland
directory is reached by a sync-with-delete that replaces the link with a regular file on every
install. The tree decides the meaning of the name (D-25), and the map decides the split (D-26).

Two files in this plan are counter-intuitive and both were decided on measured evidence.
`hypridle.conf` and `hyprlock.conf` look like quiet personal config and belong in `restow/`, because
the auto-backup primitive renames the link away on firstrun. `launch_first_available.sh` is one file
three directories deep inside a path the installer fully owns and deletes on every run — path depth
is not a reason to break the rule, and the tag communicates precisely the fact that it is destroyed
on every install until re-stowed.

This plan is repo-side only. It moves files between tracked directories and deletes a tracked
directory; it runs no GNU Stow invocation and creates no symlink under `$HOME`. Live linking for
every package this phase migrates is concentrated in plan 18-11, which runs in the main worktree after
all repo-side moves have merged — including RESEARCH F-2's aside-then-stow procedure and D-51's
closing `verify`. The live session keeps reading its existing plain files throughout this plan.

Purpose: finish placing what the repo-root tree held, then delete the tree.
Output: `stow/hypr/`, `restow/hypr/`, and repo-root `.config/` gone.
</objective>

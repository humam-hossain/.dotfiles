## 2. Core Architectural Patterns to Emulate

### Pattern 1: Declarative Timer Initialization with `Component.onCompleted` Bootstrap
**Target:** `restow/quickshell/.config/quickshell/ii/services/ResourceUsage.qml`  
**Problem Solved:** Eradicates the 60–100Hz `/proc/meminfo` and `/proc/stat` read flood (~3,100 read syscalls/s and 476 context switches/s) caused by imperative `interval = 3000` assignment inside `onTriggered` of an `interval: 1` repeating timer.  
**Analog Source:** `restow/quickshell/.config/quickshell/ii/services/HardwareTelemetry.qml:17-23, 491-494`

In QtQuick/QML, repeating timers do not reliably re-arm their underlying scheduler intervals when mutated inline during their own execution callback. The robust, declarative pattern initializes the timer with its intended cadence and uses `Component.onCompleted` to trigger instantaneous first-frame data acquisition.

#### Code Excerpt: Current Flawed Implementation
```qml
// Flawed implementation in ResourceUsage.qml:74-113
Timer {
    interval: 1
    running: true 
    repeat: true
    onTriggered: {
        fileMeminfo.reload();
        fileStat.reload();
        ...
        root.updateHistories();
        interval = Config?.options?.resources?.updateInterval ?? 3000;
    }
}
```

#### Code Excerpt: Target Robust Implementation (D-02, D-03)
```qml
// Target implementation to be executed in Phase 43.4
property bool isInspectorActive: false

function pollData() {
    fileMeminfo.reload();
    fileStat.reload();

    const textMeminfo = fileMeminfo.text();
    memoryTotal = Number(textMeminfo.match(/MemTotal:\s*(\d+)/)?.[1] ?? 1);
    memoryAvailable = Number(textMeminfo.match(/MemAvailable:\s*(\d+)/)?.[1] ?? 0);
    memoryFree = memoryAvailable;
    memoryBuffers = Number(textMeminfo.match(/Buffers:\s*(\d+)/)?.[1] ?? 0);
    memoryCached = Number(textMeminfo.match(/^Cached:\s*(\d+)/m)?.[1] ?? 0);
    swapTotal = Number(textMeminfo.match(/SwapTotal:\s*(\d+)/)?.[1] ?? 1);
    swapFree = Number(textMeminfo.match(/SwapFree:\s*(\d+)/)?.[1] ?? 0);

    const textStat = fileStat.text();
    const cpuLine = textStat.match(/^cpu\s+(\d+)\s+(\d+)\s+(\d+)\s+(\d+)\s+(\d+)\s+(\d+)\s+(\d+)/);
    if (cpuLine) {
        const stats = cpuLine.slice(1).map(Number);
        const total = stats.reduce((a, b) => a + b, 0);
        const idle = stats[3];

        if (previousCpuStats) {
            const totalDiff = total - previousCpuStats.total;
            const idleDiff = idle - previousCpuStats.idle;
            cpuUsage = totalDiff > 0 ? (1 - idleDiff / totalDiff) : 0;
        }
        previousCpuStats = { total, idle };
    }

    // D-03: Gate history array heap allocations on active inspector demand
    if (root.isInspectorActive) {
        root.updateHistories();
    }
}

Timer {
    id: pollTimer
    interval: root.isInspectorActive ? 1000 : (Config?.options?.resources?.updateInterval ?? 3000)
    running: true
    repeat: true
    onTriggered: root.pollData()
}

Component.onCompleted: {
    root.pollData();
}
```

### Pattern 2: Reference-Counted Demand-Gated Sensor Sweeping
**Target:** `restow/quickshell/.config/quickshell/ii/services/HardwareTelemetry.qml`  
**Problem Solved:** Eliminates 28 unnecessary sysfs file reads every 3 seconds in idle steady-state. The status bar pill only displays 3 metrics (`overallCpuLoad`, `packageTemp`, `gpuLoad`), but 31 files were previously being swept indiscriminately.  
**Analog Source:** Existing `fastPollingRequests` reference counter in `HardwareTelemetry.qml:14-23` and `CpuGpuPopup.qml:15-27`.

The two-tier pattern segregates sensor polling into:
- **Tier 1 (Idle Steady-State / Pill):** Sweeps strictly the 3 files necessary to render the status bar pill at 3000ms cadence.
- **Tier 2 (Active Inspection / Popup):** Sweeps the remaining 28 sensors (14 per-core temps, 2 NVMe, 6 motherboard, thread frequencies, governors) at 1000ms cadence only when `fastPollingRequests > 0`.

#### Code Excerpt: Target Two-Tier Architecture (D-05, D-07, D-08)
```qml
// Target implementation in HardwareTelemetry.qml
property int fastPollingRequests: 0
readonly property bool fastPolling: fastPollingRequests > 0 || overallCpuLoad > 0.50

Timer {
    id: pollTimer
    interval: root.fastPolling ? 1000 : 3000
    repeat: true
    running: true
    onTriggered: {
        // Always sweep Tier 1 (Pill visible metrics)
        pollTier1();

        // Conditionally sweep Tier 2 (Popup inspector metrics)
        if (root.fastPollingRequests > 0) {
            pollTier2();
        }
    }
}

function pollTier1() {
    try { updateCpuLoadTier1(); } catch (e) { console.warn("updateCpuLoadTier1 error:", e); }
    try { updatePackageTempTier1(); } catch (e) { console.warn("updatePackageTempTier1 error:", e); }
    try { updateGpuLoadTier1(); } catch (e) { console.warn("updateGpuLoadTier1 error:", e); }
}

function pollTier2() {
    try { updateFrequencies(); } catch (e) { console.warn("updateFrequencies error:", e); }
    try { updateGovernors(); } catch (e) { console.warn("updateGovernors error:", e); }
    try { updateDetailedGpuMetrics(); } catch (e) { console.warn("updateDetailedGpuMetrics error:", e); }
    try { updateCoreAndPlatformThermals(); } catch (e) { console.warn("updateCoreAndPlatformThermals error:", e); }
}
```

### Pattern 5: Integer Deadband Quantization for Scenegraph Stability
**Target:** `restow/quickshell/.config/quickshell/ii/modules/ii/bar/CpuGpuPopup.qml` & `CpuGpuPill.qml`  
**Problem Solved:** Floating-point sensor noise (e.g., CPU load bouncing between `0.1423` and `0.1429`) forces QtQuick scenegraph nodes to re-layout rectangles, re-generate geometry meshes, and recalculate text bounding boxes every tick.  
**Analog Source:** `restow/quickshell/.config/quickshell/ii/modules/ii/bar/CpuGpuPopup.qml:79, 153` (`Math.round(meterRow.value * 100)`).

Quantizing progress bar normalized values to whole integer percentages (0.01 steps) ensures that visual geometries only update when perceptible changes occur.

#### Code Excerpt: Deadband Quantization (D-11)
```javascript
// Deadband quantization helper
function quantizePercent(rawVal) {
    if (rawVal === undefined || isNaN(rawVal) || rawVal <= 0.0) return 0.0;
    if (rawVal >= 1.0) return 1.0;
    return Math.round(rawVal * 100.0) / 100.0;
}
```

Applied to UI bindings:
```qml
// In CpuGpuPill.qml
ClippedFilledCircularProgress {
    id: cpuCircProg
    value: root.quantizePercent(HardwareTelemetry.overallCpuLoad)
    ...
}

// In CpuGpuPopup.qml ThreadMeter
Rectangle {
    anchors.left: parent.left
    width: parent.width * root.quantizePercent(tMeter.load)
    ...
}
```

## 3. Anti-Patterns & Pitfalls to Avoid

| Anti-Pattern | Manifestation in Baseline | Technical Consequence | Approved Mitigation Pattern |
|---|---|---|---|
| **Timer Interval Mutation in Callback** | `interval: 1` attempting inline `interval = 3000` in `onTriggered`. | Scheduler interval fails to re-arm; timer fires at 60–100Hz continuously, generating 3,120 read syscalls/s. | Initialize `interval` declaratively; use `Component.onCompleted` for instant first-tick data fetch (Pattern 1, D-02). |
| **All-Sensor Polling in Idle** | Sweeping 31 sysfs files every 3s when only 3 metrics are displayed on the bar. | 28 unviewed sysfs reads every 3s, causing context switch churn (+439.4 switches/s). | Two-tier demand-gated sweeping: Tier 1 (3 files) vs Tier 2 (active popup only) (Pattern 2, D-05). |
| **Unguarded Scenegraph Animations** | `popupCriticalPulse` running in background while popup closed. | Drives GPU rendering clock and compositing frame redraws on an invisible item. | Enforce `running: root.active && root.isCritical` on all popup animations (Pattern 4, D-10). |
| **Heap Spread Copying in Unused Histories** | `[...history, val]` appending to arrays on every tick when overlay closed. | Continuous JavaScript garbage collection pressure and heap fragmentation. | Wrap history updates with `if (root.isInspectorActive)` guard (Pattern 1, D-03). |
| **Floating-Point Jitter Invalidation** | Raw `/proc/stat` floating point deltas directly bound to QML item widths. | Sub-pixel geometry invalidations force scenegraph recalculation and canvas repaints. | Quantize to 1% integer deadbands (`Math.round(val * 100) / 100`) (Pattern 5, D-11). |
| **Reference Count Leakage** | `fastPollingRequests` incrementing without corresponding decrement on destruction. | Permanently traps service in high-frequency 1000ms polling mode. | Pair `onActiveChanged` with `Component.onDestruction: if (active) fastPollingRequests--;` (Pattern 2). |
| **Premature Production Source Edits** | Modifying production QML source files during analysis/planning phase. | Violates phase boundaries and risks unverified regression. | Maintain strict read-only boundary during Phase 43.3; execute all code modifications in Phase 43.4. |

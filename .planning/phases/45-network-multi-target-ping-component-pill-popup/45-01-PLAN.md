## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-45-SC | Tampering | Test harness execution | low | mitigate | `scripts/phase45-network-ping-assert.sh` runs with `set -euo pipefail` and fails closed if run as root (`EUID == 0`). |

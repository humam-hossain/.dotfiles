<threat_model>
### ASVS L1 Security & Threat Mitigation
- **T-51-06: GNU Stow Directory Folding Collision (ASVS V11 - Configuration Integrity)**:
  - *Threat*: GNU Stow folding `~/.config/weather` into a directory symlink rather than creating individual leaf file symlinks, causing unmanaged secrets (`.env`) to be placed in the git repository or overwriting repo state.
  - *Mitigation*: Explicit pre-creation of `~/.config/weather` directory in `bootstrap.sh` (`run_stow_step`) before calling `stow --no-folding`. Section 1 of the assertion harness asserts `~/.config/weather` is a real directory (`[[ -d ... && ! -L ... ]]`).
- **T-51-02: Systemd Unit Permissions & Resource Exhaustion (ASVS V1 - Least Privilege)**:
  - *Threat*: Uncontrolled CPU/memory consumption by repeated service invocation or improper file descriptor handling.
  - *Mitigation*: `Nice=19`, `TimeoutStartSec=30s`, `RuntimeDirectory=weather` with `RuntimeDirectoryMode=0755` declared in unit file. Logging directed to journal with `SyslogIdentifier=wwo-fetcher`.
</threat_model>

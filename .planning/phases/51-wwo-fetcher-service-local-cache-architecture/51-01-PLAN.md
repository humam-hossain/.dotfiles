### ASVS L1 Security & Threat Mitigation
- **T-51-01: API Key Leak in Git / Repo Tracking (ASVS V2/V3 - Secret Management)**:
  - *Threat*: Accidental commit of `WWO_API_KEY` to public or shared git repository.
  - *Mitigation*: Strictly gitignore `.config/weather/.env` and `stow/weather/.config/weather/.env`. Provide only `.env.example` with placeholder strings in git. Section 1 of the assertion harness scans repo git index and working tree to fail closed if any live `.env` file or raw key is tracked.
- **T-51-02: Privilege Escalation via Systemd / Root Execution (ASVS V1 - Least Privilege)**:
  - *Threat*: Execution of fetcher or test harness as root compromising filesystem permissions or leaking secrets across user boundaries.
  - *Mitigation*: Fail closed at top of test harness if `EUID == 0`. Ensure units run under user systemd manager (`systemd --user`).
</threat_model>

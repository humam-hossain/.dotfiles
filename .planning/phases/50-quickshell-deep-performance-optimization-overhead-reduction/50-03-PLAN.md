<objective>
Eliminate offscreen multi-pass `OpacityMask` and Gaussian blurs (`StyledBlurEffect`) in `PlayerControl.qml`, downsample `cava` frequency processing to 12–15 FPS, de-escalate wavy slider physics when not hovered, clamp 2D Canvas history graphs in `Graph.qml` to max 10 FPS, decouple `ClockWidgetPopup.qml` from second ticks, cache `StyledPopup` drop shadows in GPU VRAM, and bound critical alert pulses (OPT-02, OPT-04, D-50-03, D-50-04, D-50-05, D-50-06).

Purpose: Drive MediaControls active overlay CPU from 24.58% to <= 10.0% and iGPU load from 25.53% to <= 12.0%, while guaranteeing all 8 interactive popups maintain iGPU load <= 15.0%.
Output: High-efficiency stowed overrides for `PlayerControl.qml`, `Graph.qml`, and `ClockWidgetPopup.qml`, with optimized `MediaControls.qml`, `StyledPopup.qml`, `CpuGpuPopup.qml`, and `MemoryStoragePopup.qml`.
</objective>

<threat_model>
ASVS L1 Threat Model & Mitigations:
- **T-50-05: GPU Resource Exhaustion via Unbounded Render Passes & Shader Loops**
  - Threat: Continuous 60 FPS repaints on Canvas items, infinite pulse animations, and live Gaussian blurs can cause GPU pipeline stalls, high thermal output, and battery drain.
  - ASVS L1 Mapping: V13.1.2 Resource Allocation Limits.
  - Mitigation: Clamping Canvas repainting to max 10 FPS (100ms deadband), de-escalating wavy slider animation to run strictly during active mouse hover, and bounding pulse animations to `loops: 3`.
- **T-50-06: Arbitrary File Ingestion via Media Downloader**
  - Threat: Cover art downloads executing shell commands with arbitrary URLs can lead to command injection or file overwrites.
  - ASVS L1 Mapping: V5.2.2 Output Escaping and Path Traversal.
  - Mitigation: `PlayerControl.qml` removes the `bash -c` wrapper, executing `["curl", "-4", "-sSL", targetFile, "-o", artFilePath]` directly with structured parameters constrained to the user's cache path.
- **T-50-07: Submodule Tree Contamination**
  - Threat: Overriding vendor files by editing `vendor/dots-hyprland/` directly would contaminate submodules and invalidate repository verification.
  - ASVS L1 Mapping: V1.1.2 Secure Supply Chain Integrity.
  - Mitigation: All new overrides (`PlayerControl.qml`, `Graph.qml`, `ClockWidgetPopup.qml`) are authored in `restow/quickshell/` matching upstream directory hierarchy, maintaining pristine submodule state.
</threat_model>

         ```qml
         property real lastPaintTime: 0
         property bool paintPending: false

         Timer {
             id: paintThrottleTimer
             interval: 100
             repeat: false
             onTriggered: {
                 root.paintPending = false;

             if (now - lastPaintTime >= 100) {
                 lastPaintTime = now;

             }
         }
         ```

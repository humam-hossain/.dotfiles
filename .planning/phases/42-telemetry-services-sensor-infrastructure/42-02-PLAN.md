# Plan 42-02: Ping Bridge Daemon & Service & Memory Extensions

<threat_model>
- **Spoofing**: Local API server could be spoofed if bound to public IPs. Mitigated by binding strictly to localhost `127.0.0.1`.
- **Tampering**: Alteration of daemon payload. Mitigated by file permissions.
- **Repudiation**: Non-issue.
- **Information Disclosure**: Pinging external endpoints leaks system network state. Expected behavior of a network monitor. Local JSON endpoint leaks internal targets. Mitigated by localhost restriction.
- **Denial of Service**: Unresponsive ping daemon stalling the UI. Mitigated by asynchronous HTTP requests and D-13 (15s offline backoff).
- **Elevation of Privilege**: Running raw sockets often requires root. Mitigated by using standard ping utilities or rootless daemon capabilities as pre-configured.
</threat_model>

## Objective

Update the Python ping daemon to output clean JSON and create the Quickshell `PingService` and memory extensions to parse telemetry data without blocking the UI. Implements D-12 through D-15.

## Tasks

1.  **Tracer Slice: QML Stubs**:
    - **Action**: Create `PingService.qml` stub and verify target structures in `server.py` and `ResourceUsage.qml`.
    - **Objective**: Establish the file locations for QML extensions and backend modifications.
    - **Tags**: `tracer`

2.  **Ping Daemon API Bridge (D-12, D-13, D-14)**:
    - **Action**: Modify `stow/system_monitor/.config/system_monitor/ping/server.py` and implement `PingService.qml`.
    - **Objective**: Update the `/api/status` endpoint to return structured JSON without HTML tags per D-12. In QML, implement asynchronous 5s polling with 15s offline backoff per D-13, exposing WAN, Gateway, and Home Server metrics per D-14.
    - **Tags**: `D-12`, `D-13`, `D-14`

3.  **Extended Memory Telemetry (D-15)**:
    - **Action**: Extend `ResourceUsage.qml` memory parser.
    - **Objective**: Parse `memoryAvailable`, `memoryBuffers`, and `memoryCached` from `/proc/meminfo` per D-15, making them available for the memory popup inspector.
    - **Tags**: `D-15`

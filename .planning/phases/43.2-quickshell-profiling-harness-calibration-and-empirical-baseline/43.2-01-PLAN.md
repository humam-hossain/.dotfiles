## Objectives

1. Correct the automated UI input dispatcher in `scripts/profile-quickshell.sh` to account for Wayland 2x virtual device coordinate scaling.
2. Implement automated pop-up layer detection via `hyprctl layers` (`quickshell:popup`) to guarantee pop-up is active during active-state sampling.

5. Eliminate synthetic attribution weight calculations in `generate_reports()`, dynamically formatting the executive summary from measured numbers.
6. Verify harness updates with syntax and unit checks.

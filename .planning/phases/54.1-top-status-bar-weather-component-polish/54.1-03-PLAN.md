### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Mouse and pointer input boundary, Quickshell window manager, Hyprland window focus layer, multi-monitor display outputs.
- **T-54.1-08: Accidental Click Bubbling &amp; Action Execution (ASVS V11 - UI Integrity)**:
  - *Threat*: Left or right clicks on the weather pill passing through to Hyprland windows behind the bar or toggling unwanted overview/sidebar modes.
  - *Mitigation*: Capture all buttons with `acceptedButtons: Qt.AllButtons`, `hoverEnabled: true`, and absorb all events with `onPressed: event => event.accepted = true` and `onClicked: event => event.accepted = true` per D-54.1-02.
- **T-54.1-09: Rapid Pointer Traverse Pop-in / Transient Window Churn (ASVS V11 - UI Integrity)**:
  - *Threat*: Fast cursor movements across the top bar accidentally triggering heavy popup inspector instantiation and Canvas spline drawing.
  - *Mitigation*: Strictly enforce `hoverOpenDelayMs: 300` on `WeatherPopup`, so transient cursor sweeps (&lt;300ms) cancel popup activation before any window is rendered per D-54.1-01.
- **T-54.1-10: Multi-Monitor Window Leak / Cross-Screen Anchor Bleed (ASVS V11 - UI Integrity)**:
  - *Threat*: Hovering on Monitor 1 causing popup window placement on Monitor 2 or desynchronizing popup states across monitors.
  - *Mitigation*: Each monitor instantiates its own `WeatherBar` and `WeatherPopup` within its independent `BarContent` scenegraph tree. Popup hover lifecycle is strictly isolated per monitor per D-54.1-35.
</threat_model>

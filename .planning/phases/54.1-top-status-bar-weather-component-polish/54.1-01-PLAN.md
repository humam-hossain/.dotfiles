- **Trust Boundaries**: Local script execution boundary, GNU Stow leaf symlink mappings, Quickshell UI scenegraph, git working tree index.
- **T-54.1-01: Root Privilege Execution (ASVS V1 - Principle of Least Privilege)**:
  - *Threat*: Assert harness executing as root altering ownership or permissions of user configuration files in `~/.config/quickshell/`.
  - *Mitigation*: Fail closed at script startup if `EUID == 0` with exit code 1.
- **T-54.1-02: Double-Padding Layout Snapping / Bar Desynchronization (ASVS V11 - UI Integrity)**:
  - *Threat*: Redundant internal margins (`+ 10 * 2`) in `WeatherBar.qml` combined with `BarGroup` padding causing Center Zone visual blowout and overlapping adjacent Workspaces.
  - *Mitigation*: Bind `implicitWidth` directly to `contentLayout.implicitWidth` in horizontal mode, allowing `BarGroup`'s native 5px padding to govern pill margins per D-54.1-09.
- **T-54.1-03: Submodule Drift & Supply Chain Mutation (ASVS V10 - Integrity)**:
  - *Threat*: Accidental direct mutations to `vendor/dots-hyprland/` breaking submodule tracking and upstream pull workflows.
  - *Mitigation*: Author strictly in `restow/quickshell/` overlay tree. Assert zero modifications in `vendor/dots-hyprland` via `git status --porcelain` and enforce strict zero-drift verification with `./arch/dots-hyprland.sh verify --strict`.
- **T-54.1-04: Secret Leakage (ASVS V2/V3 - Confidentiality)**:
  - *Threat*: Accidental exposure of API tokens or credentials in test logs or stdout.
  - *Mitigation*: STRICT PROHIBITION: Never access `rclone.conf` or `.env`. Assert harness only evaluates public static QML AST properties and leaf symlink targets.
</threat_model>

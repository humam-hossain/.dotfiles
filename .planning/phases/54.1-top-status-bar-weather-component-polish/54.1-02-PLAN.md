### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Local JSON cache parsing boundary, QML property binding engine, Material 3 theme token palette.
- **T-54.1-05: Cold Boot &amp; Malformed Telemetry NaN / Crash (ASVS V5.1 - Input Validation)**:
  - *Threat*: Missing, uninitialized, or unexpected telemetry types (`null`, `undefined`, empty string, string `"--"`) injecting `NaN°C` or causing QML binding crashes.
  - *Mitigation*: Defensive null-coalescing across all bindings (`Math.round(Number(raw))` guarded by `!isNaN` and empty checks, returning `"--°C"` or `"--°"`). Default glyph to `cloud_off` when temperature is unavailable per D-54.1-19, D-54.1-23.
- **T-54.1-06: Stale Alert Visual Alarm Fatigue (ASVS V11 - UI Integrity)**:
  - *Threat*: Cached severe weather alert persisting indefinitely in high-visibility bright red after network loss, alarming the operator with obsolete warnings.
  - *Mitigation*: Check `Weather.isStale || Weather.isOffline` in `alertColor` binding; dim alert symbol to `Appearance.m3colors.m3onSurfaceVariant` when telemetry is stale per D-54.1-22.
- **T-54.1-07: Telemetry Animation Churn &amp; GPU Render Storms (ASVS V11 - UI Integrity)**:
  - *Threat*: Severe alert pulse animation running indefinitely in an infinite loop, burning GPU clocks and causing idle CPU churn.
  - *Mitigation*: Strictly configure `loops: 3` on `alertPulseAnimation`. Reset `alertIcon.opacity` to 1.0 on completion so the icon remains steady at full resting contrast per D-54.1-16.
</threat_model>

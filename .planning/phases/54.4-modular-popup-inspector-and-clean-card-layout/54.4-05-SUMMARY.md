## Decisions Made
- `theme` is drawKind's sixth positional parameter. The plan's "fifth argument" counts the parameters after `ctx`.
- THEME_FALLBACK holds neutral colours used only when no theme is passed. It is an object, so the S3 palette scan does not read it, and it keeps hex out of QML.
- The Now hairline needs `geom.isTimeline25` and more than 12 slots.
- placeLabels uses an explicit index tiebreak so its order is deterministic in QV4 as well as V8.
- On a cramped card, the second coincident label falls back to below-centre (the fourth offset), which the plan specifies.

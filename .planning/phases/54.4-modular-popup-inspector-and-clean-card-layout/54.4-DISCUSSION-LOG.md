## Graph 1 — Temperature

| Option | Description | Selected |
|--------|-------------|----------|
| Labeled curve | Plain smooth spline with labels | |
| Color ramp | Spline stroked with temperature color ramp | ✓ (kept with spline) |
| Feels-like band | Fill band between temp and feels-like | (first chosen, later revised) |

**User's choice:**
- A smooth monotone spline with a fixed ramp: blue ≤20, amber ~28, red ≥34.
- Feels-like revised from a band to a **dashed spline** with no fill.
- Y-axis: 1°C gridlines, labels auto-thinned to 2° when rows are under ~12px apart (options were: auto-thin / always 1° and grow height / always 1° at fixed height).
- Dew point: tooltip only (options were: faint line / tooltip only / drop).
- Ramp source: fixed weather colors (options were: fixed / theme / single accent).
- Time format: "3AM"/"11PM" with "Now" (options were: Now + 3 PM / all clock / 3:00 PM long).

**Notes:**
- Rain bars were first kept in the temp graph, then **removed**: "100% bars would jump over the temperature curves and mm would be tiny."
- A wind-speed x-axis row was proposed by the user, then dropped when wind moved to Graph 2.
- Heat index and wind chill were dropped based on data: both duplicate other series.
- The comfort word is computed from dew point.
- The tooltip was trimmed to 2 lines.

## Layout and sizing

| Option | Description | Selected |
|--------|-------------|----------|
| Stacked, compact | Graphs stacked, shared axis, cards below | |
| Stacked, each own x-axis | Stack with per-graph axes | |
| Two columns | Graphs left, info right | |

**User's choice (free text):**
- Graphs **side by side**: temp left, wind/rain middle, AQI right.
- Non-graph content on **top**, graphs below.
- Popup size dynamic: default 50% of screen width × 50% height.
- Equal widths and heights.
- The user asked whether the popup could be drag-resizable with the size written to config.

**Notes:** Claude listed the issues:
- Thin bars; the mm label moves above the bar.
- A tight x-axis.
- The left gutter needed for alignment.
- Legend wrapping.
- Peak-label collisions.
- Wide tooltips.
- Small screens (minimum ~900px).
- Per-screen sizing.
- The drag-resize problems on a layer-shell PanelWindow.

The user locked:
- Config-driven 50/50 sizing.
- A ~900px minimum width.
- Equal cards.
- Synced hover.
- No drag-resize this phase.

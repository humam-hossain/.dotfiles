## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| config.json to popup | User-editable `popupWidthPercent` / `popupHeightPercent` reach layer-shell surface sizing | Numeric config values (low) |

| harness to verification verdict | Assert scripts decide whether earlier-phase contracts still hold | Verification outcomes (medium) |
| planning docs to verifier | ROADMAP/REQUIREMENTS text is what phase verification grades against | Planning text (low) |
| agent to live desktop session | The phase gate restarts the user's running shell | Session availability (low) |
| UAT to tracked capture mirror | A temporary config edit could be captured into git by the capture timer | Config values (low) |

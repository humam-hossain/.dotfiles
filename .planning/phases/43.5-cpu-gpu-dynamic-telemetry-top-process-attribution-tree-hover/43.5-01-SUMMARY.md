## Accomplishments

1. **Created Wave 0 Assertion Suite (`scripts/phase43.5-dynamic-telemetry-assert.sh`):**
   - Implemented 5 test sections covering static bindings, core topology, hover state machine, process tree engine, and Stow integrity.
   - Added support for `--quick` and `--section` / `-s` flags with fail-closed root guard.

2. **Universal 1000ms Hover Intent Delay (`StyledPopup.qml`):**
   - Added `property int hoverOpenDelayMs: 1000`.
   - Introduced `openTimer` with 1000ms interval triggering `root.shouldBeActive = true` only upon sustained hover.
   - Coordinated `openTimer` and `closeTimer` in `onHoveredChanged` to cancel pending activation if cursor sweeps away, while preserving 200ms grace period across window boundary crossings.

3. **Dynamic Hardware & Core Topology Discovery (`HardwareTelemetry.qml`):**
   - Added dynamic properties: `cpuModelName`, `gpuModelName`, `motherboardModelName`, `isHybridArchitecture`, `pCoreThreadCount`, `eCoreThreadCount`, `totalThreadCount`.
   - Added one-shot `hardwareDiscoveryProc` querying `/proc/cpuinfo`, `lspci -d ::0300`, `/sys/class/dmi/id/`, and `/sys/devices/cpu_atom/cpus`.
   - Updated `updateCpuLoadTier2()` and `updateFrequencies()` to eliminate hardcoded 12/8 divisions and index limits, substituting dynamic thread counts with safe fallbacks for uniform topologies.

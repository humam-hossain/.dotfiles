# Phase 43.5 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Shell execution → HardwareTelemetry | One-shot discovery runs standard system utilities unprivileged | Model strings, core topology |
| Virtual sysfs/procfs → Quickshell | Kernel sysfs and procfs are read unprivileged | CPU stats, DMI product names, DRM fdinfo |
| Quickshell Process → process_tree.sh | Invokes local helper to inspect process hierarchy | Structured JSON telemetry stream |
| process_tree.sh stdout → QML StdioCollector | Consumes JSON data stream in QML engine | JSON process tree structure |

## Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation | Status |
|-----------|----------|-----------|----------|-------------|------------|--------|
| T-43.5-01 | Tampering | hardwareDiscoveryProc | high | mitigate | Pass fixed argument array `["bash", "-c", "..."]` without concatenating untrusted inputs | closed |
| T-43.5-02 | Information Disclosure | sysfs/procfs reads | low | accept | Reading `/proc/cpuinfo` and `/sys/class/dmi/id/` is standard unprivileged kernel ABI | closed |
| T-43.5-03 | Denial of Service | hardwareDiscoveryProc | low | mitigate | Run as one-shot process on startup (`running: true`, no timer) | closed |
| T-43.5-04 | Tampering | Process command invocation | high | mitigate | Command passed as fixed array `[Quickshell.shellPath("scripts/resource-usage/process_tree.sh")]`; no shell string evaluation | closed |
| T-43.5-05 | Information Disclosure | /proc directory traversal | medium | mitigate | Only inspect directory names where name is numeric; do not accept arbitrary path arguments | closed |
| T-43.5-06 | Denial of Service | Process tree execution latency | medium | mitigate | Single-pass shell/awk scan with error guards (`BEGINFILE`) and cached deltas | closed |
| T-43.5-07 | Denial of Service | Process spawning churn | high | mitigate | Strictly gate `procScanTimer.running: root.active`; ensure single running guard | closed |
| T-43.5-08 | Tampering | StdioCollector JSON parsing | medium | mitigate | Wrap `JSON.parse(text)` in try/catch block with fallback to empty arrays | closed |
| T-43.5-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero external package dependencies; uses native Linux utilities and standard libraries | closed |

*Status: open · closed · open — below high threshold (non-blocking)*
*Severity: critical > high > medium > low — only open threats at or above workflow.security_block_on count toward threats_open*

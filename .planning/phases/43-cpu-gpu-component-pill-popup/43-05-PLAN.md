# Plan 43-05: Gap Closure — Telemetry Exception Fix, Per-Core & Motherboard Breakdown, Pill Indicators & Styling

<objective>
Close UAT gaps G-43-1, G-43-4, and G-43-5 by:
1. Fixing the runtime `TypeError: Property 'matchAll' of object ... is not a function` in `HardwareTelemetry.qml` by replacing `String.matchAll` with a standard regex loop (`exec()`). This unblocks `updateGpuMetrics()` and `updateThermals()`, restoring live package temperature (°C), GPU load (%), and per-thread frequencies (MHz).
2. Binding all 6 motherboard platform sensors (`temp1_input` through `temp6_input`) from `gigabyte_wmi` in `HardwareTelemetry.qml`, computing platform average temperature, and computing segregated average temperatures for P-cores and E-cores from `coretemp`.
3. Updating `CpuGpuPill.qml` to use `'sports_esports'` for the GPU icon and adding circular progress indicator rings around both CPU and GPU icons (matching legacy `Resources.qml` circular gauge styling).
4. Updating `CpuGpuPopup.qml` to:
   - Fix container padding so top and left margins match right and bottom margins.
   - Expand the CPU inspector to list all 12 individual P-core threads (C0–C11) and 8 individual E-core threads (C12–C19) with per-thread load progress meters and active MHz clock speeds, alongside P-core and E-core average temperatures.
   - Expand the Motherboard platform section to display all 6 platform sensor temperatures and the average platform temperature.
   - Implement an interactive power-profile / EPP switcher (cycling through `power-saver`, `balanced`, and `performance` via `powerprofilesctl`).
5. Updating assertion scripts, validating strict Stow deployment, and reloading Quickshell (`qs -c ii`).
</objective>

<threat_model>
### ASVS L1 Threat Model Evaluation

- **Unprivileged Runtime Execution:** All file operations occur on sysfs/procfs (`/sys/class/hwmon/`, `/proc/stat`, `/proc/cpuinfo`) and `powerprofilesctl` DBus client as unprivileged user `pera`. No root escalation or setuid execution is required.
- **Exception-Safe Polling Dispatch:** Wrap each polling subsystem in `pollAll()` (`updateCpuLoad`, `updateFrequencies`, `updateGovernors`, `updateGpuMetrics`, `updateThermals`) with individual try/catch blocks so an unexpected error in one telemetry source never halts the rest.
- **QML Type Safety & Memory Bounds:** Iteration over `perThreadLoads` and `threadFrequencies` is bounded strictly to 20 logical threads (12 P + 8 E). List models and repeater items avoid dynamic code evaluation.
</threat_model>

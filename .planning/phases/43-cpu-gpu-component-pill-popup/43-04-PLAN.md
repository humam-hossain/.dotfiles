# Plan 43-04: Gap Closure — Popup Scoping Fix & Bar Placement

<objective>
Close UAT gaps G-43-1 through G-43-6 by:
1. Fixing unqualified identifier resolution in `StyledPopup.qml` under `pragma ComponentBehavior: Bound` by declaring `readonly property Timer closeTimer: Timer { id: closeTimer ... }` and calling `root.closeTimer.stop()` / `root.closeTimer.restart()`, eliminating runtime `ReferenceError: closeTimer is not defined` on mouse hover.
2. Instantiating `CpuGpuPopup` inside `CpuGpuPill.qml` anchored to `root.hoverArea` (`CpuGpuPopup { hoverTarget: root.hoverArea }`), self-encapsulating the popup overlay exactly like upstream `Resources.qml`, `ClockWidget.qml`, and `WeatherBar.qml`.
3. Mounting `CpuGpuPill` in `restow/quickshell/.config/quickshell/ii/modules/ii/bar/BarContent.qml` in the Left Zone, ensuring live CPU load %, package temp, and GPU load % are rendered on the top bar and responsive to mouse hover.
4. Verifying GNU Stow leaf deployment, running the Phase 43 regression test harness, and reloading Quickshell (`qs -c ii`) so that live desktop testing succeeds.
</objective>

<threat_model>
### ASVS L1 Threat Model Evaluation

- **Unprivileged Runtime Execution:** All QML modifications and restow commands execute strictly as non-root user (`pera`, UID 1000). No file permissions or ownership drift occurs.
- **QML Component Scope & Runtime Exceptions:** Under Qt 6 `pragma ComponentBehavior: Bound`, child objects in `LazyLoader` cannot be accessed via unqualified identifiers without throwing `ReferenceError`. Explicitly qualifying property access via `root.closeTimer` guarantees zero runtime exceptions during cursor transit.
- **Layer-shell Surface Stability:** Instantiating `CpuGpuPill` in `BarContent.qml` and anchoring `CpuGpuPopup` uses established `BarGroup` and `StyledPopup` geometry bounds, preventing negative margin overflows or Wayland compositor crashes.
</threat_model>

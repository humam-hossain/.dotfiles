## Context
This plan addresses **G-02-11**. The media controls popup (`MediaControls.qml`) has hard-coded positioning that aligns it to the center-left of the screen for horizontal bars. Since the Media module has been moved to the right side of the bar, the popup needs to be repositioned to appear near the Media module on the right.

## Tasks

### 1. Reposition Media Controls Popup
In `.config/quickshell/modules/ii/mediaControls/MediaControls.qml`:
- Update the horizontal anchor constraints to preserve full vertical/bottom bar positioning while fixing the horizontal bar behavior:
  - Set `anchors.left: Config.options.bar.vertical && !Config.options.bar.bottom`
  - Set `anchors.right: !Config.options.bar.vertical || Config.options.bar.bottom`
- Update the `margins`:
  - Change the horizontal bar margins. Instead of calculating a complex left margin based on screen width and widget width, set a sensible right margin.
  - E.g., `right: !Config.options.bar.vertical ? (Appearance.sizes.barHeight * 4) : Appearance.sizes.barHeight` (adjust multiplier to roughly align with the Media module on the right).
  - Simplify the `left` margin for horizontal layouts since it is no longer anchored to the left. For vertical layouts, preserve the existing `Appearance.sizes.barHeight` logic.

## Verification
- Click the Media module on the bar (horizontal layout).
- Verify the MediaControls popup appears on the right side of the screen, underneath/near the Media module.
- (Optional if easily testable) Verify vertical bar layout still displays the popup correctly on the left/bottom.

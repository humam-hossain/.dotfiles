### 1. Timeline Window & NOW Resolution
- **D-54.2-01:** Floor to current completed hour. At 14:35, NOW snaps to 14:00 (index 12). Past spans [02:00 .. 13:00] (12 slots), NOW is 14:00, and Future spans [15:00 .. 02:00 tomorrow] (12 slots), forming an exact 25-point hourly grid.
- **D-54.2-02:** Preserve 25-point fixed array with placeholder fallback. On cold boot or missing historical cache, the array always has length 25; unpopulated past slots carry null/fallback values with `isHistoricalUnavailable: true`, guaranteeing graph layout and center hairline never jump or shift.
- **D-54.2-03:** 24h clock with date boundary metadata. Slot time labels are formatted as `"HH:00"` (e.g. `"02:00"`, `"14:00"`) with explicit `"Now"` label at center index 12, plus `dayOffset` (-1, 0, +1) and `isDayBoundary` booleans for midnight boundary chips.
- **D-54.2-04:** Top-of-hour event trigger via minute timer. `Weather.qml` checks wall clock hour on a 60-second tick (or calculates delay to next exact hour); when the hour rolls over (e.g., 14:59 to 15:00), it slides the 25-point window immediately without waiting for `wwo-fetcher.py`.
- **D-54.2-05:** Strict system local timezone anchoring. Timeline indexing and slot timestamps anchor strictly to machine local timezone via Qt/JS `Date`, matching system tray clock and status bar times.
- **D-54.2-06:** Pre-index multi-day slots by ISO datetime key `"YYYY-MM-DDTHH:00"`. `Weather.qml` normalizes hourly slots from yesterday (`history`), today (`weather[0]`), and tomorrow (`weather[1]`) into a local datetime map for instant O(1) slot resolution across day boundaries.
- **D-54.2-07:** Expose pre-computed geometry & bounds metadata. Each slot includes `index`, `normalizedX` (0.0 to 1.0, with NOW at 0.5), `isPast`, `isNow`, `isFuture`; `Weather` exposes top-level `tempBounds: { min, max }` and `rainBounds: { maxProb, maxMM }` for zero-overhead Canvas rendering.
- **D-54.2-08:** Explicit `isDaytime` boolean on each slot. Derived from WWO `isdaytime` and astronomy sunrise/sunset times, enabling Canvas to draw day/night background bands and correct day/night condition icons.

### 2. Historical Cache & Rollover Architecture
- **D-54.2-09:** Unified envelope in `weather.json`. `wwo-fetcher.py` embeds a top-level `"history"` key directly into `weather.json` and `last_known_weather.json`; `Weather.qml` reads a single atomic file with zero multi-file race conditions or extra `FileView` instances.
- **D-54.2-10:** Dynamic date transition check on fetch. When `wwo-fetcher.py` fetches fresh data, if the calendar date has advanced, it promotes previous `weather[0]` into `history` and retains up to 24h of past hourly slots before saving. Works automatically across reboots, sleep, and system pauses at 0 additional API cost.
- **D-54.2-11:** 24 hours of history retention. Retains complete previous day forecast/observations (~15–20 KB JSON); guarantees 100% coverage for the `[-12h]` past window even at 00:05 AM immediately following midnight rollover.
- **D-54.2-12:** Unconditional history preservation during error/offline states. Error envelopes copy `history` from previous cache alongside `data`, allowing `Weather.qml` to render the full 25-point timeline seamlessly in stale mode without data loss.
- **D-54.2-13:** Top-level peer key `"history"` schema. Structure as an array of day objects: `"history": [ { "date": "YYYY-MM-DD", "hourly": [...] } ]`. Keeps raw `data` untouched for 100% backward compatibility with Phase 51/52/53 consumers.
- **D-54.2-14:** Cold-boot restoration of both `data` and `history`. When `ensure_fallback_cache` runs on cold boot, copy both `data` and `history` from persistent mirror to tmpfs with `is_stale: true`, so Quickshell boots instantly with a complete 25-point timeline before network initializes.
- **D-54.2-15:** Multi-day downtime invalidation. If machine was offline for multiple calendar days (`cached_date < yesterday`), set `history: []` to prevent misleading 3-day-old telemetry from masquerading as yesterday's weather; timeline uses standard placeholder fallbacks.

## Architecture Patterns

### 1. 0-Cost Midnight Rollover & Unified Cache Envelope (`wwo-fetcher.py`)

In the existing Phase 51 architecture, `wwo-fetcher.py` atomic write creates `weather.json` with keys `["status", "fetched_at", "fetched_epoch", "is_stale", "error", "quota", "data"]` [VERIFIED: live `weather.json` inspection].

Phase 54.2 extends this with a peer top-level key `"history"`:
```json
{
  "status": "ok",
  "fetched_at": "2026-10-11T20:43:53+06:00",
  "fetched_epoch": 1791730033,
  "is_stale": false,
  "error": null,
  "quota": { ... },
  "data": { ...raw WWO payload with weather[0..2]... },
  "history": [
    {
      "date": "2026-10-10",
      "astronomy": [ ... ],
      "hourly": [ ...25 slots from yesterday... ]
    }
  ]
}
```

#### Rollover State Machine
Before performing a network fetch or when handling errors, `wwo-fetcher.py` loads the existing cache envelope from `cache_path` or `persist_path` [VERIFIED: stow/weather/.config/weather/wwo-fetcher.py:364-379].

Upon successful fetch of `new_wwo_data`:
1. Extract `new_date_str = new_wwo_data.get("weather", [{}])[0].get("date")` (e.g. `"2026-10-11"`).
2. Extract `prev_date_str = prev_weather_0.get("date")` and `prev_history = prev_cache.get("history", [])`.
3. Compute calendar day difference: `day_diff = (new_date - prev_date).days`.
   - **`day_diff == 1` (Midnight Rollover):** Calendar date advanced by exactly 1 day. Promote `prev_weather_0` directly to `history = [ prev_weather_0 ]`. Previous day's 24 hours of hourly data are retained at zero API cost!
   - **`day_diff == 0` (Same Day Update):** Retain existing history entry if its date matches `yesterday_str` (`history = [ h for h in prev_history if h.get("date") == yesterday_str ]`).
   - **`day_diff > 1` (Multi-Day Downtime Invalidation):** Machine was offline/sleeping across multiple calendar days. Old telemetry must not masquerade as yesterday; reset `history = []`.
   - **No previous cache:** Set `history = []`.
4. During network exception / offline mode: unconditionally copy `history` from previous cache: `"history": prev_cache.get("history", [])` alongside `data`.
5. In `ensure_fallback_cache()`: cold-boot restoration copies `"history"` from `persist_path` to `cache_path`, validating that if `cached_date < yesterday`, `history` is set to `[]`.

```
                   +------------------------+
                   |  wwo-fetcher.py starts |
                   +-----------+------------+
                               |
               Load prev_cache (runtime / state)
                               |
                  Fetch fresh data from API
                               |
            +------------------+------------------+
            | Success                             | Exception
            v                                     v
 Compute day_diff (new - prev)           Copy existing history:
  - 1 day  -> history = [prev_w0]        envelope["history"] = prev_hist
  - 0 days -> keep valid yesterday       envelope["is_stale"] = True
  - >1 day -> history = [] (stale)                |
            |                                     |
            +------------------+------------------+
                               |
            Atomic write to weather.json & persistent mirror
```

### 2. Continuous 25-Point Rolling Timeline Model (`Weather.qml`)

`Weather.qml` models the 25-point timeline window anchored to current local completed hour `[-12h .. NOW .. +12h]`.

#### Coordinate & Geometry Layout
```
Slot Index:     0    1    2    ...   11    12   13    ...   23   24
Time Offset:  -12h -11h -10h   ...  -1h   NOW  +1h    ... +11h +12h
Normalized X:  0.0  0.04 0.08  ...  0.46  0.5  0.54   ... 0.96 1.00
Role:         [------- PAST (12) -------] [NOW] [----- FUTURE (12) ----]
```

- Array length is invariant: **always exactly 25 slots** (`root.timeline.length === 25`).
- `normalizedX`: strictly `index / 24.0`. Index 12 is at exactly `0.5` (center hairline).
- Local system timezone anchoring: Derived using native `new Date()` [VERIFIED: 54.2-CONTEXT.md:45].
- Multi-day ISO datetime index map: Ingests `history` (yesterday) and `raw.weather[0..2]` (today, tomorrow, day+2) into `slotMap["YYYY-MM-DDTHH:00"]`.
- WWO Time Key Normalization: WWO returns hourly slot strings `"0"`, `"100"`, ..., `"2300"`, plus daily summary slot `"24"`.
  - Filter rule: `if (h.time === "24" || h.time === 24) continue;`
  - Hour extraction: `const hourNum = Math.floor(parseInt(h.time, 10) / 100);`
  - ISO key: `${d}T${String(hourNum).padStart(2, '0')}:00`.
- Missing Past History Fallback: If `slotMap[targetKey]` is missing for past slots (`index < 12`), populate slot with `isHistoricalUnavailable: true`, safe null/0 fallbacks, preserving layout geometry.
- Live NOW Blending (index 12):
  - Primary readings from `current_condition[0]`: `tempC`, `feelsLikeC`, `humidity`, `pressureHpa`, `visibilityKm`, `windKmph`, `windDir`, `windDegree`, `uvIndex`, `isDaytime`, `glyph`, `desc`.
  - Observed precipitation: `slot.moisture.precipMM = parseFloat(cur.precipMM) || 0.0`.
  - Forecast rain probability: `slot.moisture.rainProb = parseInt(forecastSlot.chanceofrain) || 0`.
  - Explicit labels: `timeLabel: "Now"`, `fullTimeLabel: "Now (14:00)"`, `observationTime: cur.observation_time`.

### 4. Memoized Series Getter (`Weather.getSeries`)

`Weather.getSeries(metricPath)` provides Canvas 2D render loops with an instantaneous `number[25]` array without runtime garbage collection churn [VERIFIED: 54.2-CONTEXT.md:62].

```javascript
// restow/quickshell/.../Weather.qml
property var _seriesCache: ({})
property int _timelineRevision: 0

function getSeries(metricPath) {
    if (!metricPath || root.timeline.length !== 25) return [];
    if (root._seriesCache[metricPath]) return root._seriesCache[metricPath];

    const parts = metricPath.split(".");
    const series = new Array(25);

    for (let i = 0; i < 25; ++i) {
        const slot = root.timeline[i];
        let val = null;
        if (parts.length === 2) {
            val = slot[parts[0]]?.[parts[1]];
        } else if (parts.length === 1) {
            val = slot[metricPath] ?? slot.thermal?.[metricPath] ?? slot.moisture?.[metricPath];
        }
        series[i] = (val !== null && val !== undefined && !isNaN(val)) ? Number(val) : (parts[0] === "thermal" ? null : 0);
    }

    root._seriesCache[metricPath] = series;
    return series;
}
```
Whenever `rebuildTimeline()` runs, `root._seriesCache = ({})` and `root._timelineRevision++` invalidates all cached series arrays.

### 5. Top-of-Hour Synchronization (`Weather.qml`)

Wall clock hours roll over at `:00:00`. The timeline window must slide immediately without waiting for `wwo-fetcher.py` (which runs on 15–20 min timer) [VERIFIED: 54.2-CONTEXT.md:43].

`Weather.qml` tracks `property int activeTimelineHour: -1`.
On every trigger of `fallbackTimer` (60s tick) OR when cache reloads:
```javascript
const currentHour = (new Date()).getHours();
if (currentHour !== root.activeTimelineHour) {
    root.rebuildTimeline();
}
```
This slides the 25-point timeline window within at most 60s of the clock rollover, or immediately when `rebuildTimeline()` runs.

## Common Pitfalls

### Pitfall 1: WWO `"time": "24"` Daily Summary Slot
**Risk:** When `fx24=yes` is passed in API parameters, WWO prepends an extra item to `hourly` with `"time": "24"`. If not filtered, `hourly` has 25 items instead of 24. Index 0 would be the daily summary (temp 34°C, uv 8) masquerading as midnight!  
**Verification:** Filter out `h.time === "24" || h.time === 24` before indexing into `slotMap`. Assert that every day produces exactly 24 hourly slots (`0` through `2300`). [VERIFIED: live `weather.json` test].

### Pitfall 2: JavaScript String Concatenation Bugs
**Risk:** WWO JSON values are strings: `"tempC": "28"`, `"chanceofrain": "50"`. In JavaScript, `"28" + 2` is `"282"`, which breaks Canvas spline and bar coordinate calculations.  
**Verification:** Parse all metrics explicitly with `Number()`, `parseInt()`, or `parseFloat()`. Verify via Node.js AST tests in `scripts/phase54.2-weather-assert.sh`. [VERIFIED: 54.2-CONTEXT.md:61].

### Pitfall 3: JavaScript `Math.min(null, 25)` evaluates to `0`
**Risk:** When past slots are unpopulated (`isHistoricalUnavailable: true`), `tempC` is `null`. In JavaScript, `Number(null)` is `0`, and `Math.min(null, 25)` evaluates to `0`! This would artificially plunge minimum temperature bounds to freezing (0°C) during summer months!  
**Verification:** Filter out `null` and non-numbers before evaluating `tempBounds`:
```javascript
const validTemps = root.timeline
    .map(s => s.thermal.tempC)
    .filter(t => typeof t === "number" && !isNaN(t) && t !== null);
const minT = validTemps.length ? Math.min(...validTemps) : 0;
const maxT = validTemps.length ? Math.max(...validTemps) : 0;
```

### Pitfall 4: Missing Rain Probability at NOW (Index 12)
**Risk:** `current_condition` contains live telemetry (`temp_C`, `precipMM`, `humidity`, etc.) but does NOT contain forecast rain probability (`chanceofrain`). If index 12 only copied `current_condition`, `slot.moisture.rainProb` would be 0 or missing.  
**Verification:** Hybrid blend at index 12: copy observed `precipMM` from `current_condition`, and forecast `rainProb` from the corresponding hourly forecast slot. [VERIFIED: 54.2-CONTEXT.md:67].

### Pitfall 5: Stale Series Cache on Hour Rollover
**Risk:** If `Weather.getSeries()` memoizes arrays and the timeline slides at top of hour, returning the old cached array would produce stale graph curves.  
**Verification:** Clear `_seriesCache = ({})` inside `rebuildTimeline()` whenever a new timeline is built. [VERIFIED: 54.2-CONTEXT.md:72].

### Pitfall 6: Submodule Git Churn
**Risk:** Touching `vendor/dots-hyprland` violates repository integrity.  
**Verification:** Assert `git status --porcelain vendor/dots-hyprland` is empty and `./arch/dots-hyprland.sh verify --strict` exits 0. [VERIFIED: arch/dots-hyprland.sh verify --strict: FAIL=0 FINDINGS=0].

### 1. Python Rollover & Multi-Day Downtime Logic (`wwo-fetcher.py`)

```python
# stow/weather/.config/weather/wwo-fetcher.py

def resolve_history_rollover(prev_cache: dict | None, new_wwo_data: dict) -> list:
    """
    Computes top-level history array based on calendar date difference.
    0-cost promotion of previous day's weather[0] upon midnight rollover.
    Invalidates history (returns []) if offline for >1 calendar day.
    """
    if not prev_cache:
        return []

    new_weather = new_wwo_data.get("weather", [])
    if not new_weather:
        return []
    new_date_str = new_weather[0].get("date")

    prev_data = prev_cache.get("data") or {}
    prev_weather = prev_data.get("weather", [])
    prev_weather_0 = prev_weather[0] if prev_weather else None
    prev_date_str = prev_weather_0.get("date") if prev_weather_0 else None
    prev_history = prev_cache.get("history", [])

    if not new_date_str:
        return []

    try:
        new_d = datetime.strptime(new_date_str, "%Y-%m-%d").date()
        yesterday_str = (new_d - timedelta(days=1)).strftime("%Y-%m-%d")

        if prev_date_str:
            prev_d = datetime.strptime(prev_date_str, "%Y-%m-%d").date()
            day_diff = (new_d - prev_d).days

            if day_diff == 1:
                # Midnight rollover: promote yesterday's day object into history
                return [prev_weather_0]
            elif day_diff == 0:
                # Same day: retain valid yesterday entry from existing history
                return [h for h in prev_history if h.get("date") == yesterday_str]
            else:
                # Multi-day downtime (>1) or clock anomaly (<0): invalidate cleanly
                return []
        elif prev_history:
            # Fallback check on existing history
            return [h for h in prev_history if h.get("date") == yesterday_str]
    except Exception:
        return []

    return []
```

// restow/quickshell/.config/quickshell/ii/services/Weather.qml

property var timeline: []
property var tempBounds: ({ min: 0, max: 0 })
property var rainBounds: ({ maxProb: 0, maxMM: 0 })
property int activeTimelineHour: -1
property var _seriesCache: ({})
property int _timelineRevision: 0

function rebuildTimeline() {
    const now = new Date();
    const nowHour = now.getHours();
    root.activeTimelineHour = nowHour;

    const payload = root.activePayload; // from loadCache()
    const raw = payload?.data || {};
    const cur = raw.current_condition?.[0] || {};

    // 1. Ingest multi-day slots into slotMap by ISO key "YYYY-MM-DDTHH:00"
    const slotMap = {};

    function ingestHourly(dayDate, hourlyArray) {
        if (!dayDate || !Array.isArray(hourlyArray)) return;
        for (let i = 0; i < hourlyArray.length; ++i) {
            const h = hourlyArray[i];
            if (h.time === "24" || h.time === 24) continue; // Skip WWO 24h summary
            const hr = Math.floor(parseInt(h.time, 10) / 100);
            const hrStr = ("0" + hr).slice(-2);
            slotMap[`${dayDate}T${hrStr}:00`] = h;
        }
    }

    if (Array.isArray(payload?.history)) {
        for (let i = 0; i < payload.history.length; ++i) {
            ingestHourly(payload.history[i].date, payload.history[i].hourly);
        }
    }
    if (Array.isArray(raw.weather)) {
        for (let i = 0; i < raw.weather.length; ++i) {
            ingestHourly(raw.weather[i].date, raw.weather[i].hourly);
        }
    }

    // 2. Build exactly 25 slots [-12h .. NOW .. +12h]
    const slots = new Array(25);
    const validTemps = [];
    let maxRainProb = 0;
    let maxRainMM = 0.0;

    const nowMidnight = new Date(now.getFullYear(), now.getMonth(), now.getDate()).getTime();

    for (let i = 0; i < 25; ++i) {
        const offset = i - 12;
        const d = new Date(now.getFullYear(), now.getMonth(), now.getDate(), nowHour + offset, 0, 0, 0);
        const yr = d.getFullYear();
        const mo = ("0" + (d.getMonth() + 1)).slice(-2);
        const da = ("0" + d.getDate()).slice(-2);
        const hr = d.getHours();
        const hrStr = ("0" + hr).slice(-2);
        const dateStr = `${yr}-${mo}-${da}`;
        const isoKey = `${dateStr}T${hrStr}:00`;

        const isPast = (i < 12);
        const isNow = (i === 12);
        const isFuture = (i > 12);
        const normalizedX = Number((i / 24.0).toFixed(4));

        const dMidnight = new Date(yr, d.getMonth(), d.getDate()).getTime();
        const dayOffset = Math.round((dMidnight - nowMidnight) / 86400000);
        const isDayBoundary = (hr === 0);

        const rawSlot = slotMap[isoKey] || null;
        const isHistoricalUnavailable = isPast && !rawSlot;

        // Condition & Daytime
        let isDay = (rawSlot?.isdaytime === "yes" || rawSlot?.isdaytime === true || rawSlot?.isdaytime === 1 || rawSlot?.isdaytime === "1");
        if (rawSlot?.isdaytime === undefined) isDay = (hr >= 6 && hr < 18);
        if (isNow && cur.isdaytime !== undefined) isDay = (cur.isdaytime === "yes" || cur.isdaytime === true || cur.isdaytime === 1);

        const wCode = isNow ? (cur.weatherCode || rawSlot?.weatherCode || "") : (rawSlot?.weatherCode || "");
        const glyph = isHistoricalUnavailable ? "cloud_off" : WeatherGlyphs.getGlyph(wCode, isDay);
        const desc = isNow ? (cur.weatherDesc?.[0]?.value || rawSlot?.weatherDesc?.[0]?.value || "Clear") : (rawSlot?.weatherDesc?.[0]?.value || (isHistoricalUnavailable ? "No Data" : "Clear"));

        // Domain Metrics Parsing
        let tempVal = null;
        let feelsVal = null;
        let dewVal = null;
        let heatVal = null;
        let chillVal = null;

        let precipMM = 0.0;
        let rainProb = 0;
        let humidity = 0;
        let cloudCover = 0;
        let snowProb = 0;
        let thunderProb = 0;

        let speedKmph = 0;
        let gustKmph = 0;
        let windDeg = 0;
        let windDir16 = "--";

        let epaIndex = 0;
        let pm2_5 = 0.0;
        let pm10 = 0.0;
        let co = 0.0;
        let no2 = 0.0;
        let o3 = 0.0;
        let so2 = 0.0;
        let defra = 0;

        let press = 0;
        let visib = 0;
        let uv = 0;
        let shortRad = 0.0;
        let diffRad = 0.0;

        if (isNow) {
            // Live condition reconciliation for index 12 (NOW)
            tempVal = !isNaN(parseInt(cur.temp_C)) ? parseInt(cur.temp_C) : null;
            feelsVal = !isNaN(parseInt(cur.FeelsLikeC)) ? parseInt(cur.FeelsLikeC) : null;
            dewVal = !isNaN(parseInt(rawSlot?.DewPointC)) ? parseInt(rawSlot?.DewPointC) : null;
            heatVal = !isNaN(parseInt(rawSlot?.HeatIndexC)) ? parseInt(rawSlot?.HeatIndexC) : null;
            chillVal = !isNaN(parseInt(rawSlot?.WindChillC)) ? parseInt(rawSlot?.WindChillC) : null;

            precipMM = parseFloat(cur.precipMM) || 0.0;
            rainProb = parseInt(rawSlot?.chanceofrain) || 0; // Hybrid blend
            humidity = parseInt(cur.humidity) || 0;
            cloudCover = parseInt(cur.cloudcover) || 0;

            speedKmph = parseInt(cur.windspeedKmph) || 0;
            gustKmph = parseInt(rawSlot?.WindGustKmph) || speedKmph;
            windDeg = parseInt(cur.winddirDegree) || 0;
            windDir16 = cur.winddir16Point || "N";

            const aq = cur.air_quality || rawSlot?.air_quality || {};
            epaIndex = parseInt(aq["us-epa-index"]) || 0;
            pm2_5 = parseFloat(aq.pm2_5) || 0.0;
            pm10 = parseFloat(aq.pm10) || 0.0;
            co = parseFloat(aq.co) || 0.0;
            no2 = parseFloat(aq.no2) || 0.0;
            o3 = parseFloat(aq.o3) || 0.0;
            so2 = parseFloat(aq.so2) || 0.0;
            defra = parseInt(aq["gb-defra-index"]) || 0;

            press = parseInt(cur.pressure) || 0;
            visib = parseInt(cur.visibility) || 0;
            uv = parseInt(cur.uvIndex) || 0;
        } else if (rawSlot) {
            tempVal = !isNaN(parseInt(rawSlot.tempC)) ? parseInt(rawSlot.tempC) : null;
            feelsVal = !isNaN(parseInt(rawSlot.FeelsLikeC)) ? parseInt(rawSlot.FeelsLikeC) : null;
            dewVal = !isNaN(parseInt(rawSlot.DewPointC)) ? parseInt(rawSlot.DewPointC) : null;
            heatVal = !isNaN(parseInt(rawSlot.HeatIndexC)) ? parseInt(rawSlot.HeatIndexC) : null;
            chillVal = !isNaN(parseInt(rawSlot.WindChillC)) ? parseInt(rawSlot.WindChillC) : null;

            precipMM = parseFloat(rawSlot.precipMM) || 0.0;
            rainProb = parseInt(rawSlot.chanceofrain) || 0;
            humidity = parseInt(rawSlot.humidity) || 0;
            cloudCover = parseInt(rawSlot.cloudcover) || 0;
            snowProb = parseInt(rawSlot.chanceofsnow) || 0;
            thunderProb = parseInt(rawSlot.chanceofthunder) || 0;

            speedKmph = parseInt(rawSlot.windspeedKmph) || 0;
            gustKmph = parseInt(rawSlot.WindGustKmph) || 0;
            windDeg = parseInt(rawSlot.winddirDegree) || 0;
            windDir16 = rawSlot.winddir16Point || "N";

            const aq = rawSlot.air_quality || {};
            epaIndex = parseInt(aq["us-epa-index"]) || 0;
            pm2_5 = parseFloat(aq.pm2_5) || 0.0;
            pm10 = parseFloat(aq.pm10) || 0.0;
            co = parseFloat(aq.co) || 0.0;
            no2 = parseFloat(aq.no2) || 0.0;
            o3 = parseFloat(aq.o3) || 0.0;
            so2 = parseFloat(aq.so2) || 0.0;
            defra = parseInt(aq["gb-defra-index"]) || 0;

            press = parseInt(rawSlot.pressure) || 0;
            visib = parseInt(rawSlot.visibility) || 0;
            uv = parseInt(rawSlot.uvIndex) || 0;
            shortRad = parseFloat(rawSlot.shortRad) || 0.0;
            diffRad = parseFloat(rawSlot.diffRad) || 0.0;
        }

        if (tempVal !== null) validTemps.push(tempVal);
        if (feelsVal !== null) validTemps.push(feelsVal);
        if (rainProb > maxRainProb) maxRainProb = rainProb;
        if (precipMM > maxRainMM) maxRainMM = precipMM;

        slots[i] = {
            index: i,
            normalizedX: normalizedX,
            isPast: isPast,
            isNow: isNow,
            isFuture: isFuture,
            dayOffset: dayOffset,
            isDayBoundary: isDayBoundary,
            isHistoricalUnavailable: isHistoricalUnavailable,
            isDaytime: isDay,
            timeLabel: isNow ? "Now" : `${hrStr}:00`,
            fullTimeLabel: isNow ? `Now (${hrStr}:00)` : `${hrStr}:00`,
            hour: hr,
            date: dateStr,
            isoKey: isoKey,
            weatherCode: wCode,
            glyph: glyph,
            desc: desc,
            observationTime: isNow ? (cur.observation_time || "") : "",

            thermal: {
                tempC: tempVal,
                feelsLikeC: feelsVal,
                dewPointC: dewVal,
                heatIndexC: heatVal,
                windChillC: chillVal
            },
            moisture: {
                precipMM: precipMM,
                rainProb: rainProb,
                humidity: humidity,
                cloudCover: cloudCover,
                snowProb: snowProb,
                thunderProb: thunderProb
            },
            wind: {
                speedKmph: speedKmph,
                gustKmph: gustKmph,
                degree: windDeg,
                dir16: windDir16
            },
            aqi: {
                epaIndex: epaIndex,
                pm2_5: pm2_5,
                pm10: pm10,
                co: co,
                no2: no2,
                o3: o3,
                so2: so2,
                defraIndex: defra
            },
            atmosphere: {
                pressureHpa: press,
                visibilityKm: visib
            },
            solar: {
                uvIndex: uv,
                shortRad: shortRad,
                diffRad: diffRad
            }
        };
    }

    root.timeline = slots;
    root.tempBounds = {
        min: validTemps.length ? Math.min(...validTemps) : 0,
        max: validTemps.length ? Math.max(...validTemps) : 0
    };
    root.rainBounds = {
        maxProb: maxRainProb,
        maxMM: maxRainMM
    };

    // Invalidate series cache
    root._seriesCache = ({});
    root._timelineRevision++;
}

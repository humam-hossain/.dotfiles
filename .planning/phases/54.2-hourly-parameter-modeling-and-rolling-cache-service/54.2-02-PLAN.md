<threat_model>
### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Local JSON cache file observer, Quickshell QML runtime engine, JavaScript numeric evaluation boundary.
- **T-54.2-06: JavaScript String Concatenation and Type Coercion Bug in Graph Splines (ASVS V11 - Data Processing)**:
  - *Threat*: Raw WWO string metrics (e.g. `"28"`) causing string concatenation in Canvas coordinate math (`"28" + 2` is `"282"`), blowing out Canvas coordinate bounds.
  - *Mitigation*: Strict numeric coercion (`parseInt()`, `parseFloat()`, `Number()`) across all 6 domain objects per D-54.2-18.
- **T-54.2-07: Canvas Graph Hairline Snapping / Coordinate Shift (ASVS V11 - UI Integrity)**:
  - *Threat*: Dynamic array lengths (e.g. 13 slots on cold boot) causing Canvas graph coordinates and center NOW hairline to jump horizontally.
  - *Mitigation*: Invariant 25-point array length with `isHistoricalUnavailable: true` placeholders per D-54.2-02.
- **T-54.2-08: Stale Series Data in Canvas Render Loops (ASVS V11 - Data Consistency)**:
  - *Threat*: Memoized series arrays retaining obsolete data after top-of-hour timeline advancement.
  - *Mitigation*: Synchronous cache invalidation in `rebuildTimeline()` resetting `_seriesCache = ({})` and incrementing `_timelineRevision` per D-54.2-19.
- **T-54.2-09: Null Temperature Bounds Plunging Bug (ASVS V11 - Data Integrity)**:
  - *Threat*: Unpopulated past slots with `null` temperatures causing `Math.min(null, 25)` to evaluate to `0`, artificially plunging summer minimum temperatures to freezing (0°C).
  - *Mitigation*: Filter array to numbers and non-null values before evaluating `Math.min(...validTemps)`.
- **T-54.2-10: Submodule Git Churn & Upstream Corruption (ASVS V10 - Integrity)**:
  - *Threat*: Accidental direct mutations to `vendor/dots-hyprland/` breaking submodule tracking.
  - *Mitigation*: Author strictly in personal overlay `restow/quickshell/`.
</threat_model>

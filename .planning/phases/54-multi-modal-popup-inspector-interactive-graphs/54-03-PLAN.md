### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Quickshell UI scenegraph, Canvas 2D raster engine, mouse event stream, and local tmpfs weather cache.
- **T-54-01: CPU / GPU Scenegraph Thrashing (ASVS V11 - DoS Prevention)**:
  - *Threat*: Redrawing Canvas 2D at 60fps inside `MouseArea.onPositionChanged` or when popup is hidden consuming 15–30% CPU and draining battery.
  - *Mitigation*: Canvas draws strictly ONCE on data change or popup open. Mouse hover scrub is handled by lightweight QML `Rectangle` and text items updating geometry without requesting Canvas repaint per D-54-20. Repaint requests are gated behind `popupActive === true` per D-54-22.
- **T-54-02: Spline Divergence / NaN Coordinate Crash (ASVS V5.1 - Input Validation)**:
  - *Threat*: Missing, string, or identical temperature data producing zero divisions (`dx === 0`) or `NaN` coordinates in `ctx.bezierCurveTo`.
  - *Mitigation*: Enforce Fritsch-Carlson secant delta guard (`if (dx === 0) tangents = 0`) and clamp interpolation weights $\alpha^2 + \beta^2 \le 9$ per D-54-15 and 54-RESEARCH.md mathematical specification.
- **T-54-03: Array Index Out-of-Bounds (ASVS V5.1 - Input Validation)**:
  - *Threat*: Mouse hover scrub calculating index outside valid hourly array bounds.
  - *Mitigation*: Clamp hovered slot index to `Math.max(0, Math.min(hourlySlots.length - 1, slotIndex))`.
- **T-54-04: Submodule Drift (ASVS V10 - Integrity)**:
  - *Threat*: Unintended mutations in `vendor/dots-hyprland`.
  - *Mitigation*: Author strictly under `restow/quickshell/`.
- **T-54-05: Secret Leakage (ASVS V2/V3 - Confidentiality)**:
  - *Threat*: Exposing API keys or configuration secrets.
  - *Mitigation*: STRICT PROHIBITION: Never access `rclone.conf` or `.env`.
</threat_model>

### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Quickshell UI scenegraph, local tmpfs cache (`$XDG_RUNTIME_DIR/weather/`), GNU Stow overlay symlinks in `~/.config/quickshell/`, and git repository tracking.
- **T-54-01: Root Privilege Execution (ASVS V1 - Principle of Least Privilege)**:
  - *Threat*: Test harness or deployment commands running as root altering file ownership or symlinks in user configuration directories.
  - *Mitigation*: Fail closed if executed as EUID == 0. Author solely in user-owned workspace paths.
- **T-54-02: Boundary Overflow & Window Clipping (ASVS V11 - UI Integrity)**:
  - *Threat*: Fixed-dimension popup clipping off-screen on constrained 1080p displays or narrow vertical bars.
  - *Mitigation*: Wrap root popup layout in `StyledFlickable` with `Layout.maximumHeight: root.screen?.height * 0.8` and enforce `StyledPopup` automatic monitor clamping (`updateLockedMargins()`) per D-54-09, D-54-12.
- **T-54-03: Malformed Mock Fixture Injection (ASVS V5.1 - Input Validation)**:
  - *Threat*: Unsanitized JSON fixtures leading to schema mismatches or false-positive assertion runs.
  - *Mitigation*: Author fixtures strictly validating against Phase 51 envelope schema (`status`, `is_stale`, `data.current_condition`, `data.weather.hourly`, `data.weather.astronomy`, `data.alerts`).
- **T-54-04: Submodule Drift & Supply Chain Tampering (ASVS V10 - Integrity)**:
  - *Threat*: Accidental edits inside `vendor/dots-hyprland/` breaking upstream tracking.
  - *Mitigation*: Author strictly under `restow/quickshell/` and assert `git status --porcelain vendor/dots-hyprland` is empty in Section 5 via `./arch/dots-hyprland.sh verify --strict`.
- **T-54-05: Secret Leakage (ASVS V2/V3 - Confidentiality)**:
  - *Threat*: Exposing API keys or configuration secrets.
  - *Mitigation*: STRICT PROHIBITION: Never access `rclone.conf` or `.env`. Components consume only public telemetry singletons.
</threat_model>

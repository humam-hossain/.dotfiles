### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Quickshell UI scenegraph, Canvas 2D lunar drawing, rotation animation timers, and local tmpfs weather cache.
- **T-54-01: Angular Wrap-Around Disorientation (ASVS V11 - UI Integrity)**:
  - *Threat*: Raw degree transitions from 355° to 5° spinning the needle 350° clockwise, causing visual jerkiness.
  - *Mitigation*: Shortest-path angle calculation `let diff = (target - (current % 360) + 540) % 360 - 180; current += diff;` guaranteeing transitions $\le 180^\circ$ per D-54-25.
- **T-54-02: Zero Division in Lunar Arc Math (ASVS V5.1 - Input Validation)**:
  - *Threat*: Invalid illumination strings (`"NaN"`, empty, negative) causing `ctx.ellipse` parameter crashes.
  - *Mitigation*: Guard illumination parsing with `const frac = Math.max(0, Math.min(100, parseInt(model?.moonIllumination || 0))) / 100` and default to safe circle if parsing fails.
- **T-54-03: Submodule Drift & Supply Chain Tampering (ASVS V10 - Integrity)**:
  - *Threat*: Accidental edits inside `vendor/dots-hyprland/` breaking upstream tracking.
  - *Mitigation*: Deploy leaf symlinks exclusively under `restow/quickshell/` and verify `./arch/dots-hyprland.sh verify --strict` exits 0 with FAIL=0 FINDINGS=0.
- **T-54-04: Secret Leakage (ASVS V2/V3 - Confidentiality)**:
  - *Threat*: Exposing API keys or configuration secrets.
  - *Mitigation*: STRICT PROHIBITION: Never access `rclone.conf` or `.env`.

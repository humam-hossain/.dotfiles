<threat_model>
### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Quickshell UI scenegraph, tmpfs weather cache data, and user interaction inputs.
- **T-54-01: Malformed JSON / Undefined Property Crash (ASVS V5.1 - Input Validation)**:
  - *Threat*: Missing alert properties (`headline`, `desc`, `severity`) or missing temperature values causing QML runtime exceptions or blank rendering.
  - *Mitigation*: Defensive optional chaining and safe neutral fallbacks (`model?.tempC ?? "--"`, `activeAlert?.severity ?? ""`) across all card text fields per D-54-33.
- **T-54-02: API Quota Exhaustion via Click Spam (ASVS V11 - DoS Prevention)**:
  - *Threat*: User rapidly clicking refresh icon triggering rapid disk re-reads or rogue API network calls.
  - *Mitigation*: Manual refresh calls `Weather.getData()` which strictly re-reads local disk cache without network requests per D-54-37. The button is disabled for 2000ms upon activation via visual state lock per D-54-38.
- **T-54-03: Accidental Browser Launch / URL Redirection (ASVS V11 - Desktop Telemetry Integrity)**:
  - *Threat*: Clicking alert text launching an external browser to commercial weather websites.
  - *Mitigation*: Pure desktop telemetry per D-54-40; clicks only toggle internal drawer expansion (`expanded = !expanded`).
- **T-54-04: Submodule Mutation (ASVS V10 - Supply Chain Integrity)**:
  - *Threat*: Edits to vendor tree.
  - *Mitigation*: Author strictly in `restow/quickshell/` overlay tree.
- **T-54-05: Secret Leakage (ASVS V2/V3 - Confidentiality)**:
  - *Threat*: Exposing API keys or configuration secrets.
  - *Mitigation*: STRICT PROHIBITION: Never access `rclone.conf` or `.env`.
</threat_model>

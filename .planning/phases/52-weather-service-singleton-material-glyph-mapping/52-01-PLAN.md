### ASVS L1 Security & Threat Mitigation
- **T-52-01: Malformed Input / Prototype Pollution in QML / JS (ASVS V5.1 - Input Validation)**:
  - *Threat*: Unsanitized weather codes or missing fields causing unhandled exceptions, NaN propagation, or script crashes.
  - *Mitigation*: `WeatherGlyphs.getGlyph()` checks `code != null`, casts to string `String(code)`, uses `.hasOwnProperty()` safely, and defaults to `"cloud"` per D-52-11. `getAqiColor()` and `getAqiCategory()` parse with `parseInt()` and default safely to `transparent` / `Unavailable`.
- **T-52-02: Secret Leakage (ASVS V2/V3 - Least Privilege)**:
  - *Threat*: Accidental leakage or logging of API keys or environment tokens in QML singletons.
  - *Mitigation*: `WeatherGlyphs.qml` operates purely on condition codes and telemetry numbers; it has zero access to environment files or API credentials.
- **T-52-03: Denial of Service / CPU Spikes (ASVS V10 - Performance & Resource Management)**:
  - *Threat*: Deep nested function evaluations or recursive glyph lookups causing UI thread pauses.
  - *Mitigation*: Static object hashmap lookup $O(1)$ for condition codes without regex loops or subshell calls.
</threat_model>

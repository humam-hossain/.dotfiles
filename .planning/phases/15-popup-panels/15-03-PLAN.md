```qml
// In the root PanelWindow
property Item currentPopup: null

function openPopup(popup) {
    if (currentPopup && currentPopup !== popup) {
        currentPopup.visible = false
        currentPopup.open = false
    }
    currentPopup = popup
    popup.visible = true
    popup.open = true
}
```

  <action>
Add a MouseArea click handler to ClockWidget that calls BarContent's `openPopup` with the CalendarPopup.

The challenge: ClockWidget is inside a ModulePill inside a BarGroup inside a RowLayout inside BarContent PanelWindow. It needs a reference to the parent BarContent's `openPopup` function.

**Approach — find BarContent via parent hierarchy:**
```qml
MouseArea {
    anchors.fill: parent
    cursorShape: Qt.PointingHandCursor
    onClicked: {
        // Walk up parents to find BarContent root
        var parent = root.parent
        while (parent && typeof parent.openPopup === 'undefined') {
            parent = parent.parent
        }
        if (parent) {
            parent.openPopup(parent.calendarPopup)
        }
    }
}
```

Add the MouseArea after the existing Text element (nested inside Local.ModulePill). Use `anchors.fill: parent` to cover the entire ModulePill.

**DO NOT:**
- Remove the existing Text element
- Change any colors, fonts, or styling
- Add any imports (QtQuick is already available in ModulePill's scope)
</action>

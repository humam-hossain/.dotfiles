  <action>
Create `.config/quickshell/services/CalendarService.qml` as a `pragma Singleton` following the same pattern as ClockService.qml.

**Properties to expose:**
- `property int currentYear` — selected year (init: today's year)
- `property int currentMonth` — selected month (0-11, init: today's month)
- `property int todayYear` — today's year (read-only, from `new Date().getFullYear()`)
- `property int todayMonth` — today's month (read-only, from `new Date().getMonth()`)
- `property int todayDate` — today's date (read-only, from `new Date().getDate()`)
- `property var dayGrid` — array of 42 objects (6 rows × 7 cols), each with `{ day: int, month: int, year: int, isCurrentMonth: bool, isToday: bool, isWeekend: bool, weekNumber: int }`

**Functions:**
- `function prevMonth()` — decrement currentMonth, wrap year at 0
- `function nextMonth()` — increment currentMonth, wrap year at 11
- `function monthData(year, month)` — internal: returns grid data (see RESEARCH.md §2 for algorithm)

**Calendar grid algorithm (in monthData function):**
```
1. firstDay = new Date(year, month, 1)
2. daysInMonth = new Date(year, month + 1, 0).getDate()
3. startOffset = (firstDay.getDay() === 0 ? 6 : firstDay.getDay() - 1)  // Mon=0
4. totalCells = Math.ceil((startOffset + daysInMonth) / 7) * 7  // 35 or 42
5. For each i in 0..totalCells-1:
   cellDay = i - startOffset + 1
   if cellDay < 1: prev month day (year, month-1)
   else if cellDay > daysInMonth: next month day (year, month+1)
   else: current month day
6. Calculate ISO week number for each row (every 7 cells)
7. Set isWeekend: true for columns 5 (Sat) and 6 (Sun) based on Mon=0 indexing
```

**Expose convenience properties for QML binding:**
- `property var weekNumbers` — array of 6 week numbers (one per row, 0 for irrelevant partial weeks)
- `property int gridRows` — 6 (fixed, per D-10)
- `property string monthHeader` — `Qt.formatDateTime(new Date(currentYear, currentMonth, 1), "MMMM yyyy")`

**DO NOT:**
- Import any UI components (this is a data-only service)
- Use `Component.onCompleted` or Timer — all data derived from JS Date
- Add signal handlers — use property bindings in the popup

```
import Quickshell
import Quickshell.Wayland

import QtQuick.Layouts

```

**Window setup:**
- `PopupWindow` (not PanelWindow) per D-28
- `visible: false` (not opacity: 0) per P-03
- Anchor: `anchor.window: parentWindow`, fixed offset pattern matching VolumeOsd
- `WlrLayershell.layer: WlrLayer.Overlay` (render above normal windows)
- Popup width: 320px (7 columns × 36px + 1 week col × 36px + padding)
- Popup height: fixed for 6 rows (36px × 6 rows + header + padding = ~280px)

**Content structure (top to bottom):**

1. **Month header row** (RowLayout):
   - Left arrow Button: Nerd Font , flat style, transparent bg, onClicked: CalendarService.prevMonth()
   - Centered Text: CalendarService.monthHeader, 14px bold, Colours.textColor
   - Right arrow Button: Nerd Font , onClicked: CalendarService.nextMonth()
   - Use `Layout.preferredWidth` for spacing

2. **Separator line** (thin Rectangle divider)

3. **Day-of-week + week number + grid layout** (RowLayout):
   
   a. **Week number column** (left side, Column):
      - Header: "Wk" label
      - 6 Text items: CalendarService.weekNumbers[i], smaller font, subtextColor
   
   b. **7-column day grid** (Grid with 7 columns):
      - Header row: 7 Text items "M" "T" "W" "T" "F" "S" "S"
      - Day cells: Repeater over CalendarService.dayGrid (42 items)
        - Each cell: 36x36px Rectangle
        - isToday → `color: Colours.accent`, text: white
        - isCurrentMonth && isWeekend → `color: Colours.subtext0` at opacity 0.15
        - !isCurrentMonth → `color: "transparent"`, text: `color: Colours.subtextColor`
        - Default → `color: "transparent"`, text: `color: Colours.textColor`
        - Text: cell.day (number), 14px bold, center-aligned
        - MouseArea: onClicked → visual highlight (sets a selectedDay property, does NOT close popup per D-05)

**Popup management:**
- `property bool open: false` — toggle by BarContent
- `function show() { root.visible = true; root.open = true }`
- `function close() { root.visible = false; root.open = false }`
- `onVisibleChanged: if (!visible) open = false`

**Dismiss mechanisms:**
- `HyprlandFocusGrab { windows: [root]; active: root.visible; onCleared: root.close() }` (outside-click dismiss)
- `Keys.onEscapePressed: root.close()` (Escape dismiss) — set `focus: true` on a container Item
- **`Item { focus: true; Keys.onEscapePressed: root.close() }`** as root content item to capture Escape

**Styling:**
- Popup background: Rectangle with `color: Colours.base`, `radius: 8`, padding: 8px
- Nerd Font: `font.family: "JetBrainsMono Nerd Font"`

**DO NOT:**
- Import or create a popups/qmldir (per D-30, direct import path is used)
- Use LazyLoader (per D-29, static visible:false is sufficient)
- Close popup on day cell click (per D-36, visual-only)
- Use `grabFocus: true` (per P-01, use HyprlandFocusGrab)
- Add animations (Phase 16)

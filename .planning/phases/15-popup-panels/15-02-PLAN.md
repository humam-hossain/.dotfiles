IMPORTANT — nmcli command patterns (from RESEARCH.md):
- Scan: `nmcli --get-values SSID,SECURITY,SIGNAL dev wifi list`
  - Output format: `SSID:SECURITY:SIGNAL` (colon-delimited, one per line)
  - Empty SSID = hidden network
  - SECURITY empty or `--` = open
- Connection info: `nmcli -g GENERAL.TYPE,GENERAL.STATE,GENERAL.CONNECTION dev show <iface>`
- IP info: `nmcli -g IP4.ADDRESS,IP4.GATEWAY,IP4.DNS con show --active`
- Connect: `nmcli dev wifi connect <SSID> password <password>`
- Disconnect: `nmcli con down id <SSID>`

P-06 (Process.command doesn't expand $HOME) is not relevant here — all commands are absolute (nmcli, kitty).

**Connection status data flow:**
Use Process to fetch connection info:
```qml
Process {
  id: connInfoProc
  command: ["bash", "-c", "nmcli -t -f GENERAL.DEVICE,GENERAL.TYPE dev status | head -5"]
  stdout: StdioCollector { onStreamFinished: { /* parse */ } }
  running: false
}
```
On popup visible:
```
onVisibleChanged: {
  if (visible) { scanProc.running = true; connInfoProc.running = true }
}
```

Parse `nmcli dev show <iface>` output:
```
command: ["bash", "-c", "nmcli -g GENERAL.TYPE,GENERAL.STATE,GENERAL.CONNECTION dev show $(nmcli -t -f DEVICE,TYPE dev status | grep -m1 ':wifi\\|:ethernet' | cut -d: -f1)"]
```
Store parsed fields as `property string connType`, `property string connState`, `property string connName`.

Use separate Process for IP details:
```
command: ["bash", "-c", "nmcli -g IP4.ADDRESS,IP4.GATEWAY,IP4.DNS,IP6.ADDRESS,IP6.GATEWAY con show --active"]
```

**Handle disconnected state:** If no active connection (connState != "connected" or empty), show "Not connected" in the status section and hide disconnect button.

```qml
Process {
  id: scanProc
  command: ["nmcli", "--get-values", "SSID,SECURITY,SIGNAL", "dev", "wifi", "list"]
  stdout: StdioCollector {
    onStreamFinished: {
      // Parse colon-delimited output

    }
  }
  running: false
}
```

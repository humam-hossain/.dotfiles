### ASVS L1 Security & STRIDE Threat Register
- **Trust Boundaries**: Quickshell UI scenegraph, local tmpfs weather cache (`$XDG_RUNTIME_DIR/weather/`), GNU Stow overlay symlinks in `~/.config/quickshell/`, and git repository tracking.
- **T-53-01: Root Privilege Execution (ASVS V1 - Principle of Least Privilege)**:
  - *Threat*: Accidental execution as root altering file ownership or symlinks in user configuration directories.
  - *Mitigation*: Fail closed if executed as EUID == 0. Author solely in user-owned workspace paths.
- **T-53-02: NaN String Injection / Layout Snapping (ASVS V5.1 - Input Validation)**:
  - *Threat*: Uninitialized cache or unexpected telemetry types injecting `NaN°C` or causing 0-width layout collapses.
  - *Mitigation*: Guard temperature parsing with `Math.round(Number(raw))` and `!isNaN(...)` fallback to `"--"` per D-53-19. Bind `Revealer` implicit dimensions directly to child layout implicit dimensions to prevent 0-width collapse.
- **T-53-03: Event Bubbling / Unintended Action Execution (ASVS V11 - UI Integrity)**:
  - *Threat*: Clicks on weather pill passing through to background status bar mouse areas, toggling the right sidebar unexpectedly.
  - *Mitigation*: Set `acceptedButtons: Qt.AllButtons`, `onPressed: event => event.accepted = true`, `onClicked: event => event.accepted = true` on root `MouseArea` per D-53-05, D-53-30.
- **T-53-04: Submodule Tampering & Git Churn (ASVS V10 - Supply Chain Integrity)**:
  - *Threat*: Mutating files under `vendor/dots-hyprland/` breaking upstream tracking and failing strict repository verification.
  - *Mitigation*: Author strictly in `restow/quickshell/` overlay tree per D-53-02. Leave `BarContent.qml` 100% UNTOUCHED per D-53-01. Maintain vendor hygiene verified via `./arch/dots-hyprland.sh verify --strict`.
- **T-53-05: Secret Leakage (ASVS V2/V3 - Confidentiality)**:
  - *Threat*: Exposing API keys or configuration secrets.
  - *Mitigation*: STRICT PROHIBITION: Never access `rclone.conf` or `.env`. Component consumes only public telemetry singletons.

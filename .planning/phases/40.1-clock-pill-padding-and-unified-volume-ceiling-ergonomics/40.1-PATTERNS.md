```lua
-- Upstream unbinds (D-04, VOL-01)
hl.unbind("XF86AudioRaiseVolume") -- upstream hardcoded 1.5 ceiling raise volume

-- Resolve desktop volume ceiling once at startup/reload (D-04, VOL-01)
local function get_volume_ceiling()
    local default_ceiling = "1.5"
    local config_path = HOME .. "/.config/illogical-impulse/config.json"
    local f = io.open(config_path, "r")
    if not f then return default_ceiling end
    local content = f:read("*a")
    f:close()
    if not content then return default_ceiling end
    local ceiling = content:match('"volumeCeiling"%s*:%s*([%d%.]+)')
    if ceiling and tonumber(ceiling) and tonumber(ceiling) > 0 then
        return ceiling
    end
    return default_ceiling
end
local volume_ceiling = get_volume_ceiling()

-- Audio controls (D-04, VOL-01)
hl.bind("XF86AudioRaiseVolume", hl.dsp.exec_cmd("wpctl set-volume @DEFAULT_AUDIO_SINK@ 2%+ -l " .. volume_ceiling),
    { locked = true, repeating = true, description = "Audio: Raise volume" })
```

**Key Considerations & Guardrails:**
- Pure Lua parsing uses `io.open` and pattern match `[%d%.]+`. Zero subprocess forks (`jq` or subshells) during key repeats.
- `tonumber(ceiling) > 0` validation prevents invalid injection.
- Unbind upstream `XF86AudioRaiseVolume` first to guarantee only the custom bind fires.

**Key Considerations & Guardrails:**
- **Avoid Double Normalization:** `TrackDot` inside `StyledSlider.qml` evaluates `normalizedValue = (value - root.from) / (root.to - root.from)`. ## Cross-Cutting Patterns & Constraints Summary

| Subsystem / Area | Architectural Rule | Failure Mode if Violated |
|---|---|---|
| **Submodule Isolation** | Do NOT modify any file inside `vendor/dots-hyprland`. All customizations must be authored in `restow/quickshell/` or `stow/hypr/`. | Git submodule dirty state; breaks `./arch/dots-hyprland.sh verify --strict` (INTG-01, INTG-03). |
| **GNU Stow Overwrite Protection** | Upstream regular files at `~/.config/quickshell/...` must be backed up to `.qml.bak` before stowing. | `stow` exits with conflict error when stowing over existing regular files. |
| **Dynamic Configuration Deserialization** | Any custom property added to `config.json` must be explicitly declared in `restow/.../modules/common/Config.qml`. | Property evaluates to `undefined` at runtime inside QML; defaults silently fallback. |
| **Zero-Subshell Keybind Loops** | Compositor volume keybindings must resolve the ceiling once during Lua initialization, not via `jq` / bash on every key repeat tick. | High CPU usage and stutter during repeated volume adjustment keypresses. |
| **Slider Track Normalization** | Pass raw values (e.g. `[1.0]`) to `stopIndicatorValues`; `StyledSlider.TrackDot` normalizes internally against `(value - from) / (to - from)`. | Visual notch positioned at incorrect track position (e.g. at 44.4% instead of 66.7%). |

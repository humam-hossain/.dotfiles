# Plan 42-03: Validation Harness, Stow Links & Verification

<threat_model>
- **Spoofing**: Test scripts could be tricked into passing by mock files. Mitigated by strict assertions on real filesystem targets.
- **Tampering**: Execution of untrusted test code. Mitigated by running from source-controlled, trusted location.
- **Repudiation**: Non-issue.
- **Information Disclosure**: Test failures might leak configuration. Mitigated by secure local logging.
- **Denial of Service**: Infinite loops in assertions. Mitigated by timeouts in the bash script.
- **Elevation of Privilege**: Testing requiring `sudo`. Mitigated by explicitly designing tests to run unprivileged.
</threat_model>

## Objective

Create a bash test harness to assert the correctness of telemetry QML singletons, ping daemon JSON structures, and ensure stow links exist with zero working tree drift.

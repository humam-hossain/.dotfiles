#### Imports Pattern (Zero Process Imports)
In Phase 43.5, `import Quickshell.Io` was imported to support `Process` and `StdioCollector`. In Phase 43.6, process execution is eliminated:
```qml
pragma ComponentBehavior: Bound

import qs.modules.common
import qs.modules.common.widgets
import qs.services
import QtQuick
import QtQuick.Layouts
import Quickshell
```
*Note:* Do **not** import `Quickshell.Io` since zero background subprocesses are invoked.

#### Fast-Polling Lifecycle Refcounter Pattern
Guarantees zero reference count leaks to the `HardwareTelemetry` singleton across popup activations and destruction:
```qml
    // Reactive fast-polling lifecycle boost (1000ms active / 3000ms idle)
    // Guarantees zero reference count leaks
    onActiveChanged: {
        if (active) {
            HardwareTelemetry.fastPollingRequests++;
        } else {
            HardwareTelemetry.fastPollingRequests--;
        }
    }

    Component.onDestruction: {
        if (active) {
            HardwareTelemetry.fastPollingRequests--;
        }
    }
```

#### Alert Threshold & Dynamic Warning Fallback Pattern
Uses `Appearance.colors.colWarning` with dots-hyprland amber fallback (`#FFA000`) and Material 3 error/primary tokens:
```qml
    // Alert threshold color mappings with dots-hyprland amber warning color fallback
    readonly property color warningColor: Appearance.colors.colWarning !== undefined ? Appearance.colors.colWarning : "#FFA000"

    function getLoadColor(val) {
        if (val >= 0.90) return Appearance.colors.colError;
        if (val >= 0.70) return root.warningColor;
        return Appearance.colors.colPrimary;
    }

    function getTempColor(temp) {
        if (temp >= 80) return Appearance.colors.colError;
        if (temp >= 65) return root.warningColor;
        return Appearance.colors.colOnLayer1;
    }

    readonly property color cpuLoadColor: getLoadColor(HardwareTelemetry.overallCpuLoad || 0.0)
    readonly property color gpuLoadColor: getLoadColor(HardwareTelemetry.gpuLoad || 0.0)
```

## Anti-Patterns to Avoid

| Anti-Pattern | Why to Avoid | Correct Alternative |
|---|---|---|
| **Spawning Subprocesses in UI Popups** | Running `Timer` + `Process` (`process_tree.sh`) causes periodic background CPU churn, PID consumption, and latency spikes when hovering over status bar. | Bind visual meters directly to `HardwareTelemetry` singleton properties; zero subprocesses or timers inside `CpuGpuPopup.qml`. |
| **Hardcoding Hardware Names** | Hardcoding `i5-13500`, `Intel UHD 770`, or `B760` breaks portability on AMD/other hardware (violating CPUGPU-05). | Use dynamic properties: `HardwareTelemetry.cpuModelName`, `HardwareTelemetry.gpuModelName`, and `HardwareTelemetry.motherboardModelName`. |
| **Static Core Thread Counts** | Hardcoding `(12T)` or `(8T)` displays inaccurate thread counts on other CPUs (violating CPUGPU-06). | Use dynamic bindings `${HardwareTelemetry.pCoreThreadCount}T` and `${HardwareTelemetry.eCoreThreadCount}T`, gated by `visible: HardwareTelemetry.isHybridArchitecture`. |
| **Unbounded Column Height / Asymmetry** | Leaving column heights unequal or stretching row items unevenly creates vertical visual distortion. | Use `Item { Layout.fillHeight: true }` at the bottom of the Right column to absorb excess vertical space cleanly. |
| **Refcount Leaks in `HardwareTelemetry`** | Forgetting `Component.onDestruction` or failing to decrement `fastPollingRequests` on popup close locks telemetry into 1000ms polling permanently. | Retain dual cleanup: decrement on `active: false` in `onActiveChanged` AND in `Component.onDestruction`. |
| **Ungated Animations** | Running `SequentialAnimation` when popup is closed wastes compositor render cycles. | Gate animations strictly on `running: root.active && root.isCritical` with reset on `!running`. |
| **Hardcoded Alert Colors** | Using hardcoded hex strings (`#FF0000`) bypasses Material You theming. | Resolve colors via `root.getLoadColor()` and `root.getTempColor()` using `Appearance.colors` tokens with `#FFA000` warning fallback. |

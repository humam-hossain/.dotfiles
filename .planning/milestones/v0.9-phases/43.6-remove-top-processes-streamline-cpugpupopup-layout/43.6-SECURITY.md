# Phase 43.6 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Quickshell runtime → OS subprocesses | Invoking external shell scripts from QML creates process lifecycle and resource overhead | Subprocess execution |
| Sysfs/procfs → HardwareTelemetry | Virtual procfs and sysfs telemetry streams consumed unprivileged | Kernel telemetry stats |
| QML Scenegraph → Wayland Layer-Shell | Popup sizing and boundary clamping interacting with Wayland compositor | Window geometry and rendering |
| GNU Stow symlinks → Upstream dots-hyprland | Stow overlays must not contaminate vendor/dots-hyprland submodule | Leaf symlink mappings |

## Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation | Status |
|-----------|----------|-----------|----------|-------------|------------|--------|
| T-43.6-01 | Denial of Service | procScanTimer / processTreeProc | high | mitigate | Completely remove `Timer`, `Process`, and `Quickshell.Io` from `CpuGpuPopup.qml`, eliminating background process execution churn and potential PID exhaustion. | closed |
| T-43.6-02 | Denial of Service | fastPollingRequests refcounter | medium | mitigate | Retain refcounted increment in `onActiveChanged` (+1 when active, -1 when inactive) and decrement in `Component.onDestruction`, asserted by Section 4. | closed |
| T-43.6-03 | Information Disclosure | Process listing in UI | low | accept | Process inspection trees are removed from the status bar popup entirely. | closed |
| T-43.6-04 | Denial of Service | CpuGpuPopup.qml layout geometry | medium | mitigate | Fixed 320px column widths and trailing vertical spacer prevent layout expansion cycles; total popup width (673px) fits safely within layer-shell bounds. | closed |
| T-43.6-05 | Integrity | Telemetry property bindings | medium | mitigate | Assert dynamic bindings (HardwareTelemetry.cpuModelName, gpuModelName, motherboardModelName, isHybridArchitecture) in Section 2 of assert harness to prevent regression of CPUGPU-05/CPUGPU-06. | closed |
| T-43.6-06 | Tampering / Drift | Stow package structure | high | mitigate | Strictly manage overlay files in `restow/quickshell/` without folding parent directories and enforce zero drift via `./arch/dots-hyprland.sh verify --strict`. | closed |
| T-43.6-SC | Denial of Service | Infinite pulse animations | low | mitigate | `popupCriticalPulse` running state is strictly gated on `root.active && root.isCritical`, preventing off-screen GPU rendering. | closed |

*Status: open · closed · open — below high threshold (non-blocking)*  
*Severity: critical > high > medium > low — only open threats at or above workflow.security_block_on count toward threats_open*  
*Disposition: mitigate (implementation required) · accept (documented risk) · transfer (third-party)*

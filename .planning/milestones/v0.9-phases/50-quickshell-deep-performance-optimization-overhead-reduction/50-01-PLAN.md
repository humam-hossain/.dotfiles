<objective>
Implement the Phase 50 automated validation harness `scripts/phase50-opt-assert.sh` (Wave 0 scaffold) and establish the coalesced 5000ms quiescent idle telemetry heartbeat across Quickshell singletons (`ResourceUsage.qml`, `HardwareTelemetry.qml`, `StorageUsage.qml`) bound to a central bar hover state in `GlobalStates.qml` and `BarContent.qml` (OPT-01, OPT-05, D-50-01, D-50-10).

Purpose: Eliminate desynchronized background polling (1s, 2s, 3s) that prevents CPU package low-power C-states during stationary idle, while establishing automated AST, timer, and benchmark ceiling verification.
Output: Executable `scripts/phase50-opt-assert.sh` with working Section 1 and Section 3 timer assertions, updated `GlobalStates.qml` and `BarContent.qml`, and coalesced 5000ms idle cadences in `HardwareTelemetry.qml`, `ResourceUsage.qml`, and `StorageUsage.qml`.
</objective>

<threat_model>
ASVS L1 Threat Model & Mitigations:
- **T-50-01: Elevated Execution Risk (Root/Sudo Abuse)**
  - Threat: Running test or assertion harnesses under root can corrupt home directory file permissions, create unwritable root-owned artifacts, or modify critical system paths.
  - ASVS L1 Mapping: V1.1.1 Least Privilege Architecture.
  - Mitigation: `scripts/phase50-opt-assert.sh` enforces `[[ "${EUID:-$(id -u)}" -ne 0 ]]` fail-closed check immediately on entry.
- **T-50-02: Denial of Service via State Churn or Integer Underflow**
  - Threat: Dynamic registration of `activeInspectorCount` or rapid cursor hover could cause counter underflow (`activeInspectorCount < 0`) or continuous fast-polling lockup.
  - ASVS L1 Mapping: V5.1.1 Input and State Validation.
  - Mitigation: `GlobalStates.qml` clamps inspector counter updates via `Math.max(0, activeInspectorCount - 1)` and guarantees `fastTelemetryRate` evaluates safely with boolean primitives.
- **T-50-03: Submodule Integrity Violation & Drift**
  - Threat: Modifying files in `vendor/dots-hyprland` directly would break personal overlay boundaries and fail repository verification.
  - ASVS L1 Mapping: V1.1.2 Secure Software Development Lifecycle / Supply Chain Integrity.
  - Mitigation: All QML modifications are strictly confined to `restow/quickshell/`, deployed via GNU Stow leaf symlinks, and validated by Section 5 of `phase50-opt-assert.sh`.
</threat_model>

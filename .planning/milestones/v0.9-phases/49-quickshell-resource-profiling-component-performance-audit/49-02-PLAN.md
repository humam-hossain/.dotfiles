    1. Extend `scripts/profile-quickshell.sh` with a declarative table of interactive popup stages (`POPUP_STAGES`):
       - `popup_cpugpu|hover|100|10|quickshell:popup|CPU/GPU Inspector popup`
       - `popup_memstorage|hover|40|10|quickshell:popup|Memory/Storage Breakdown popup`
       - `popup_netping|hover|160|10|quickshell:popup|Network/Multi-Target Ping popup`
       - `popup_clock|hover|800|10|quickshell:popup|Clock & Calendar popup`
       - `popup_weather|hover|900|10|quickshell:popup|Weather extended forecast popup`
       - `popup_mediacontrols|ipc|mediaControls|open|quickshell:mediaControls|MediaControls overlay`
       - `popup_sidebarleft|ipc|sidebarLeft|open|quickshell:sidebarLeft|Left Dashboard sidebar`
       - `popup_sidebarright|ipc|sidebarRight|open|quickshell:sidebarRight|Right Control sidebar`

    2. Implement `navigate_and_sample_popup`:
       - Accepts: `stage_id`, `stage_name`, `method` ("hover" or "ipc"), `target_x` / IPC target, `target_y` / IPC open method, `expected_layer`.
       - For `hover`: Moves cursor using `ydotool mousemove -a -x "$target_x" -y "$target_y" 2>/dev/null || true` and sleeps 0.5s for hover intent.
       - For `ipc`: Issues `qs -c ii ipc call "$target_x" "$target_y" 2>/dev/null || true` and sleeps 0.5s.
       - Validates layer presence: checks `hyprctl layers 2>/dev/null | grep -q "namespace: $expected_layer"`. If found, logs `[PASS] Layer surface verified: $expected_layer`.
       - Calls `run_sample_window "$stage_id" "$stage_name" "custom_active"`.
       - Cleanup / dismiss:
         - For `hover`: Moves cursor to neutral center `(860, 360)` via `ydotool mousemove -a -x 860 -y 360` and sleeps 0.4s.
         - For `ipc`: Calls `qs -c ii ipc call "$target_x" "close"` and sleeps 0.4s.
         - Confirms layer dismissal.

    3. Implement `run_interactive_popup_audit`:
       - Iterates over all entries in `POPUP_STAGES`.
       - Calls `navigate_and_sample_popup` for each entry.

    4. Extend CLI options:
       - Add `--popups`: executes `run_interactive_popup_audit` and generates reports.
       - Add individual popup stage support in `--stage <id>`.
       - Update `--list-stages` to display all popup stages.

    5. Update Markdown and JSON generation in `profile-quickshell.sh`:
       - Add section "## 2. Interactive Popup Attribution Matrix" to `BENCHMARK.md` listing all measured popups with CPU, GPU %, GPU MHz, RSS, context switches, and syscall rates.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Wayland uinput Device (`/dev/uinput` via `ydotoold`) → Hyprland Compositor | Synthetic mouse motion events dispatched to position cursor over top status bar pills |
| Quickshell IPC Socket (`qs -c ii ipc call <target>`) → Quickshell Process | Direct remote procedure calls to toggle overlay visibility |
| Hyprland Compositor IPC (`hyprctl layers`) → Profiling Script | Read-only layer shell hierarchy query to verify surface activation |

## Threat Assessment

| Threat ID | Threat Type | Target | Severity | Mitigation Strategy |
|-----------|-------------|--------|----------|---------------------|
| T-49-05 | Denial of Service | Desktop UI interaction | medium | Avoid leaving popups open after sampling by enforcing a structured teardown block that repositions cursor to neutral center `(860, 360)` and sends IPC `close` calls. |
| T-49-06 | Safety / Stability | Mouse cursor positioning | low | Calibrate coordinates strictly using the verified $2\times$ uinput scale factor on `DP-1` (`Screen = 2 * ydotool + 1`), keeping cursor strictly within the 40px top bar region ($Y=10$) or neutral screen center ($Y=360$). |
| T-49-07 | Tampering / Schema Invalidation | Benchmark JSON artifact | low | Validate stage dictionary presence in `scripts/phase49-audit-assert.sh -s 3` using `jq -e` against strict required stage list. |
| T-49-08 | Information Disclosure | Confidential credentials | high | Strictly prohibit viewing, parsing, or matching any `rclone.conf` or OAuth token storage files. |
</threat_model>

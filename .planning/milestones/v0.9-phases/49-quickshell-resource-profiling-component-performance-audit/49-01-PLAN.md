<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Kernel DRM Sysfs (`/sys/class/drm/card1/`) → Profiling Script | Hardware counter reads for Intel UHD 770 GPU RC6 sleep residency and frequency |
| Linux procfs (`/proc/$PID/`) → Profiling Script | Process accounting ticks, memory maps, context switches, and file descriptor handles |
| Media Player D-Bus (`playerctl`) → Profiling Script | Status inspection and playback control to eliminate external GPU decode pollution |
| GNU Stow Symlink Tree (`~/.config/quickshell/ii`) → Upstream Baseline Isolation | Temporary unlinking and re-linking of dotfile leaf configurations |

## Threat Assessment

| Threat ID | Threat Type | Target | Severity | Mitigation Strategy |
|-----------|-------------|--------|----------|---------------------|
| T-49-01 | Elevation of Privilege | Execution context | low | Enforce strict non-root check (`EUID != 0`) in all scripts to prevent inadvertent execution with root privileges. |
| T-49-02 | Integrity Violation | Dotfile symlink tree | medium | Trap `EXIT INT TERM` in `profile-quickshell.sh` to ensure `restore_restow_quickshell` runs unconditionally, preventing orphaned stubs or broken leaf links. |
| T-49-03 | Denial of Service / Telemetry Pollution | GPU baseline accuracy | low | Check and pause all active MPRIS media players before sampling system idle to ensure hardware video decoding does not elevate GPU load beyond 10%. |
| T-49-04 | Information Disclosure | Confidential credentials | high | Strictly prohibit viewing, parsing, or matching any `rclone.conf` or OAuth token storage files. |
</threat_model>

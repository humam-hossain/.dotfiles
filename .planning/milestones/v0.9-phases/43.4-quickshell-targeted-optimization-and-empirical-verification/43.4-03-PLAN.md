# Plan 43.4-03: Empirical Benchmark Re-run & Performance Verification

<objective>
Execute a complete, side-by-side empirical benchmark profiling run using `scripts/profile-quickshell.sh` comparing pure upstream dots-hyprland baseline against the optimized custom overlay stack, capturing updated empirical telemetry in `BENCHMARK.md` and `benchmark-latest.json`, verifying that idle read syscalls drop from ~3,120/s to <80/s and active iGPU overhead is significantly curtailed, and asserting full compliance under `scripts/phase43-perf-assert.sh`, `scripts/phase43-cpu-gpu-assert.sh`, and `arch/dots-hyprland.sh verify --strict` with zero working tree drift.
</objective>

<threat_model>
### ASVS L1 Threat Model Evaluation

- **Privilege Escalation & Unprivileged Session Guard:** `scripts/profile-quickshell.sh` and all assert harnesses must execute strictly under the unprivileged user session owning the Quickshell Wayland process (`EUID -ne 0`), preventing permission skew across user runtime configurations in `~/.config/quickshell/`.
- **Working Tree State Corruption via Stow Interruption:** Profiling involves unstowing custom overlays to measure pure upstream baseline. The harness signal trap (`trap cleanup EXIT INT TERM`) ensures that even upon abnormal interruption (SIGINT, SIGTERM, error), temporary `.bak` stubs are removed and `restow/quickshell` is re-stowed before exiting, preserving system integrity.
- **Wayland IPC and Display Server Stability:** Profiling executes real Wayland pop-up interactions via `ydotool` and layer-shell polling (`hyprctl layers`). To prevent desktop disruption, the harness includes explicit user notification banners before moving the cursor and restores the cursor to neutral idle upon completion.
- **Repository Drift & Inadvertent Modifications:** GNU Stow operations, benchmark artifact generation, and assertions must not leave untracked files or unstowed symlinks. `./arch/dots-hyprland.sh verify --strict` verifies 100% clean leaf symlink topology and pristine upstream submodule status.
</threat_model>

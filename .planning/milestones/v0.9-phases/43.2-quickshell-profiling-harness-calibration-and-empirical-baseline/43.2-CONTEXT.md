# Phase 43.2: Quickshell Profiling Harness Calibration and Empirical Baseline Capture - Context

**Gathered:** 2026-09-27
**Status:** In Progress

<domain>
## Phase Boundary

Calibrate the diagnostic performance profiling harness (`scripts/profile-quickshell.sh`) to eliminate synthetic/fabricated estimations, correct automated Wayland/Hyprland input dispatcher coordinate scaling, enforce automated layer-shell pop-up verification, aggregate multi-threaded kernel telemetry, and capture genuine empirical reference baselines for Quickshell.

1. **Dual-State Active Pop-up Verification & Dispatcher Fix:**
   - Account for Wayland/Hyprland virtual uinput 2x coordinate scaling (`-x 90 -y 10` $\rightarrow$ `(181, 21)`).
   - Enforce rigorous verification via `hyprctl layers` to assert that `quickshell:popup` is actively rendered before sampling.
   - Enforce user safety protocol: print clear notices before moving the mouse and when finished, restoring the cursor to a neutral idle coordinate (`1001, 501`).
2. **Multi-Threaded Process Telemetry:**
   - Aggregate voluntary and non-voluntary context switches across all `/proc/$PID/task/*/status` worker threads instead of only sampling the main GUI thread.
3. **Honest Reporting & Removal of Synthetic Attribution:**
   - Eliminate fabricated/interpolated weight maps (`weight_map = {0.10, 0.35, ...}`) in `generate_reports()`.
   - Distinguish empirically measured stages from unmeasured stages.
   - Dynamically generate the executive summary from measured numbers rather than using hardcoded conflicting templates.
4. **Empirical Baseline Capture:**
   - Re-run calibrated baseline profiling across `upstream_baseline`, `full_idle`, and `full_active_popup`.
   - Update `BENCHMARK.md` and `benchmark-latest.json` with genuine empirical data to serve as the authentic foundation for optimization in Phases 44–46.

**Out of scope:**
- Applying QML code refactors or optimizations (deferred until real empirical baseline is locked).
- Discrete GPU telemetry or DDC/CI monitor polling (prohibited).
</domain>

<decisions>
## Implementation Decisions

- **D-01 (Automated Layer Verification):** `set_ui_state active_popup` MUST poll `hyprctl layers` for `quickshell:popup` before profiling begins, guaranteeing the pop-up is physically open on screen.
- **D-02 (Mouse Movement Notification Protocol):** The harness and the agent must warn before moving the mouse and notify when finished, ensuring zero accidental user input disruption.
- **D-03 (Thread-Wide Context Switch Aggregation):** Context switches are summed across all threads in `/proc/$PID/task/*/status` to capture full background worker activity.
- **D-04 (Authentic Attribution Data):** Remove all synthetic weight multipliers. Only measured stages are reported in delta comparisons.
- **D-05 (Dynamic Executive Summary):** Executive summary metrics in `BENCHMARK.md` are dynamically generated from measured stage objects.
</decisions>

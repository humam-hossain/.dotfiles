## 2. Core Architectural Patterns to Emulate

### Pattern A: Unprivileged Quickshell Process Discovery & Lifecycle
**Analog Source:** `arch/dots-hyprland.sh:222-262, 304-345`

Quickshell processes must be discovered without `pgrep -f` to avoid false positives against text editors or shell sessions that mention `quickshell`. Processes must be terminated gracefully and waited on before restarting to avoid Wayland display socket collisions.

```bash
# Analog excerpt from arch/dots-hyprland.sh:222-261
collect_qs_pids() {
  local uid
  uid="$(id -u)"
  local proc pid cmdline exe comm owner exe_base argv0
  for proc in /proc/[0-9]*; do
    pid="${proc##*/}"
    [[ "$pid" =~ ^[0-9]+$ ]] || continue
    [[ "$pid" == "$$" ]] && continue
    # Owner must be current user
    owner="$(stat -c '%u' "$proc" 2>/dev/null || true)"
    [[ "$owner" == "$uid" ]] || continue

    comm="$(cat "$proc/comm" 2>/dev/null || true)"
    if [[ "$comm" == "qs" || "$comm" == "quickshell" ]]; then
      printf '%s\n' "$pid"
      continue
    fi

    exe="$(readlink "$proc/exe" 2>/dev/null || true)"
    exe_base="${exe% (deleted)}"
    exe_base="${exe_base##*/}"
    if [[ "$exe_base" == "qs" || "$exe_base" == "quickshell" ]]; then
      printf '%s\n' "$pid"
      continue
    fi

    cmdline=""
    if [[ -r "$proc/cmdline" ]]; then
      cmdline="$(tr '\0' ' ' <"$proc/cmdline" 2>/dev/null || true)"
      cmdline="${cmdline%"${cmdline##*[![:space:]]}"}" # rtrim
    fi
    argv0="${cmdline%% *}"
    argv0="${argv0##*/}"
    if [[ "$argv0" == "qs" || "$argv0" == "quickshell" ]]; then
      printf '%s\n' "$pid"
      continue
    fi
  done
}

restart_quickshell() {
  local qs_bin=""
  command -v qs >/dev/null 2>&1 && qs_bin="qs" || qs_bin="quickshell"
  
  # Terminate existing instance
  $qs_bin -c ii kill 2>/dev/null || true
  local pids
  pids=($(collect_qs_pids))
  if [[ ${#pids[@]} -gt 0 ]]; then
    kill "${pids[@]}" 2>/dev/null || true
    # Wait up to 3 seconds for sockets and processes to terminate
    for _ in {1..30}; do
      local remaining=0
      for p in "${pids[@]}"; do
        if kill -0 "$p" 2>/dev/null; then remaining=1; break; fi
      done
      [[ "$remaining" -eq 0 ]] && break
      sleep 0.1
    done
  fi

  # Launch daemonized
  $qs_bin -c ii -d >/dev/null 2>&1 &
  sleep 1
}
```

### Pattern C: Native Linux Kernel Telemetry Sampling Engine (procfs & sysfs)
**Analog Source:** Linux Kernel Procfs Specification (`/proc/$PID/stat`, `/proc/$PID/smaps_rollup`, `/proc/$PID/status`, `/proc/$PID/io`) & `43.1-RESEARCH.md`

All metrics must be unprivileged, instantaneous, and zero-overhead without external binaries (`pidstat`, `strace`, `perf`):

```bash
# 1. Process CPU % (ticks / elapsed time)
sample_proc_cpu() {
  local pid="$1"
  local stat_line tail utime stime
  stat_line="$(cat "/proc/$pid/stat" 2>/dev/null || true)"
  [[ -n "$stat_line" ]] || return 1
  # Strip everything up to the last closing parenthesis to safely handle process names with spaces
  tail="${stat_line##*) }"
  # In tail: field 12 is utime, field 13 is stime
  read -r _ _ _ _ _ _ _ _ _ _ _ utime stime _ <<< "$tail"
  echo "$((utime + stime))"
}

# 2. Deep Memory Vector from smaps_rollup (kB to MB)
sample_proc_memory() {
  local pid="$1"
  local rss_kb=0 pss_kb=0 priv_dirty_kb=0
  if [[ -r "/proc/$pid/smaps_rollup" ]]; then
    while IFS=':' read -r key val; do
      val="${val//[^0-9]/}"
      case "$key" in
        Rss) rss_kb="$val" ;;
        Pss) pss_kb="$val" ;;
        Private_Dirty) priv_dirty_kb="$val" ;;
      esac
    done < "/proc/$pid/smaps_rollup"
  fi
  printf "%.2f %.2f %.2f\n" \
    "$(awk -v k="$rss_kb" 'BEGIN { printf "%.2f", k/1024 }')" \
    "$(awk -v k="$pss_kb" 'BEGIN { printf "%.2f", k/1024 }')" \
    "$(awk -v k="$priv_dirty_kb" 'BEGIN { printf "%.2f", k/1024 }')"
}

# 3. Threads & Context Switches from /proc/$PID/status
sample_proc_status() {
  local pid="$1"
  local threads=0 vol_ctx=0 nonvol_ctx=0
  if [[ -r "/proc/$pid/status" ]]; then
    while IFS=':' read -r key val; do
      val="${val//[[:space:]]/}"
      case "$key" in
        Threads) threads="$val" ;;
        voluntary_ctxt_switches) vol_ctx="$val" ;;
        nonvoluntary_ctxt_switches) nonvol_ctx="$val" ;;
      esac
    done < "/proc/$pid/status"
  fi
  echo "$threads $vol_ctx $nonvol_ctx"
}

# 4. Syscall Churn & I/O from /proc/$PID/io
sample_proc_io() {
  local pid="$1"
  local syscr=0 syscw=0 rbytes=0 wbytes=0
  if [[ -r "/proc/$pid/io" ]]; then
    while IFS=':' read -r key val; do
      val="${val//[[:space:]]/}"
      case "$key" in
        syscr) syscr="$val" ;;
        syscw) syscw="$val" ;;
        read_bytes) rbytes="$val" ;;
        write_bytes) wbytes="$val" ;;
      esac
    done < "/proc/$pid/io"
  fi
  echo "$syscr $syscw $rbytes $wbytes"
}

# 5. Open File Descriptors
sample_proc_fds() {
  local pid="$1"
  ls -1 "/proc/$pid/fd" 2>/dev/null | wc -l || echo 0
}
```

### Pattern D: Intel UHD 770 iGPU Telemetry Sampling
**Analog Source:** `restow/quickshell/.config/quickshell/ii/services/HardwareTelemetry.qml:337-369`

sample_intel_gpu() {
  local rc6_path="/sys/class/drm/card1/gt/gt0/rc6_residency_ms"
  local act_freq_path="/sys/class/drm/card1/gt_act_freq_mhz"
  local cur_freq_path="/sys/class/drm/card1/gt_cur_freq_mhz"

  local rc6_ms=0 freq_mhz=0
  [[ -r "$rc6_path" ]] && rc6_ms="$(cat "$rc6_path" 2>/dev/null || echo 0)"
  if [[ -r "$act_freq_path" ]]; then
    freq_mhz="$(cat "$act_freq_path" 2>/dev/null || echo 0)"
  elif [[ -r "$cur_freq_path" ]]; then
    freq_mhz="$(cat "$cur_freq_path" 2>/dev/null || echo 0)"
  fi
  echo "$rc6_ms $freq_mhz"
}

compute_gpu_load() {
  local d_rc6_ms="$1"
  local d_t_ms="$2"
  awk -v drc6="$d_rc6_ms" -v dt="$d_t_ms" 'BEGIN {
    if (dt <= 0) { printf "0.00"; exit; }
    idle_ratio = drc6 / dt;
    if (idle_ratio > 1.0) idle_ratio = 1.0;
    if (idle_ratio < 0.0) idle_ratio = 0.0;
    active_pct = (1.0 - idle_ratio) * 100.0;
    printf "%.2f", active_pct;
  }'
}

### Pattern E: GNU Stow Upstream Baseline Isolation Lifecycle
**Analog Source:** `arch/dots-hyprland.sh` Stow tree mechanics & `43.1-RESEARCH.md`

To isolate pristine upstream `dots-hyprland` (`illogical-impulse`), custom overlays must be unstowed via GNU Stow and the 16 original upstream `.bak` files temporarily restored:

```bash
STOW_ISOLATED=0
STUB_LIST_FILE="$(mktemp /tmp/p43.1-stubs-XXXXXX)"
TMP_FILES+=("$STUB_LIST_FILE")

isolate_upstream_baseline() {
  info "Isolating pure upstream baseline: unstowing restow/quickshell..."
  stow -D --no-folding -d "$REPO_ROOT/restow" -t "$HOME" quickshell 2>/dev/null || true
  
  # Restore upstream backup stubs (.bak -> active filename)
  local ii_dir="$HOME/.config/quickshell/ii"
  > "$STUB_LIST_FILE"
  while IFS= read -r bak_file; do
    [[ -n "$bak_file" ]] || continue
    local dir base target_name target
    dir="$(dirname "$bak_file")"
    base="$(basename "$bak_file")"
    target_name="${base%%.bak*}"
    target="$dir/$target_name"
    if [[ ! -e "$target" ]]; then
      cp "$bak_file" "$target"
      echo "$target" >> "$STUB_LIST_FILE"
    fi
  done < <(find "$ii_dir" -name "*.bak*" -type f)

  STOW_ISOLATED=1
  restart_quickshell
}

restore_restow_quickshell() {
  if [[ "$STOW_ISOLATED" -eq 1 ]]; then
    info "Restoring custom overlays: removing upstream stubs and restowing..."
    if [[ -f "$STUB_LIST_FILE" ]]; then
      while IFS= read -r target; do
        [[ -n "$target" ]] && rm -f "$target" 2>/dev/null || true
      done < "$STUB_LIST_FILE"
      > "$STUB_LIST_FILE"
    fi
    stow --no-folding -d "$REPO_ROOT/restow" -t "$HOME" quickshell 2>/dev/null || true
    STOW_ISOLATED=0
    restart_quickshell
  fi
}
```

```bash
run_sample_window() {
  local stage_id="$1"
  local stage_name="$2"
  local ui_mode="$3"
  local warmup_sec="${WARMUP_SEC:-5}"
  local duration_sec="${DURATION_SEC:-30}"

  info "Starting stage: $stage_name ($stage_id)"
  set_ui_state "$ui_mode"

  info "Stabilization warm-up (${warmup_sec}s)..."
  sleep "$warmup_sec"

  local pids=($(collect_qs_pids))
  if [[ ${#pids[@]} -eq 0 ]]; then
    fail "No Quickshell PID found for stage: $stage_id"
    return 1
  fi
  local pid="${pids[0]}"
  info "Profiling Quickshell PID: $pid"

  local clk_tck
  clk_tck="$(getconf CLK_TCK 2>/dev/null || echo 100)"

  # Baseline sample snapshot
  local t1 cpu_ticks1 vol_ctx1 nonvol_ctx1 syscr1 syscw1 rc6_1
  t1="$(date +%s%N)"
  cpu_ticks1="$(sample_proc_cpu "$pid")"
  read -r threads1 vol_ctx1 nonvol_ctx1 <<< "$(sample_proc_status "$pid")"
  read -r syscr1 syscw1 rbytes1 wbytes1 <<< "$(sample_proc_io "$pid")"
  read -r rc6_1 freq_mhz1 <<< "$(sample_intel_gpu)"

  # Periodic sampling during duration window
  local samples=0
  local peak_cpu=0.0
  local sum_cpu=0.0
  local last_ticks="$cpu_ticks1"
  local last_t="$t1"

  for ((i=1; i<=duration_sec; i++)); do
    sleep 1
    local now_t="$(date +%s%N)"
    local now_ticks="$(sample_proc_cpu "$pid")"
    local dt_sec="$(awk -v t1="$last_t" -v t2="$now_t" 'BEGIN { printf "%.4f", (t2 - t1)/1000000000.0 }')"
    local dticks="$((now_ticks - last_ticks))"
    local inst_cpu="$(awk -v dticks="$dticks" -v dt="$dt_sec" -v clk="$clk_tck" 'BEGIN { printf "%.2f", (dticks / (dt * clk)) * 100.0 }')"
    
    sum_cpu="$(awk -v s="$sum_cpu" -v c="$inst_cpu" 'BEGIN { printf "%.2f", s + c }')"
    peak_cpu="$(awk -v p="$peak_cpu" -v c="$inst_cpu" 'BEGIN { printf "%.2f", (c > p ? c : p) }')"
    samples=$((samples + 1))
    last_ticks="$now_ticks"
    last_t="$now_t"
  done

  # Final sample snapshot
  local t2="$(date +%s%N)"
  local total_dt_sec="$(awk -v t1="$t1" -v t2="$t2" 'BEGIN { printf "%.4f", (t2 - t1)/1000000000.0 }')"
  local total_dt_ms="$(awk -v t1="$t1" -v t2="$t2" 'BEGIN { printf "%.2f", (t2 - t1)/1000000.0 }')"

  local avg_cpu="$(awk -v sum="$sum_cpu" -v n="$samples" 'BEGIN { printf "%.2f", (n > 0 ? sum / n : 0.0) }')"
  read -r rss_mb pss_mb priv_dirty_mb <<< "$(sample_proc_memory "$pid")"
  read -r final_threads vol_ctx2 nonvol_ctx2 <<< "$(sample_proc_status "$pid")"
  read -r syscr2 syscw2 rbytes2 wbytes2 <<< "$(sample_proc_io "$pid")"
  read -r rc6_2 final_freq_mhz <<< "$(sample_intel_gpu)"
  local open_fds="$(sample_proc_fds "$pid")"

  # Rates computation
  local vol_ctx_rate="$(awk -v v1="$vol_ctx1" -v v2="$vol_ctx2" -v dt="$total_dt_sec" 'BEGIN { printf "%.1f", (v2 - v1) / dt }')"
  local nonvol_ctx_rate="$(awk -v n1="$nonvol_ctx1" -v n2="$nonvol_ctx2" -v dt="$total_dt_sec" 'BEGIN { printf "%.1f", (n2 - n1) / dt }')"
  local syscr_rate="$(awk -v s1="$syscr1" -v s2="$syscr2" -v dt="$total_dt_sec" 'BEGIN { printf "%.1f", (s2 - s1) / dt }')"
  local syscw_rate="$(awk -v s1="$syscw1" -v s2="$syscw2" -v dt="$total_dt_sec" 'BEGIN { printf "%.1f", (s2 - s1) / dt }')"
  local gpu_busy_pct="$(compute_gpu_load "$((rc6_2 - rc6_1))" "$total_dt_ms")"

  # Store structured results for JSON and Markdown report generation
  record_stage_result "$stage_id" "$stage_name" \
    "$avg_cpu" "$peak_cpu" "$rss_mb" "$pss_mb" "$priv_dirty_mb" \
    "$final_threads" "$vol_ctx_rate" "$nonvol_ctx_rate" \
    "$syscr_rate" "$syscw_rate" "$open_fds" "$gpu_busy_pct" "$final_freq_mhz"
}
```

## 4. Key Gotchas & Anti-Patterns to Prevent

1. **Unprotected Abort Leaving Tree Unstowed:**
   - *Problem:* If the operator presses Ctrl+C during the baseline stage, Quickshell would be left running with upstream stubs and without custom restow symlinks.
   - *Mitigation:* The bash trap `trap cleanup EXIT INT TERM` must unconditionally call `restore_restow_quickshell`, removing temporary stubs and re-running `stow --no-folding -d "$REPO_ROOT/restow" -t "$HOME" quickshell`.
2. **Process Restart Socket Collisions:**
   - *Problem:* Immediate invocation of `qs -c ii -d` after killing Quickshell fails if the previous process hasn't finished unmapping the Wayland socket.
   - *Mitigation:* Loop with `kill -0 "$pid"` with a 3-second timeout and 100ms sleeps before executing the new daemon command.
3. **Fragile `/proc/$PID/stat` Parsing:**
   - *Problem:* Process names with spaces (e.g. `(qs -c ii)`) break simple space-delimited `read` or `awk '{print $14}'`.
   - *Mitigation:* Always strip `tail="${stat_line##*) }"` before extracting fields 12 (`utime`) and 13 (`stime`).
4. **External Tool Dependency Failures:**
   - *Problem:* Scripts relying on `pidstat`, `iostat`, `strace`, or `perf` fail on minimal installations or unprivileged containers.
   - *Mitigation:* Rely 100% on Linux native unprivileged kernel files (`/proc/$PID/stat`, `smaps_rollup`, `io`, `status`, `/sys/class/drm/card1/`).
5. **Premature QML Refactoring in Profiling Phase:**
   - *Problem:* Modifying QML source files (like changing `ResourceUsage.qml` `interval: 1`) before capturing baseline data breaks reproducibility.
   - *Mitigation:* Enforce read-only constraint on all QML files during Phase 43.1. Document recommendations in `BENCHMARK.md` for Phase 44 instead.
6. **Git Churn on Benchmark Artifacts:**
   - *Problem:* Writing output files to unignored root paths fails `./arch/dots-hyprland.sh verify --strict`.
   - *Mitigation:* Store benchmark outputs within `.planning/phases/43.1-.../` (which is tracked under version control) and verify clean working tree in assert tests.

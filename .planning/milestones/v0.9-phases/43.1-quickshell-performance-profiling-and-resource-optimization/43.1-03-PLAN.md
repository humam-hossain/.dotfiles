# Plan 43.1-03: Performance Assertion Suite & Evidence-Based Optimization Framework

<objective>
Implement the automated regression test harness (`scripts/phase43-perf-assert.sh`) across five structured assertion sections, verifying harness safety traps, output artifact schemas, runtime resource leak ceilings (FDs < 150, idle CPU < 15%, RSS < 1200 MB, Private Dirty < 700 MB), static sensor and timer inventories, and zero working tree drift under `./arch/dots-hyprland.sh verify --strict`.
</objective>

<threat_model>
### ASVS L1 Threat Model Evaluation

- **Root Privilege Escalation Prevention:** `scripts/phase43-perf-assert.sh` immediately executes `[[ "${EUID:-$(id -u)}" -ne 0 ]]` to fail closed if invoked with `sudo` or `root`, preventing inadvertent root ownership of dotfiles or temporary files.
- **Resource Exhaustion & Handle Leak Guard (ASVS DoS Protection):**
  - Section 3 asserts that Quickshell's open file descriptors remain strictly below 150. Given that `HardwareTelemetry.qml` continuously monitors 23+ sysfs/procfs files via `FileView`, an unclosed handle bug would rapidly exhaust process descriptors and destabilize the desktop shell.
  - Section 3 asserts memory bounds (< 1200 MB RSS, < 700 MB Private Dirty) and steady-state CPU (< 15.0% of a single core) to prevent runaway resource leaks.
- **Concurrency & Process Interruption Safety (Edge Case Coverage):**
  - *Concurrency Probe:* If the test harness or profiling script is interrupted or terminated midway, signal traps guarantee temporary porcelain files and test fixtures in `/tmp` are removed, and GNU Stow symlinks are verified intact.
- **Submodule & Working Tree Drift Prevention (INTG-01):** Section 5 takes a porcelain snapshot before running tests and verifies identical porcelain state after execution (excluding benchmark output files). It then executes `./arch/dots-hyprland.sh verify --strict`, guaranteeing zero git drift across `vendor/dots-hyprland` and the parent repository.
</threat_model>

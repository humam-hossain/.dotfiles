# Phase 43.1: Quickshell Performance Profiling and Resource Optimization - Context

**Gathered:** 2026-09-27
**Status:** Ready for planning

<domain>
## Phase Boundary

Build a comprehensive, reusable, and future-proof diagnostic performance profiling harness (`scripts/profile-quickshell.sh`) to benchmark Quickshell resource consumption across CPU, memory (RSS, PSS, Private Dirty), threads, storage/sysfs I/O, and GPU render clock activity.

1. **Pure Upstream Baseline Measurement:**
   - Temporarily unstow `restow/quickshell/` to measure pristine upstream `dots-hyprland` (`illogical-impulse`) as the reference baseline.
2. **Modular Staged Attribution Matrix:**
   - Incrementally introduce custom overlays via a declarative component registry (Baseline $\rightarrow$ +Config/Bar $\rightarrow$ +Each Singleton independently $\rightarrow$ +Pills $\rightarrow$ +Popups) to isolate the exact marginal resource cost of each component.
3. **Comprehensive Diagnostic Metrics & Report:**
   - Produce `.planning/phases/43.1-quickshell-performance-profiling-and-resource-optimization/BENCHMARK.md` detailing the complete attribution matrix, context switches, file descriptors, and bottleneck findings.
   - Output machine-readable `.planning/phases/43.1-quickshell-performance-profiling-and-resource-optimization/benchmark-latest.json` supporting automated delta comparisons (`--compare`) for future phases (Phase 44, 45, 46).
4. **Evidence-Based Optimization Roadmap:**
   - Document concrete, data-backed optimization recommendations (sensor demand-gating, popup Loader lifecycle, idle sleep throttling) based on hard numbers rather than speculation.

**Out of scope:**
- Prematurely modifying or refactoring production QML components before baseline data is captured.
- Retiring or rewiring legacy `Resources.qml` and `ResourceUsage.qml` (scheduled for Phase 44 and Phase 46).
- `ddcutil` backlight polling and discrete GPU telemetry (strictly prohibited host constraints).

</domain>

<decisions>
## Implementation Decisions

### Baseline Isolation & Staging Architecture
- **D-01 (Upstream Baseline Isolation via GNU Stow):** Temporarily unstow `restow/quickshell` via `stow -D -d restow quickshell` to measure pure upstream `dots-hyprland` (`illogical-impulse`) baseline, then re-stow for staged runs. — **Reversibility:** reversible.
- **D-02 (Extensible Declarative Staging Registry):** `scripts/profile-quickshell.sh` defines a modular, configuration-driven array of stages/components rather than hardcoding Phase 43 items, enabling future components from Phase 44, 45, and 46 to be profiled without script rewrites. — **Reversibility:** reversible.
- **D-03 (Standardized Sampling Cadence):** 5-second stabilization warm-up (allowing QML compilation and font caching to settle) followed by a 30-second steady-state measurement per stage (~5 minutes full suite). — **Reversibility:** reversible.
- **D-04 (Harness Artifacts & Location):** Dedicated script `scripts/profile-quickshell.sh` outputting human-readable `BENCHMARK.md` and machine-readable `benchmark-latest.json` into `.planning/phases/43.1-quickshell-performance-profiling-and-resource-optimization/`. — **Reversibility:** reversible.

### Profiling Tools & Resource Metrics
- **D-05 (Native Unprivileged Kernel Metrics):** Zero-overhead data collection via Linux `/proc/$PID/status`, `/proc/$PID/smaps_rollup`, `/proc/$PID/io`, and `pidstat`. — **Reversibility:** reversible.
- **D-06 (Deep Memory Vector):** Profile total RSS (Resident Set Size), PSS (Proportional Set Size), and Private Dirty (exclusive physical RAM allocated by Quickshell QML heap/objects). — **Reversibility:** reversible.
- **D-07 (Host-Native GPU Metric):** Measure Intel UHD 770 iGPU load delta via `/sys/class/drm/card1/gt/gt0/rc6_residency_ms` and active render clock via `gt_act_freq_mhz` (100% unprivileged). — **Reversibility:** reversible.
- **D-08 (Process Storage & Sysfs I/O):** Measure `/proc/$PID/io` (read/write bytes and `syscr`/`syscw` read/write syscall rates) plus open file descriptor count (`/proc/$PID/fd`). — **Reversibility:** reversible.
- **D-09 (Thread Activity & Context Switches):** Track voluntary and non-voluntary context switches to isolate timer wakeups vs CPU starvation across active threads (currently ~70 threads). — **Reversibility:** reversible.
- **D-10 (Static Code Audit & Timer Hotspot Tally):** Cross-reference context switch counts with a static inventory of all QML timer intervals across singletons and components. — **Reversibility:** reversible.
- **D-11 (Dual-State UI Benchmarking):** Measure both Idle Steady-State (unhovered, stationary) and Active Interaction (hovered, popup open, animations running). — **Reversibility:** reversible.
- **D-12 (Bash Trap Restoration Guarantee):** Bash trap handlers (`EXIT/INT/TERM`) in `scripts/profile-quickshell.sh` guarantee that `restow/quickshell` is always re-stowed and working tree integrity is preserved, even upon abort. — **Reversibility:** reversible.

### Strategy & Scope Guardrails
- **D-13 (Phase Boundary & Legacy Service Preservation):** Retain legacy `Resources.qml` and `ResourceUsage.qml` without premature refactoring or rewiring in this phase, leaving their replacement strictly to Phase 44 (Memory/Storage) and Phase 46 (Left Zone). — **Reversibility:** reversible.
- **D-14 (Evidence-First Optimization Scope):** Focus Phase 43.1 strictly on diagnostic benchmarking and root-cause attribution; defer final reduction targets and major structural refactoring until hard baseline numbers are established. — **Reversibility:** reversible.
- **D-15 (Automated Test Suite Integration):** Create an automated test harness `scripts/phase43-perf-assert.sh` that checks steady-state CPU overhead, file descriptor leaks, and zero git churn, integrated with `arch/dots-hyprland.sh verify --strict`. — **Reversibility:** reversible.

### the agent's Discretion

- Command line flag naming (`--full`, `--stage`, `--compare`, `--json`) in `scripts/profile-quickshell.sh`.
- Intermediate temporary file management in `/tmp` during sampling runs.

## Existing Code Insights

### Reusable Assets
- `arch/dots-hyprland.sh verify --strict`: Verification wrapper enforcing zero git churn and symlink tree integrity.
- `stow` / `restow` tree structure: `restow/quickshell/` mirrors `~/.config/quickshell/ii/` via leaf symlinks, allowing clean isolation via `stow -D -d restow quickshell`.

### Established Patterns
- Unprivileged sysfs/procfs reading: Reading `/sys/class/hwmon`, `/sys/class/drm`, `/proc/stat`, and `/proc/$PID/` without root or daemon requirements.
- Signal traps in scripts: `trap cleanup EXIT INT TERM` widely used across `scripts/phase*.sh` to prevent left-behind state.

### Integration Points
- `scripts/profile-quickshell.sh`: New top-level benchmark script callable directly by operators and test suites.
- `scripts/phase43-perf-assert.sh`: Verification script callable from `arch/dots-hyprland.sh verify`.

# Plan 43.1-01: Baseline & Staged Resource Profiling Harness

<objective>
Build the core performance profiling harness (`scripts/profile-quickshell.sh`) capable of capturing pure upstream `dots-hyprland` reference metrics via GNU Stow baseline isolation (`stow -D` with `.bak` upstream stub restoration), sampling unprivileged Linux procfs and sysfs telemetry vectors (CPU %, deep memory RSS/PSS/Private Dirty, context switches, I/O syscall rates, open file descriptors, and Intel UHD 770 iGPU activity), and enforcing robust bash safety traps (`EXIT INT TERM`) to preserve working tree integrity under all conditions.
</objective>

<threat_model>
### ASVS L1 Threat Model Evaluation

- **Root Privilege Escalation Prevention:** Profiling and assertion scripts must run strictly under the unprivileged user session owning the Quickshell Wayland process. `scripts/profile-quickshell.sh` enforces `[[ "${EUID:-$(id -u)}" -ne 0 ]]` at entry to fail closed if executed with `sudo` or `root`, preventing inadvertent permission changes across `~/.config/quickshell/` or `/proc/`.
- **Command Injection & Argument Traversal:** All CLI arguments (`--stage`, `--json`, `--report`, `--warmup`, `--duration`) are parsed using strict case switching with regex validation for integer intervals (`^[0-9]+$`). Dynamic shell `eval` is strictly forbidden.
- **State Corruption & Working Tree Inconsistency (Reversibility Gate):** Baseline measurement requires unstowing `restow/quickshell` and copying temporary upstream `.bak` stubs into `~/.config/quickshell/ii/`. If the script is aborted (via `SIGINT`, `SIGTERM`, or error), an unhandled exit would leave the desktop without custom bar components and with loose unstowed files. A robust signal trap `trap cleanup EXIT INT TERM` unconditionally deletes temporary `.bak` copies, re-stows `restow/quickshell`, and restarts Quickshell before exiting, guaranteeing complete reversibility (D-01, D-12).
- **Process Race Condition & Wayland Socket Collision:** Terminating and restarting `qs -c ii` immediately can cause socket collision if the previous process has not released the Wayland display socket. The harness implements a polling loop with `kill -0 "$pid"` with a 3-second timeout and 100ms sleep intervals before spawning the daemonized replacement instance.
- **Unprivileged Telemetry Fallback (Edge Case Coverage):** In constrained environments where `/proc/$PID/smaps_rollup` or `/sys/class/drm/card1/` might have altered access permissions or be absent, sampling functions gracefully fall back to zero or `"N/A"` rather than terminating prematurely with an unhandled arithmetic error.
</threat_model>

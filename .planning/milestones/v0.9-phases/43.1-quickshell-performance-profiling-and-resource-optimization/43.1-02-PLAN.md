# Plan 43.1-02: Staged Attribution Matrix, Dual-State Profiling & Comprehensive Reporting

<objective>
Implement the extensible declarative staging registry, dual-state active UI benchmarking dispatcher via `ydotool`, static QML timer and FileView hotspot scanner, and report generation pipeline in `scripts/profile-quickshell.sh` to produce the comprehensive diagnostic attribution report (`BENCHMARK.md`) and machine-readable JSON telemetry export (`benchmark-latest.json`) with automated `--compare` baseline diffing.
</objective>

<threat_model>
### ASVS L1 Threat Model Evaluation

- **Malformed Data Injection & Serialization Security:** Data collected from procfs and sysfs is formatted into JSON and Markdown. To prevent arbitrary injection or malformed payloads, all numeric values are cast to strict floating point or integer types in Python/Bash before serialization. JSON export uses standard `json.dump` with proper indentation rather than raw string templating.
- **GUI Input Simulation Safety & Display Boundary Guard:** Dual-state benchmarking utilizes `ydotool` to simulate cursor movement. Uncontrolled or infinite mouse events could disrupt other user applications. Input dispatching is strictly constrained to predetermined safe coordinates (`x=1000, y=500` for idle and `x=180, y=20` for top bar hover). If `ydotool`, `ydotoold`, or `WAYLAND_DISPLAY` is missing or inaccessible, the dispatcher gracefully soft-skips active UI simulation without failing the harness.
- **Boundary & Null Telemetry Handling (Edge Case Coverage):**
  - *Adjacency Probe:* When comparing metrics that are numerically identical between two benchmark runs (delta = 0.00), the diff engine formats output as `+0.00` or `0.00` without triggering division-by-zero or NaN in percentage calculations.
  - *Empty/Null Probe:* If a stage fails to record telemetry or produces null/empty metrics, the reporting engine falls back to `"N/A"` or `0.0` gracefully instead of aborting table generation.
  - *Ordering Probe:* Output stages in both Markdown tables and JSON dictionaries maintain stable, deterministic ordering matching the declarative registry schema.
</threat_model>

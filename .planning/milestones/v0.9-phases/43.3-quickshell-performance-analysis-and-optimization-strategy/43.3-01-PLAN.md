### ASVS Level: 1 Threat Model Evaluation

- **Planning Artifact & Decision Integrity:** Optimization decisions (D-01 through D-12) govern critical desktop shell telemetry and UI rendering loops. Falsification or dilution of locked operator decisions could lead to regressions or missed performance targets. Mitigation: Every locked decision from 43.3-CONTEXT.md is explicitly formalized with its exact identifier, trade-offs, and reversibility rating, validated via automated grep tests.
- **Verification Harness Execution Safety:** Assertion suites (`scripts/phase43-perf-assert.sh` and `arch/dots-hyprland.sh verify --strict`) run in read-only and non-destructive modes during planning. Scripts must not run with root privileges (`EUID -ne 0`) or mutate runtime session state. Mitigation: Automated commands specify `--quick` and `--strict` without destructive flags.
- **Unauthorized Production Code Mutation (Zero Churn Gate):** Phase 43.3 is strictly analytical and architectural; no production QML files under `restow/quickshell/` may be altered. Any modification to runtime QML components during this phase represents an unauthorized scope breach. Mitigation: Automated verification confirms `git diff --name-only` contains zero files outside the `.planning/` directory.
- **Privilege Escalation & Environment Pollution:** Planning tasks must execute solely within the unprivileged user session owning the Quickshell Wayland compositor instance. All commands are run with unprivileged shell execution.
</threat_model>

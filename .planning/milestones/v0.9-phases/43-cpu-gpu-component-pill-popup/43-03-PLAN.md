<threat_model>
### ASVS L1 Threat Model Evaluation

- **Zero-Root RAPL / Platypus Mitigation Enforcement:** The Linux kernel restricts read permissions on Intel RAPL energy attributes (`/sys/class/powercap/intel-rapl/intel-rapl:0/energy_uj`) to root (`0400`) as a defense-in-depth mitigation against CVE-2020-8694 / CVE-2020-8695 (Platypus side-channel power attacks). In accordance with Phase 42 locked decision D-05, `CpuGpuPopup.qml` strictly refrains from executing suid wrappers, privileged daemons, or probing root-only power paths. Instead, it renders an explicit unprivileged placeholder string `"N/A (unprivileged)"`, completely eliminating privilege escalation exposure while fulfilling the CPU telemetry row specification cleanly.
- **Reference Counting Leak / Denial of Service Prevention:** `HardwareTelemetry` switches from 3000ms idle polling to 1000ms fast polling based on `fastPollingRequests > 0`. If `CpuGpuPopup` increments this counter when opened but fails to decrement on destruction (e.g. if the user swiftly switches workspaces or closes the bar), `fastPollingRequests` will leak positive, pinning the polling timer at 1000ms and causing permanent background CPU overhead. To prevent this, refcount decrementing is registered in both `onActiveChanged` (`if (!active) HardwareTelemetry.fastPollingRequests--`) and `Component.onDestruction` (`if (active) HardwareTelemetry.fastPollingRequests--`).
- **Input Encoding & String Sanitization:** Telemetry readouts, frequency displays, and status badges use standard UTF-8 strings (`QString`). Material Symbols ligatures (`planner_review`, `speed`, `developer_board`, `device_thermostat`) are rendered from validated ASCII glyph identifiers. Degree symbols are UTF-8 code point `U+00B0` (`°`). Status evaluations (`gpuThrottled ? "Throttling" : "Normal"`) use strict boolean checks, preventing arbitrary string reflection or layout corruption.
- **Symlink & File System Integrity:** The deployment step backs up any pre-existing plain file at `~/.config/quickshell/ii/modules/ii/bar/StyledPopup.qml` to `.bak` prior to invoking GNU Stow. This avoids stow folding errors and ensures that `vendor/dots-hyprland` remains 100% pristine with zero untracked git mutations.
</threat_model>

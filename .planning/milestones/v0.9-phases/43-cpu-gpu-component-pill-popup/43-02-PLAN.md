# Plan 43-02: Top Bar Status Pill (`CpuGpuPill.qml`)

<objective>
Implement the top bar telemetry status pill (`restow/quickshell/.config/quickshell/ii/modules/ii/bar/CpuGpuPill.qml`) displaying live CPU load %, CPU Package Temp (°C), and Intel UHD 770 iGPU load % with distinct Material Symbols icons (`planner_review`, `speed`), fluid 250ms Material 3 width resizing, responsive narrow-screen temperature hiding, independent two-tier alert coloring (Amber warning at 70%/75°C, Red critical at 90%/85°C), breathing pulse animation under critical load, and completely inert click handling.
</objective>

<threat_model>
### ASVS L1 Threat Model Evaluation

- **UI Event Hijacking / Click-Through Prevention:** Status bar pills sit persistently at the top layer of the user desktop interface. If mouse clicks bleed through an unhandled component, unintended click events could activate underlying client application windows or quick-settings menus. `CpuGpuPill.qml` encapsulates a re-parented `MouseArea` capturing `acceptedButtons: Qt.AllButtons` and inertly consuming `onPressed` and `onClicked` (`event => event.accepted = true`) (D-17), ensuring mouse clicks are completely inert.
- **Input Robustness & Coalescing (Empty / Null Telemetry Fallback):** During desktop initialization or wake from sleep, sysfs sensor readings in `HardwareTelemetry` may momentarily return null, empty strings, or NaN. The component strictly guards all numerical evaluations with coalesced defaults (`(HardwareTelemetry.overallCpuLoad || 0.0)`, `(HardwareTelemetry.packageTemp || 0)`, `(HardwareTelemetry.gpuLoad || 0.0)`). Alert predicates evaluate cleanly to false during uninitialized states, preventing visual flicker, runaway NaN calculations, or erroneous alert triggering.
- **Resource Exhaustion & UI Animation Runaway:** Continuous animations can leak CPU/GPU rendering power if left running indefinitely. The critical breathing pulse animation activates strictly when `running: root.cpuCritical` or `root.gpuCritical`. When alert levels recede, `onRunningChanged` forces `opacity = 1.0` immediately, guaranteeing the animation stops and leaves the icon at full opacity.
</threat_model>

# Plan 43-07: Gap Closure — ThreadMeter Render Optimization, Stable GPU Clock, EPP Button Removal & Platform Sensor Hierarchy

<objective>
Close UAT gap G-43-5-2 by:
1. **ThreadMeter Render Overhead Optimization in `CpuGpuPopup.qml`:**
   - Replace heavy `StyledProgressBar` control instances in `ThreadMeter` (which instantiate 20 concurrent `Behavior on value` animations forcing continuous 60fps Wayland scene graph repainting) with a lightweight, zero-animation static `Rectangle` progress bar (track and fill).
   - This eliminates continuous compositor redraws and drastically drops GPU and CPU resource usage when the popup is open.
2. **GPU Render Clock Stability in `HardwareTelemetry.qml`:**
   - Update GPU frequency reader to check `/sys/class/drm/card1/gt_cur_freq_mhz` (or fallback when `gt_act_freq_mhz` is 0) so the render clock consistently reports the active operating frequency instead of fluctuating to 0 MHz during microsecond RC6 idle states.
3. **EPP Switcher Button Removal in `CpuGpuPopup.qml`:**
   - Completely remove the redundant interactive EPP button from `CpuGpuPopup.qml` as requested by the user.
4. **Platform Sensors Typography & Hierarchy in `CpuGpuPopup.qml`:**
   - Convert the 6 platform sensors from a 2-column grid into clean rows with labels on the left and °C temperatures on the right.
   - Reduce typography to match the CPU core meters (`Appearance.font.pixelSize.smaller`).
   - Retain dynamic temperature threshold colors (amber warning, red critical) on all 6 sensors.
5. Update assertion harness, verify strict Stow deployment, and reload Quickshell (`qs -c ii`).
</objective>

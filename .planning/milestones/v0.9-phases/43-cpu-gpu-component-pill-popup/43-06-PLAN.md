# Plan 43-06: Gap Closure — Telemetry Resource Optimization, Layout Restructuring, Amber Warning Colors & Breathing Pulse

<objective>
Close UAT gaps G-43-1, G-43-4, G-43-5, and G-43-6 by:
1. **Resource & Polling Optimization in `HardwareTelemetry.qml`:**
   - Eliminate unnecessary background CPU and subprocess churn by decoupling `fastPolling` from baseline idle GPU load (`gpuLoad > 0.15`), reserving fast polling (1000ms) strictly for when the popup is open (`fastPollingRequests > 0`) or active high load (`overallCpuLoad > 0.50`).
   - Only execute `powerprofilesctl get` subprocess when the popup is opened or on profile changes, rather than every second in the background.
   - Smooth Intel UHD 770 GPU load calculation using an exponential moving average (EMA) on RC6 sleep deltas to eliminate erratic 70–80% spikes during bar idle.
   - Expose individual core temperatures array (`pCoreTemps` and `eCoreTemps`) from `coretemp` to support per-thread temperature readouts.
2. **Pill Colors & Breathing Animation in `CpuGpuPill.qml`:**
   - Replace `Appearance.colors.colTertiary` (which dynamically resolved to sky blue) with dots-hyprland amber warning color (`#FFA000`), preserving `Appearance.colors.colError` for critical red and `Appearance.colors.colOnLayer1` for normal.
   - Add multi-tier temperature color thresholds (warning >= 65°C, critical >= 80°C).
   - Expand the breathing pulse animation to modulate opacity across text labels (`cpuText`, `tempText`, `gpuText`) and circular indicators, not just the inner icon.
3. **Popup Layout Restructuring, Widening & Typography in `CpuGpuPopup.qml`:**
   - Widen popup column width from 230px to 320px, eliminating any label wrapping and text overlap.
   - Restructure CPU inspector layout into the unified format:
     - Overall CPU: `[Overall MHz] [Total Load %] [Package Temp °C]` followed by progress bar.
     - P-Core Section Header: `[Avg P-Core MHz] [P-Core Load %] [P-Core Avg Temp °C]` followed by progress bar.
     - Individual P-Core Threads (C0–C11): `C{n}`, thread load bar, `${load}%`, `${mhz} MHz`, and `${coreTemp}°C`.
     - E-Core Section Header: `[Avg E-Core MHz] [E-Core Load %] [E-Core Avg Temp °C]` followed by progress bar.
     - Individual E-Core Threads (C12–C19): `C{n}`, thread load bar, `${load}%`, `${mhz} MHz`, and `${coreTemp}°C`.
     - Remove redundant standalone rows for "Package Temp" and "P-Core / E-Core Avg".
   - Restyle Platform / Motherboard sensors:
     - Enlarge typography to match CPU core meters (`Appearance.font.pixelSize.small`).
     - Replace muted gray (`colSubtext`) with crisp white (`Appearance.colors.colOnLayer1`).
     - Bind temperature alert threshold colors (amber warning, red critical) to all 6 platform sensors.
   - Add breathing pulse animation to critical metrics inside the popup.
4. Update assertion scripts (`scripts/phase43-cpu-gpu-assert.sh`), verify strict Stow deployment, and reload Quickshell (`qs -c ii`).
</objective>

<threat_model>
### ASVS L1 Threat Model Evaluation

- **Unprivileged Execution:** All sensor reads continue to use sysfs/procfs directly without root. `powerprofilesctl` is invoked via unprivileged DBus client.
- **Resource Denial of Service (DoS) Mitigation:** Polling frequency is strictly rate-limited (3000ms idle, 1000ms active popup), eliminating subshell forking churn and reducing idle CPU load to < 0.5%.
- **Bounds Checking:** Logical CPU thread models and core temperature arrays are clamped strictly to 20 threads (12 P + 8 E) with safe default fallbacks preventing out-of-bounds QML array accesses.
</threat_model>

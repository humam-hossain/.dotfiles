<threat_model>
### ASVS L1 Threat Model Evaluation

- **Root Privilege Escalation Prevention:** Test assertion scripts and Quickshell components must operate strictly under an unprivileged user session. The test harness immediately enforces `[[ "${EUID:-$(id -u)}" -ne 0 ]]` to fail closed if executed under `sudo` or `root`, preventing inadvertent file ownership drift or privilege escalation across `~/.config/quickshell/`.
- **Injection & Path Traversal:** The assert script operates strictly with pinned paths relative to `$REPO_ROOT` determined via `BASH_SOURCE[0]`. Untrusted user arguments are strictly regex-validated (e.g. `^[1-5]$` for sections) with zero dynamic shell `eval` usage.
- **Denial of Service / Unbounded Event Loop Cycles:** In `StyledPopup.qml`, window active states are controlled by a single-shot `Timer` (`interval: 200`, `repeat: false`). This guarantees the timer fires once upon mouse exit and cancels cleanly on re-entry, preventing polling loops or high CPU consumption in the Qt Quick scene graph.
- **Geometry Underflow & Wayland Compositor Stability:** Center coordinate calculations for popups on left-zone bar items can yield negative X offsets (`(targetWidth - popupWidth) / 2 < 0`). Unchecked negative margins passed to `wlr-layer-shell` can crash the shell or create unmapped windows. Enforcing `Math.max(minX, Math.min(targetX, maxX))` with `minX = Appearance.sizes.hyprlandGapsOut` guarantees strictly bounded, non-negative geometry.
</threat_model>

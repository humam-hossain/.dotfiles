## End-to-End User Flow Verification

1. **Power Profile Switching Flow (Phase 38):**
   User clicks Quick Toggle in Right Sidebar -> D-Bus method call switches hardware profile (`power-saver` -> `balanced` -> `performance`) -> `PropertiesChanged` signal reactively updates icon and label. External `powerprofilesctl` stays synchronized. (**PASSED**)
2. **Dynamic Media Popup Positioning & Clamping Flow (Phase 39):**
   User clicks Media pill in Top Bar or Vertical Bar -> `updateMediaPillCoords()` captures scene coordinates -> `MediaControls.qml` opens directly beneath pill clamped to display bounds. Dismissal resets to `-1` fallback. (**PASSED**)
3. **Notification 1-Click Dismissal & Smart Click Flow (Phase 40):**
   Notification card arrives -> clicking header 'X' dismisses card immediately without expanding. Clicking body invokes default D-Bus action, falls back to web URL in browser, copies content/OTP to clipboard, and closes sidebar. (**PASSED**)
4. **Smart OTP Extraction & 1-Click Copy Flow (Phase 40):**
   2FA verification message arrives -> `NotificationUtils.extractOtpCode()` detects code -> `NotificationItem.qml` displays "Copy [Code]" chip -> clicking chip copies code to clipboard with 1.5s "Copied!" feedback without opening unwanted apps. (**PASSED**)
5. **Unified Volume Control Flow (Phase 40.1):**
   Volume up keybind raises volume up to 150% ceiling via `wpctl`. Mouse wheel scroll over bar volume pill steps by 2%, auto-unmutes, and clamps at 150%. Right sidebar slider smoothly drags to 150% with tactile 100% stop notch. (**PASSED**)
6. **Automated Assertion & Strict Verification Flow (Phase 41):**
   `./scripts/phase41-interactions-assert.sh` runs all 6 sections and orchestrates 4 sub-harnesses (`phase38`, `phase39`, `phase40`, `phase40.1`). `./arch/dots-hyprland.sh verify --strict` exits 0 with `FAIL=0 FINDINGS=0` and zero git churn. (**PASSED**)

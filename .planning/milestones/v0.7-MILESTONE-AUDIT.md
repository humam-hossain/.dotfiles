## End-to-End User Flow Verification

1. **STT Active Recording Flow:** User speaks -> `voice.py` creates `recorder.pid` -> `Voice.qml` transitions to `recording` -> duration counter updates live from `0:00` -> `VoicePill.qml` shifts to `colPrimary` with pulsing `graphic_eq` symbol -> M3 width expands to ~63px. (**PASSED**)
2. **STT Transcribing & Typing Flow:** Recording ends -> state shifts to `transcribing` -> duration freezes -> pulse stops (opacity resets to 1.0) -> color shifts to `colTertiary` with "Transcribing..." badge (~125px) -> transitions to `typing` with `colSecondary` and "Typing..." badge. (**PASSED**)
3. **Wrap-up & Idle Transition Flow:** Typing completes -> service enters `idle` -> `VoicePill.qml` holds final recorded duration for 1500ms via `wrapUpTimer` -> fluid deceleration contraction back to 26px resting size in `colOnLayer1`. (**PASSED**)
4. **TTS Speech Playback Flow:** Text synthesised via Kokoro -> `tts.pid` created -> `Voice.qml` extracts `--tts-voice` and `--tts-backend` -> `overallState = "speaking"` -> `VoicePill.qml` displays playback duration in `colSecondary`. (**PASSED**)
5. **Stale Lock & Crash Recovery Flow:** Speech process crashes or exits abnormally -> `/proc/<pid>/cmdline` fails validation -> `Voice.qml` purges stale file via `Quickshell.execDetached` -> logs discrete console warning -> state returns cleanly to `idle`. (**PASSED**)
6. **Multi-Monitor & Vertical Adaptation Flow:** Full-width screens expand normally; narrow screens (`useShortenedForm: 2`) suppress text to resting 26px icon-only state; vertical bars remain centered without horizontal expansion. (**PASSED**)
7. **Event Isolation Flow:** Accidental mouse clicks on `VoicePill` are captured and consumed by `inertMouseArea` (`Qt.AllButtons`), preventing accidental toggles of the right sidebar. (**PASSED**)

## Context
This plan addresses two issues in `BarContent.qml`:
1. **G-02-9 (Cosmetic)**: The left module cluster (LeftSidebarButton, Workspaces, Resources) has ad-hoc margins from an older layout and a 0-spacing RowLayout, making it look disjointed and sparse.
2. **G-02-10 (Major)**: Mute and mic indicator icons are purely visual. They reside inside a parent `RippleButton` and under a global `barRightSideMouseArea`, both of which trigger the right sidebar on click. We need independent hit targets for mute/mic to toggle their respective states.

## Tasks

### 1. Fix Left Cluster Spacing (G-02-9)
In `.config/quickshell/modules/ii/bar/BarContent.qml`, update `leftSectionRowLayout`:
- Set `spacing: 6` (or a similar small, uniform value).
- Remove `Layout.leftMargin: 10` and `Layout.rightMargin: 4` from `Workspaces`.
- Remove `Layout.rightMargin: Appearance.rounding.screenRounding` from `Resources`.
- Wrap the items in a visual container if appropriate, or let the `spacing` and `RowLayout` handle the tight grouping organically.

### 2. Make Mute and Mic Icons Clickable (G-02-10)
In `.config/quickshell/modules/ii/bar/BarContent.qml`, inside the `indicatorsRowLayout`:
- Inside the mute `MaterialSymbol`, add a `MouseArea` as its child.
  - Set `anchors.fill: parent` on the `MouseArea` so it fills the `MaterialSymbol` without causing layout conflicts in the `RowLayout`.
  - In `onClicked`, call `Audio.toggleMute()`.
  - Set `mouse.accepted = true` to prevent the click from propagating to the parent `RippleButton`.
- Inside the mic `MaterialSymbol`, add a `MouseArea` as its child.
  - Set `anchors.fill: parent` on the `MouseArea`.
  - In `onClicked`, call `Audio.toggleMicMute()`.
  - Set `mouse.accepted = true` to prevent propagation.
- Ensure the `barRightSideMouseArea` does not swallow clicks over the indicators. You may need to adjust `z` values or change `barRightSideMouseArea` so it doesn't overlap the indicators pill, OR use `propagateComposedEvents: true` in the overlays. If the `RippleButton` already catches clicks normally, just the inner `MouseArea` interception should be enough, provided the overlays aren't blocking.

## Verification
- Verify the left modules (LeftSidebarButton, Workspaces, Resources) are tightly grouped with uniform spacing.
- Verify clicking the Mute icon toggles mute (and does NOT open the right sidebar).
- Verify clicking the Mic icon toggles mic mute (and does NOT open the right sidebar).
- Verify clicking elsewhere in the indicators pill (e.g. Bluetooth/Network) still opens the right sidebar.

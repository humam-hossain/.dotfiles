## Context

**Gap G-02-12 (cosmetic):** The previous fix (02-09) set `spacing: 6` on `leftSectionRowLayout`, but the RowLayout still has `anchors.fill: parent`. The parent `FocusedScrollMouseArea` stretches from `parent.left` to `middleSection.left` — half the screen width. Because the three child modules don't use `Layout.fillWidth`, they cluster at their natural sizes inside a container that spans ~50% of the screen. The `spacing: 6` IS working between the modules, but the overall visual impression is "spaced too far apart" because the RowLayout container is enormous and the modules float inside it.

**Root cause:** `anchors.fill: parent` on the RowLayout.

**Fix:** Anchor the RowLayout to the left edge + top/bottom (for vertical centering via `fillHeight`) instead of filling the entire parent. The `FocusedScrollMouseArea` must keep its current anchors (left edge to middleSection.left) so brightness scroll and left-click-to-sidebar still work across the entire left half.

## Tasks

### Task 1: Anchor leftSectionRowLayout to left edge only

**File:** `.config/quickshell/modules/ii/bar/BarContent.qml`

**Current (line 82):**
```qml
anchors.fill: parent
```

**Replace with:**
```qml
anchors.left: parent.left
anchors.top: parent.top
anchors.bottom: parent.bottom
```

This makes the RowLayout size to its content width (implicitWidth from the three modules + spacing) while still filling the parent's height. The `FocusedScrollMouseArea` parent continues to cover the full left region for scroll/click events — the RowLayout just doesn't stretch to fill it.

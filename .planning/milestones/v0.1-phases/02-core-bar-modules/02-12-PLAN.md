## Context

**Gap G-02-13 (major):** Left sidebar opens from empty bar clicks and top-left corner hover. User wants open only via the left-sidebar button.

**Root causes:**
1. `barLeftSideMouseArea.onPressed` in `BarContent.qml` toggles `GlobalStates.sidebarLeftOpen` on any left-click across the left half.
2. `ScreenCorners.qml` TopLeft action + live `sidebar.cornerOpen.clicklessCornerEnd: true` toggles the same flag when the pointer enters the top-left corner edge (no click).

Debug: `.planning/debug/left-sidebar-empty-click-hover.md`

## Tasks

### Task 1: Remove empty-bar left-sidebar toggle

**File:** `.config/quickshell/modules/ii/bar/BarContent.qml`

In `barLeftSideMouseArea`, remove the `onPressed` handler that toggles `GlobalStates.sidebarLeftOpen` (lines ~65–68). Keep:
- `onScrollDown` / `onScrollUp` brightness
- `onMovedAway` OSD close
- `ScrollHint` and `leftSectionRowLayout` children unchanged

`LeftSidebarButton` already toggles the sidebar on its own `onPressed` — that remains the only open path from the bar.

### Task 2: Disable corner-open for sidebars

Dual-write so corner hover/click no longer opens sidebars:

**File:** `.config/quickshell/modules/common/Config.qml` — under `sidebar.cornerOpen`:
- Set `property bool enable: false`

**File:** `/home/pera/.config/illogical-impulse/config.json` — under `sidebar.cornerOpen`:
- Set `"enable": false`

Do not change `ScreenCorners.qml` action map unless enable alone is insufficient (enable=false already gates the Loader via `Config.options.sidebar.cornerOpen.enable`).

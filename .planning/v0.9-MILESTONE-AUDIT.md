## 1. Milestone Overview & Definition of Done

Milestone v0.9 delivers a complete hardware telemetry and status bar resource monitoring suite for Quickshell under Hyprland, featuring:
1. **Telemetry Services & Singletons:** Dedicated background services (`HardwareTelemetry`, `ResourceUsage`, `StorageUsage`, `PingService`, `NetworkUsage`) acquiring CPU/GPU metrics, memory tiers, multi-mount drive states, network throughput, and multi-target ping latencies without blocking the Qt Quick event loop.
2. **Interactive Status Bar Components:** Three standalone Left-Zone pills (`CpuGpuPill`, `MemoryStoragePill`, `NetworkPingPill`) paired with rich popup inspector overlays (`CpuGpuPopup`, `MemoryStoragePopup`, `NetworkPingPopup`).
3. **Ergonomic Enhancements:** Universal 1000ms hover intent delay with 200ms boundary grace period (`POPUP-01`), dynamic hardware model and core topology discovery (`CPUGPU-05`, `CPUGPU-06`), and responsive width animations.
4. **Status Bar Zone Reorganization:** Center Zone reordered with Clock left of Workspaces and Weather right of Workspaces (`CNTR-01..03`); Right Zone media player dynamically scaled to monitor width with complete metadata (`RGHT-01..02`); System tray reactive gating when empty (`RGHT-03`).
5. **Deep Resource Profiling & Optimization:** Stationary idle CPU reduced to 1.68% (<= 2.0%), context switches reduced to 72/s (< 100/s), read syscalls reduced to 38/s (< 50/s), MediaControls FBO blurs eliminated, and popup scenegraph throttled.
6. **Repository & Deployment Integrity:** All configurations deployed via GNU Stow leaf symlinks under `restow/quickshell/` without folding parent directories, maintaining submodule `vendor/dots-hyprland` pristine with 0 git churn and passing `./arch/dots-hyprland.sh verify --strict`.

## 5. Non-Critical Tech Debt & Operational Warnings

1. **Intermediate Sub-Phase VERIFICATION.md Omission (Phases 43.2 & 43.4):**
   - *Impact:* Low. All plans in both phases were executed with passing test runs and documented in SUMMARY.md and BENCHMARK.md. Requirements assigned to these inserted sub-phases (`PERF-01..03`) are tracked and verified in Phase 43.1 and Phase 50.
2. **External Local Ping Daemon Dependency (`PingService.qml`):**
   - *Impact:* Handled. `PingService` connects to `http://127.0.0.1:8765/api/status`. If the daemon is stopped, `handleOffline()` triggers graceful UI degradation (`-- ms`, offline badges, offline popup banner, and 15s poll backoff) without UI stutter.
3. **Unprivileged RAPL Power Reading (`HardwareTelemetry.qml`):**
   - *Impact:* Handled. `/sys/class/powercap/intel-rapl` requires root permissions on standard Linux kernels. An explicit placeholder (`"N/A (unprivileged)"`) renders cleanly in `CpuGpuPopup` while thermal, frequency, and load metrics function normally.
4. **CPUGPU-07 Process Tree UI Streamlining:**
   - *Impact:* Handled per Phase 43.6 ADR. The hierarchical process attribution tree engine was removed from the active QML scenegraph to eliminate background process polling overhead, while the standalone Python engine (`process_tree.py`) is retained for standalone CLI diagnostics.

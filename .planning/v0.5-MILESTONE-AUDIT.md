## End-to-End User Flows

### Flow 1: Dynamic Theme Generation & Propagation Flow
* **Command:** `switchwall.sh /path/to/image` (or `--noswitch` / `--color "#hex"`)
* **Status:** **COMPLETE**
* **Verification Trace:**
  1. **Pre-process:** Sets GNOME desktop `color-scheme` to `prefer-dark` and `gtk-theme` to `adw-gtk3-dark` via `gsettings`.
  2. **Generator Invocation:** Executes `matugen` synchronously using templates from `~/.config/matugen/config.toml`.
  3. **GTK 3 & GTK 4 Propagation:** Writes `~/.config/gtk-3.0/gtk.css` and `~/.config/gtk-4.0/gtk.css` with valid Material You tokens and GTK 4 `.boxed-list row:disabled` selector (zero parser warnings).
  4. **Hyprland Accent Propagation:** Writes `~/.config/hypr/hyprland/colors.lua`; live running compositor re-evaluates `active_border` and `inactive_border` via inotify without restarting the compositor.
  5. **Quickshell ii Accent Propagation:** Writes `~/.local/state/quickshell/user/generated/colors.json`; Quickshell FileWatcher detects mtime update and reactively updates bar/widget colors.
  6. **Launcher & Terminal Propagation:** Writes `~/.config/fuzzel/fuzzel_theme.ini`; `applycolor.sh` compiles `kitty-theme.conf` and `sequences.txt`; signals running Kitty terminal instances via `killall -SIGUSR1 kitty 2>/dev/null || true` and streams escape codes into `/dev/pts/*`.
  7. **Qt & KDE Harmonization:** Asynchronously invokes `kde-material-you-colors-wrapper.sh`, extracting color seed, activating virtualenv with fallback `${ILLOGICAL_IMPULSE_VIRTUAL_ENV:-$XDG_STATE_HOME/quickshell/.venv}`, and updating `~/.config/kdeglobals` with `ColorScheme=MaterialYouDark` and compliant dark window luminance.
  8. **Repository Cleanliness:** Guard paths and `.gitignore` ensure **zero git working tree drift** (`git status --porcelain` remains byte-identical).

### Flow 2: Fresh Bootstrap & Stow Reconciliation Flow
* **Command:** `./bootstrap.sh`
* **Status:** **COMPLETE**

  1. **Step 4 (Destubbing):** Destubs conflicts and prunes stale root-owned Catppuccin symlinks in `~/.config/gtk-3.0` and `~/.config/gtk-4.0` while preserving generated regular files.

Stows packages from `stow/` and `restow/` cleanly.

## End-to-End User Flows

### 1. Coordinated Wallpaper Change & Dynamic Theme Propagation
- **Command:** `switchwall.sh /path/to/image` (or `--noswitch` / `--color "#hex"`)
- **Status:** **COMPLETE**
- **Flow:**
  1. Sets GNOME desktop dark mode and `adw-gtk3-dark` theme via `gsettings`.
  2. Runs `matugen` synchronously to generate GTK 3, GTK 4, Hyprland borders, Hyprlock, Fuzzel, Quickshell JSON, and KDE color seeds.
  3. Live compositor inotify updates Hyprland border gradients without restarting the compositor.
  4. Quickshell FileWatcher updates widget colors in-place.
  5. `applycolor.sh` updates `kitty-theme.conf`, emits `SIGUSR1` to Kitty, and pours `sequences.txt` into active `/dev/pts/*` terminals.
  6. Subshell asynchronously executes `kde-material-you-colors`, updating `~/.config/kdeglobals`.

### 2. Cold Machine Bootstrap
- **Command:** `./bootstrap.sh`
- **Status:** **COMPLETE**
- **Flow:**
  1. Verifies prerequisites and submodule state.
  2. Runs `arch/*.sh` installers with `PAIR_COUNT == 18` invariant intact (`arch/kitty.sh` stowing from `restow/`).
  3. Pre-creates sensitive directories preventing GNU Stow folding.
  4. Destubs foreign files and safely prunes legacy Catppuccin symlinks while preserving guarded theme paths.
  5. Stows personal configuration packages.
  6. Sanitizes GTK 4 template and runs initial theme generation with fail-soft color fallback.
  7. Activates `dotfiles-capture.timer` and gates completion 1:1 on `./arch/dots-hyprland.sh verify --strict`.

### 3. Cross-Cutting: Virtualenv Variable Fallback Outside Hyprland
- **Item:** `ILLOGICAL_IMPULSE_VIRTUAL_ENV` is set by `hyprland/env.lua` inside an active Hyprland session. If `switchwall.sh` or `bootstrap.sh` is invoked outside a graphical session (e.g., TTY, SSH), sourcing the virtualenv in `switchwall.sh` and `kde-material-you-colors-wrapper.sh` fails softly without default parameter fallback (`${ILLOGICAL_IMPULSE_VIRTUAL_ENV:-$HOME/.local/state/quickshell/.venv}`).
- **Impact:** Does not affect live Hyprland desktop sessions. `bootstrap.sh` instructs the user to log into Hyprland to complete full session initialization.

### 4. Cross-Cutting: Process Matching Divergence in `applycolor.sh`
- **Item:** [applycolor.sh](file:///home/pera/github_repo/.dotfiles/quickshell/ii/scripts/colors/applycolor.sh#L45-L48) guards Kitty signaling with `pgrep -f kitty` (full command line pattern) while executing `kill -SIGUSR1 $(pidof kitty)` (exact binary name). If a non-Kitty process has "kitty" in its arguments, `kill` emits a benign syntax notice.
- **Impact:** Benign; runs in background subshell without aborting the wallpaper switcher.

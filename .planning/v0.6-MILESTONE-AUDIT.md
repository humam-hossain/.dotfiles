## End-to-End User Flows

1. **Resource Monitoring Flow (`procfs`/`sysfs` -> `ResourceUsage.qml` -> `Resource.qml` -> `Resources.qml` -> `BarContent.qml`):**
   - Polled every 3000ms by `ResourceUsage.qml`.
   - `Resources.qml` formats memory into definite gigabytes (`X.X/Y.Y GB (ZZ%)`) and dynamically reveals Swap when `swapUsed > 0`.
   - `Resource.qml` triggers synchronized Amber (`#FFA000`) and Error (`Appearance.colors.colError`) tones across circular progress ring, symbol icon, and text label.
   - `BarGroup.qml` provides fluid 250ms `emphasizedDecel` width resizing upon swap reveal/collapse.
   - **Status:** **COMPLETE**

2. **Package Update Flow (`pacman`/AUR check -> `Updates.qml` -> `UpdatesButton.qml` -> terminal spawn `system-update.sh`):**
   - `services/Updates.qml` aggregates pending repo and AUR updates non-blockingly via CLI pipeline (`checkupdates` + `yay -Qua`).
   - When `Updates.count > 0`, `BarContent.qml`'s `updatesLoader` dynamically renders `BarGroup { UpdatesButton {} }`.
   - Clicking dispatches `system-update.sh` via `Directories.scriptPath`, launching the configured terminal emulator with `--hold` flags, executing `yay -Syu --noconfirm` and pacman cache cleanups.
   - **Status:** **COMPLETE**

3. **Privacy Alert Flow (`PipeWire` / `wf-recorder` -> `Privacy.qml` -> `indicatorsRowLayout` in `BarContent.qml`):**
   - `services/Privacy.qml` ingests PipeWire audio/video link groups and polls `pgrep -x wf-recorder` every 1000ms.
   - `indicatorsRowLayout` reveals an Amber mic icon (`#FFA000`) when `Privacy.micActive` is true, and a Red screen share icon (`colError`) when `Privacy.screenSharing` is true.
   - Clicking the mic icon executes `wpctl set-mute @DEFAULT_SOURCE@ 1`.
   - Clicking the screen share icon invokes `record.sh`, halting `wf-recorder`, displaying a desktop notification with the saved recording path, and smoothly collapsing the indicator.
   - **Status:** **COMPLETE**

4. **Dynamic Theming Flow (`switchwall.sh` -> `colors.json` -> `Appearance` singleton -> `BarGroup`/pills):**
   - Running `switchwall.sh [image|--color <hex>|--noswitch]` executes `matugen` synchronously to extract Material 3 palette tokens into `~/.local/state/quickshell/user/generated/colors.json`.
   - `MaterialThemeLoader.qml` watches the file via native `FileView`, updating `Appearance.m3colors` and `Appearance.colors` in place.
   - All pills in `BarContent.qml` (`BarGroup`, `Resource`, `ClockWidget`, `UpdatesButton`, `SysTray`) immediately adapt with zero process restarts and zero git working tree churn.
   - **Status:** **COMPLETE**

5. **Cold Bootstrap Flow (`bootstrap.sh` -> `run_destub` -> `run_stow_step` -> 11 leaf symlinks):**
   - On fresh execution, `run_destub` simulates GNU Stow linking, backing up conflicting upstream Quickshell files into `~/.dotfiles-backup.<epoch>/` with SHA-256 manifest and unlinking them.
   - `run_stow_step` pre-creates ancestor directories (`modules/ii/bar`, `services`, `scripts/videos`) to prevent whole-directory folding, then stows `restow/quickshell` creating 11 discrete leaf symlinks.
   - `generate_initial_theme` validates that `colors.json` exists and is primed, falling back to seed `#3f51b5`.
   - **Status:** **COMPLETE**

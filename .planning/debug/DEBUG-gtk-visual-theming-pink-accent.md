## Root Cause Analysis

The symptom reported by the user ("still catppuccin color pink") has two distinct causes:

1. **Primary Cause (Cross-Toolkit Tool Launch Confusion):**
   The default desktop shortcuts for file manager (`SUPER + E`) and volume mixer (`CTRL + SUPER + V` / Quickshell widget) are configured in `hyprland/variables.lua` and `custom/variables.lua` to launch `dolphin` and `pavucontrol-qt` respectively. Both are Qt 6 / KDE applications running under `QT_QPA_PLATFORMTHEME=kde`, which reads `~/.config/kdeglobals`. `kdeglobals` currently retains upstream dots-hyprland's hardcoded mauve/pink accent colors (`LastUsedCustomAccentColor=184,117,220` and `DecorationFocus=#cdb9fb`). When the user launched their desktop file manager or volume mixer to verify Test 5, they were viewing Qt/KDE apps whose theming has not yet been harmonized (which is the explicit scope of **Phase 26**).

2. **Secondary Cause (Dracula Icon Theme Folder Accents):**
   For actual GTK applications like Nautilus, the active icon theme configured in both GTK settings and GSettings is `Tela-circle-dracula-dark`. In this theme, all directory and folder SVGs (e.g. `/usr/share/icons/Tela-circle-dracula/scalable/places/folder.svg`) have their folder tabs hardcoded to Dracula purple/pink `#bd93f9`. An observer opening Nautilus sees prominent purple/pink folder tabs, creating the visual impression of Catppuccin pink despite GTK UI elements (buttons, toggles, pathbar) correctly displaying Matugen cyan (`#82d3e1`).
